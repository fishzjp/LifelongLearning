## 📚 快速参考卡片

### 线性代数

```bash
# 矩阵运算

A + B  # 对应位置相加
A - B  # 对应位置相减
A @ B  # 矩阵乘法（注意维度匹配）
A.T    # 转置
np.linalg.inv(A)  # 逆矩阵
np.linalg.eig(A)  # 特征值/向量

# 图像表示

灰度图像: (H, W)        # 高度×宽度
彩色图像: (H, W, 3)     # 高度×宽度×通道(RGB)
```

### 微积分

```bash
# 导数与梯度

f'(x) = lim(h→0) [f(x+h) - f(x)] / h  # 导数定义

# 链式法则
# y = f(g(x))  =>  dy/dx = f'(g(x)) × g'(x)

# 梯度下降

w_new = w_old - learning_rate × ∇L(w)
# ∇L(w) 是损失函数对w的梯度

# 常用导数
# sigmoid: σ'(z) = σ(z)(1 - σ(z))
# ReLU:    ReLU'(z) = 1 if z>0 else 0
# softmax: ∂softmax/∂z_i = softmax(z_i)(1 - softmax(z_i))

```

### 概率统计

```bash
# 贝叶斯定理

P(A|B) = P(B|A) × P(A) / P(B)
# 后验 = 似然 × 先验 / 证据

# Softmax

softmax(z)_i = exp(z_i) / Σ_j exp(z_j)

# 正态分布

N(x|μ, σ²) = (1/(σ√(2π))) × exp(-(x-μ)²/(2σ²))

# 常用概率
# 68% 在 [μ-σ, μ+σ]
# 95% 在 [μ-2σ, μ+2σ]
# 99.7% 在 [μ-3σ, μ+3σ]

```
