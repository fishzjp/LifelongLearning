## 图像的本质

### 1.1 什么是数字图像？

#### 从现实到数字

想象你用手机拍了一张照片：
1. **现实世界**：光线通过镜头 → 传感器捕获 → 模拟信号
2. **数字化**：将模拟信号转换为数字（0和1）
3. **存储**：保存为文件（JPEG、PNG等）

**关键问题：计算机如何"看"图像？**

```python

# 依赖: matplotlib, numpy
# 安装: pip install matplotlib numpy

import matplotlib.pyplot as plt
```

### 2.2 分辨率

#### 什么是分辨率？

分辨率 = 图像的尺寸（宽度 × 高度），单位是像素。

```bash
# 分辨率对比演示

def resolution_comparison():
    """不同分辨率的效果对比"""

    # 创建一个简单的图案
    def create_pattern(size):
        img = np.zeros((size, size, 3), dtype=np.uint8)
        # 创建棋盘图案
        for i in range(size):
            for j in range(size):
                if (i // (size//8)) % 2 == (j // (size//8)) % 2:
                    img[i, j] = [255, 255, 255]
        return img

    resolutions = [32, 64, 128, 256]

    fig, axes = plt.subplots(2, 2, figsize=(12, 10))
    axes = axes.flatten()

    for i, res in enumerate(resolutions):
        img = create_pattern(res)
        axes[i].imshow(img)
        axes[i].set_title(f'分辨率: {res}x{res}\n总像素: {res*res}\n内存: {res*res*3}字节')
        axes[i].axis('off')

    plt.suptitle('分辨率对比：细节清晰度', fontsize=14)
    plt.tight_layout()
    plt.show()

resolution_comparison()
```

### 3.1 RGB色彩空间

#### RGB基础

RGB = **R**ed（红） + **G**reen（绿） + **B**lue（蓝）

这是最常用的颜色表示方法，就像你家里的彩色电视/显示器工作原理。


### 3.2 HSV色彩空间

#### 为什么需要HSV？

RGB的问题：**不直观**。调整亮度会影响所有通道。

HSV的优势：**分离亮度和颜色**，更符合人类直觉。

```bash
# HSV直观解释

def hsv_explanation():
    """HSV空间详细解释"""

    print("=== HSV色彩空间 ===")
    print("H (Hue/色调): 颜色的类型（红、绿、蓝等）")
    print("  范围：0-360度（0=红，120=绿，240=蓝）")
    print("S (Saturation/饱和度): 颜色的纯度")
    print("  范围：0-1（0=灰色，1=纯色）")
    print("V (Value/亮度): 颜色的明暗")
    print("  范围：0-1（0=黑，1=最亮）")

    print("\n=== 为什么用HSV？ ===")
    print("例子：想把图片中的红色物体变亮")
    print("- RGB: 需要同时调整R,G,B三个值")
    print("- HSV: 只调整V（亮度）即可，H和S保持不变")

    # 可视化HSV各分量
    fig, axes = plt.subplots(1, 3, figsize=(15, 5))

    # 创建彩色测试图
    test = np.zeros((100, 300, 3), dtype=np.uint8)
    test[:, :100] = [255, 0, 0]      # 红
    test[:, 100:200] = [0, 255, 0]   # 绿
    test[:, 200:] = [0, 0, 255]      # 蓝

    # 转换为HSV
    hsv = cv2.cvtColor(test, cv2.COLOR_BGR2HSV)

    axes[0].imshow(test)
    axes[0].set_title('原始RGB')
    axes[0].axis('off')

    axes[1].imshow(hsv)
    axes[1].set_title('HSV表示')
    axes[1].axis('off')

    # 调整亮度
    hsv_bright = hsv.copy()
    hsv_bright[:, :, 2] = np.minimum(hsv_bright[:, :, 2] + 50, 255)
    rgb_bright = cv2.cvtColor(hsv_bright, cv2.COLOR_HSV2RGB)

    axes[2].imshow(rgb_bright)
    axes[2].set_title('增加亮度后的RGB')
    axes[2].axis('off')

    plt.show()

hsv_explanation()
```

#### RGB与HSV转换详解

```bash
# RGB转HSV手动实现（教学用）

def manual_rgb_to_hsv():
    """手动实现RGB转HSV，理解转换原理"""

    def rgb_to_hsv_manual(r, g, b):
        """手动计算HSV"""
        # 归一化到[0, 1]
        r, g, b = r/255.0, g/255.0, b/255.0

        # 计算最大值、最小值、差值
        cmax = max(r, g, b)
        cmin = min(r, g, b)
        delta = cmax - cmin

        # 计算H（色调）
        if delta == 0:
            h = 0
        elif cmax == r:
            h = 60 * (((g - b) / delta) % 6)
        elif cmax == g:
            h = 60 * ((b - r) / delta + 2)
        else:  # cmax == b
            h = 60 * ((r - g) / delta + 4)

        # 计算S（饱和度）
        s = 0 if cmax == 0 else delta / cmax

        # 计算V（亮度）
        v = cmax

        return h, s, v

    # 测试几个颜色
    test_colors = {
        '红色': (255, 0, 0),
        '绿色': (0, 255, 0),
        '蓝色': (0, 0, 255),
        '黄色': (255, 255, 0),
        '灰色': (128, 128, 128)
    }

    print("RGB -> HSV 转换示例：")
    print(f"{'颜色':<8} {'RGB':<15} {'HSV':<20}")
    print("-" * 50)

    for name, (r, g, b) in test_colors.items():
        h, s, v = rgb_to_hsv_manual(r, g, b)
        print(f"{name:<8} ({r},{g},{b})<15> ({h:.1f}°, {s:.3f}, {v:.3f})")

    # 可视化
    fig, axes = plt.subplots(1, 2, figsize=(12, 5))

    # RGB显示
    rgb_img = np.array([[[r, g, b] for r, g, b in test_colors.values()]], dtype=np.uint8)
    axes[0].imshow(rgb_img)
    axes[0].set_title('RGB颜色')
    axes[0].axis('off')

    # HSV显示（H归一化到0-1）
    hsv_values = [rgb_to_hsv_manual(r, g, b) for _, (r, g, b) in test_colors.items()]
    hsv_img = np.array([[[h/360, s, v] for h, s, v in hsv_values]])
    axes[1].imshow(hsv_img)
    axes[1].set_title('HSV颜色 (H归一化)')
    axes[1].axis('off')

    plt.show()

manual_rgb_to_hsv()
```

```bash
# 灰度化详解

def grayscale_explanation():
    """为什么以及如何转换为灰度"""

    print("=== 灰度图像 ===")
    print("为什么需要灰度？")
    print("- 简化计算（只有一个通道）")
    print("- 边缘检测、特征提取通常在灰度图上进行")
    print("- 减少存储空间")

    print("\n转换公式：")
    print("灰度 = 0.299×R + 0.587×G + 0.114×B")
    print("为什么是这些系数？")
    print("因为人眼对绿色最敏感，蓝色最不敏感")

    # 演示
    color_img = np.zeros((100, 200, 3), dtype=np.uint8)
    color_img[:, :50] = [255, 0, 0]      # 红
    color_img[:, 50:100] = [0, 255, 0]   # 绿
    color_img[:, 100:150] = [0, 0, 255]  # 蓝
    color_img[:, 150:] = [255, 255, 0]   # 黄

    # 手动计算灰度
    gray_manual = 0.299 * color_img[:, :, 0] + \
                  0.587 * color_img[:, :, 1] + \
                  0.114 * color_img[:, :, 2]
    gray_manual = gray_manual.astype(np.uint8)

    # OpenCV灰度转换
    gray_cv = cv2.cvtColor(color_img, cv2.COLOR_BGR2GRAY)

    fig, axes = plt.subplots(1, 3, figsize=(15, 5))

    axes[0].imshow(color_img)
    axes[0].set_title('彩色图像')
    axes[0].axis('off')

    axes[1].imshow(gray_manual, cmap='gray')
    axes[1].set_title('手动计算灰度\n(0.299R + 0.587G + 0.114B)')
    axes[1].axis('off')

    axes[2].imshow(gray_cv, cmap='gray')
    axes[2].set_title('OpenCV灰度转换')
    axes[2].axis('off')
```

```python
def format_comparison():

        test_img[i, :] = [i-100, 180-i, 100]

    Image.fromarray(test_img).save(formats['JPEG_10'], quality=10)

        elif 'BMP' in name:

    fig, axes = plt.subplots(2, 3, figsize=(15, 10))

    # 原图
```

## 本章总结

### 核心概念回顾

#### 图像本质

- ✅ **图像 = 数字矩阵**：H×W×C的三维数组
- ✅ **像素**：图像的基本单位，值范围0-255
- ✅ **分辨率**：图像尺寸，决定细节清晰度

#### 色彩空间

- ✅ **RGB**：最常用，直观，但亮度和颜色耦合
- ✅ **HSV**：分离色调、饱和度、亮度，适合颜色处理
- ✅ **灰度**：单通道，简化计算
- ✅ **LAB**：感知均匀，适合专业色彩处理

#### 图像格式

- ✅ **PNG**：无损，适合图标、文字、需要透明度
- ✅ **JPEG**：有损，适合照片，文件小
- ✅ **BMP**：无压缩，原始质量，文件大

#### 基础操作

- ✅ **读写**：cv2.imread/imwrite
- ✅ **几何变换**：缩放、旋转、翻转
- ✅ **颜色调整**：亮度、对比度、通道操作

### 实践要点

1. **理解数据结构**：始终记住图像是数组
2. **注意数据类型**：uint8范围0-255，避免溢出
3. **选择合适格式**：根据用途选择PNG或JPEG
4. **色彩空间选择**：根据任务选择RGB或HSV
5. **保存原始数据**：编辑时用无损格式
