## 针孔相机模型

### 1.1 成像原理

**针孔相机模型**是计算机视觉中最基础的成像模型，它抽象了真实相机的成像过程。

#### 核心原理

针孔相机基于**小孔成像**原理：
- 光线通过一个小孔（针孔）投射到成像平面
- 物体距离越远，在成像平面上的投影越小
- 成像过程是**中心投影**，所有投影线汇聚于一点（相机中心）

#### 数学模型

对于3D空间中的点 P = (X, Y, Z)，其在图像平面上的投影点 p = (x, y) 满足：

```
x = f × X / Z
y = f × Y / Z
```

其中：
- **f**：焦距（focal length），单位是像素
- **(X, Y, Z)**：3D点在相机坐标系中的坐标
- **(x, y)**：投影后的2D图像坐标

#### 几何解释

- **Z轴**：光轴方向，垂直于图像平面
- **X, Y轴**：图像平面的水平和垂直方向
- **相似三角形**：物体与投影点形成相似三角形，比例因子为 f/Z

```python

# 依赖: matplotlib, numpy
# 安装: pip install matplotlib numpy
import numpy as np
import matplotlib.pyplot as plt
from mpl_toolkits.mplot3d import Axes3D

print("=== 针孔相机模型 ===")

# 可视化针孔成像

def visualize_pinhole():
    """可视化针孔成像原理"""
    fig = plt.figure(figsize=(12, 5))

    # 2D示意图
    ax1 = fig.add_subplot(1, 2, 1)

    # 相机参数
    f = 3  # 焦距（单位：任意长度）
    Z = 10  # 物体距离相机的深度

    # 物体位置（在X-Y平面，Z=10处）
    object_x = 2
    object_y = 1

    # 成像平面位置（在Z=-f处，即焦距的反方向）
    image_z = -f

    # 计算成像点（利用相似三角形原理）
    # 物体大小 / 物体距离 = 像点大小 / 焦距
    image_x = -f * object_x / Z
    image_y = -f * object_y / Z

    # 绘制光轴（Z轴）
    ax1.plot([0, Z], [0, 0], 'k-', linewidth=2)

    # 绘制物体（垂直于光轴的线段）
    ax1.plot([Z, Z], [0, object_y], 'b-', linewidth=2)

    # 绘制投影线
    ax1.plot([0, image_z], [0, image_y], 'r-', linewidth=2)

    # 标记关键点
    ax1.plot([0], [0], 'ko', markersize=10, label='针孔（相机中心）')
    ax1.plot([Z], [object_y], 'bo', markersize=8, label='物体')
    ax1.plot([image_z], [image_y], 'ro', markersize=8, label='像点')

    # 标注距离
    ax1.text(Z/2, 0.2, 'Z = 10', fontsize=12)
    ax1.text(image_z/2, image_y/2, f'f = {f}', fontsize=12, color='red')

    ax1.set_xlim(-12, 12)
    ax1.set_ylim(-3, 5)
    ax1.set_xlabel('Z轴 (深度)')
    ax1.set_ylabel('Y轴')
    ax1.set_title('2D针孔成像原理')
    ax1.legend()
    ax1.grid(True, alpha=0.3)

    # 3D示意图
    ax2 = fig.add_subplot(1, 2, 2, projection='3d')

    # 3D物体点
    X, Y, Z_obj = 2, 1, 10

    # 投影到成像平面
    x_img = -f * X / Z_obj
    y_img = -f * Y / Z_obj
    z_img = -f

    # 绘制3D点
    ax2.scatter([X], [Y], [Z_obj], c='b', s=100, label='3D点')
    ax2.scatter([0], [0], [0], c='k', s=100, label='相机中心')
    ax2.scatter([x_img], [y_img], [z_img], c='r', s=100, label='2D像点')

    # 绘制投影线（光线）
    ax2.plot([0, X], [0, Y], [0, Z_obj], 'k--', alpha=0.5, linewidth=1)
    ax2.plot([X, x_img], [Y, y_img], [Z_obj, z_img], 'b-', alpha=0.5, linewidth=1)

    # 绘制成像平面
    xx, yy = np.meshgrid(np.linspace(-2, 2, 10), np.linspace(-2, 2, 10))
    zz = np.full_like(xx, -f)
    ax2.plot_surface(xx, yy, zz, alpha=0.2, color='gray')

    ax2.set_xlabel('X')
    ax2.set_ylabel('Y')
    ax2.set_zlabel('Z')
    ax2.set_title('3D投影几何')
    ax2.legend()
    ax2.grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

    print("针孔模型公式：")
    print("x = f * X / Z")
    print("y = f * Y / Z")
    print("\n其中：")
    print("f = 焦距（像素）")
    print("(X, Y, Z) = 3D世界坐标（相机坐标系）")
    print("(x, y) = 2D图像坐标")
    print("\n关键理解：")
    print("1. 深度Z越大，投影坐标越小（物体越远，成像越小）")
    print("2. 焦距f越大，放大倍数越大")
    print("3. 这是一个非线性变换（除以Z）")

visualize_pinhole()
```

### 1.2 投影矩阵

为了将3D到2D的投影过程用**矩阵运算**统一表示，我们引入投影矩阵。

#### 投影方程的完整形式

完整的投影过程分为两步：

**步骤1：世界坐标 → 相机坐标**
```
P_camera = R × P_world + t
```
其中：
- R：3×3旋转矩阵，描述相机朝向
- t：3×1平移向量，描述相机位置
- P_world：世界坐标系中的3D点 [X, Y, Z]
- P_camera：相机坐标系中的3D点 [X_c, Y_c, Z_c]

**步骤2：相机坐标 → 图像坐标**
```
x = fx × X_c / Z_c + cx
y = fy × Y_c / Z_c + cy
```
其中：
- fx, fy：x和y方向的焦距（可能不同）
- cx, cy：主点坐标（图像中心）

#### 投影矩阵形式

将上述两步合并，得到**投影矩阵P**：

```
s × [u]   [fx  0  cx  0]   [X]
  × [v] = [0  fy  cy  0] × [Y]
    [1]   [0   0   1  0]   [Z]
                            [1]
```

或者写成：
```
P = K × [R | t]
```

其中 **K** 是内参矩阵，**[R | t]** 是外参矩阵。

```python
print("\n=== 投影矩阵 ===")

def projection_demo():
    """演示投影矩阵计算和完整的投影过程"""

    # 3D世界坐标点（单位：mm）
    world_points = np.array([
        [100, 200, 500],   # 点1：右前方
        [200, 100, 800],   # 点2：右上方远处
        [-100, 300, 1000], # 点3：左前方远处
        [300, -200, 600]   # 点4：右下方
    ])

    # 相机内参（假设：手机相机）
    fx = fy = 800  # 焦距800像素
    cx = 320       # 主点x（图像中心）
    cy = 240       # 主点y（图像中心）

    # 内参矩阵 K
    K = np.array([
        [fx, 0, cx],
        [0, fy, cy],
        [0, 0, 1]
    ])

    # 外参矩阵（相机在世界坐标系中的位姿）
    # 假设相机位于(0, 0, 0)，无旋转
    R = np.eye(3)  # 单位矩阵：无旋转
    t = np.array([0, 0, 0])  # 无平移：相机在原点

    # 投影函数
    def project_points(world_points, K, R, t):
        """将3D世界点投影到2D图像"""
        projected = []

        for point in world_points:
            # 步骤1：世界坐标 → 相机坐标
            # P_camera = R × P_world + t
            camera_point = R @ point + t

            # 步骤2：相机坐标 → 图像坐标
            if camera_point[2] > 0:  # 确保点在相机前方
                # 透视投影
                x = K[0, 0] * camera_point[0] / camera_point[2] + K[0, 2]
                y = K[1, 1] * camera_point[1] / camera_point[2] + K[1, 2]
                projected.append([x, y])
            else:
                projected.append([np.nan, np.nan])  # 在相机后方，无法投影

        return np.array(projected)

    # 执行投影
    image_points = project_points(world_points, K, R, t)

    print("完整投影过程演示：")
    print("-" * 70)
    print(f"{'点':<5} {'世界坐标 (X,Y,Z)':<25} → {'图像坐标 (u,v)':<20}")
    print("-" * 70)
    for i, (wp, ip) in enumerate(zip(world_points, image_points)):
        if not np.isnan(ip[0]):
            print(f"点{i+1}: [{wp[0]:6.0f}, {wp[1]:6.0f}, {wp[2]:6.0f}] → [{ip[0]:6.1f}, {ip[1]:6.1f}]")
        else:
            print(f"点{i+1}: [{wp[0]:6.0f}, {wp[1]:6.0f}, {wp[2]:6.0f}] → 无法投影（在相机后方）")

    # 可视化
    fig, axes = plt.subplots(1, 2, figsize=(14, 6))

    # 3D视图
    ax3d = fig.add_subplot(1, 2, 1, projection='3d')

    # 绘制世界点
    ax3d.scatter(world_points[:, 0], world_points[:, 1], world_points[:, 2],
                c='blue', s=100, marker='o', label='世界点')

    # 绘制相机位置
    ax3d.scatter([0], [0], [0], c='red', s=200, marker='^', label='相机位置')

    # 绘制视线
    for i, wp in enumerate(world_points):
        ax3d.plot([0, wp[0]], [0, wp[1]], [0, wp[2]], 'k--', alpha=0.3)

    ax3d.set_xlabel('X (mm)')
    ax3d.set_ylabel('Y (mm)')
    ax3d.set_zlabel('Z (mm)')
    ax3d.set_title('3D世界坐标系')
    ax3d.legend()
    ax3d.grid(True, alpha=0.3)

    # 2D视图
    valid_mask = ~np.isnan(image_points[:, 0])
    axes[0].scatter(image_points[valid_mask, 0], image_points[valid_mask, 1],
                   c='red', s=100, marker='x')

    # 标注每个点
    for i, ip in enumerate(image_points[valid_mask]):
        axes[0].text(ip[0]+5, ip[1]+5, f"P{i+1}", fontsize=10, color='red')

    # 绘制图像边界
    axes[0].axvline(x=0, color='gray', linestyle='--', alpha=0.5)
    axes[0].axvline(x=640, color='gray', linestyle='--', alpha=0.5)
    axes[0].axhline(y=0, color='gray', linestyle='--', alpha=0.5)
    axes[0].axhline(y=480, color='gray', linestyle='--', alpha=0.5)

    axes[0].set_xlim(-100, 740)
    axes[0].set_ylim(-100, 580)
    axes[0].set_aspect('equal')
    axes[0].set_xlabel('u (像素)')
    axes[0].set_ylabel('v (像素)')
    axes[0].set_title('2D图像投影')
    axes[0].grid(True, alpha=0.3)

    # 显示参数
    axes[1].axis('off')
    param_text = "相机参数详解：\n\n"
    param_text += f"内参矩阵 K:\n{K}\n\n"
    param_text += f"旋转矩阵 R:\n{R}\n\n"
    param_text += f"平移向量 t:\n{t}\n\n"
    param_text += "投影矩阵 P = K × [R|t]:\n"
    P = K @ np.hstack([R, t.reshape(3, 1)])
    param_text += f"{P}"

    axes[1].text(0.05, 0.95, param_text, fontsize=8, family='monospace',
                 verticalalignment='top', transform=axes[1].transAxes,
                 bbox=dict(boxstyle='round', facecolor='wheat', alpha=0.5))

    plt.tight_layout()
    plt.show()

    print("\n投影矩阵 P = K × [R|t]")
    print(f"内参 K:\n{K}")
    print(f"\n外参 R:\n{R}")
    print(f"外参 t:\n{t}")
    print(f"\n完整投影矩阵 P:\n{P}")

projection_demo()
```

## 相机内参与外参

### 2.1 内参详解

**相机内参**描述相机内部的几何和光学特性，与相机在世界中的位置无关。

#### 内参矩阵 K

```
K = [fx   0   cx]
    [0    fy  cy]
    [0    0    1 ]
```

#### 参数详解

**1. 焦距 (fx, fy)**
- **物理意义**：相机镜头的焦距，单位是像素
- **作用**：决定图像的放大倍数和视野范围
- **典型值**：
  - 手机相机：800-1200像素
  - 单反相机：1500-3000像素
  - 广角镜头：400-600像素

**2. 主点 (cx, cy)**
- **物理意义**：光轴与图像平面的交点，通常是图像中心
- **作用**：坐标系的原点偏移
- **典型值**：(图像宽度/2, 图像高度/2)

**3. 像素纵横比**
- 通常 fx/fy ≈ 1（方形像素）
- 某些特殊相机可能 ≠ 1

#### 焦距与视野的关系

焦距直接影响视野（Field of View, FOV）：

```
FOV_x = 2 × arctan(图像宽度 / (2 × fx))
FOV_y = 2 × arctan(图像高度 / (2 × fy))
```

- **焦距大** → 视野小 → 放大效果（长焦）
- **焦距小** → 视野大 → 广角效果

```python
print("\n=== 相机内参详解 ===")

def intrinsic_parameters_demo():
    """深入讲解内参矩阵的含义和影响"""

    print("内参矩阵 K 的结构：")

    print("    [0    fy  cy]")
    print("    [0    0    1 ]")

        print(f"  内参 K:\n{K}")

        fov_y = 2 * np.arctan(H / (2 * f)) * 180 / np.pi

        # 绘制图像平面

        axes[idx].set_ylim(-H/2-50, H/2+50)
        axes[idx].set_aspect('equal')

        # 绘制图像边界
        axes[idx].plot([-W/2, W/2, W/2, -W/2, -W/2],
                      [-H/2, -H/2, H/2, H/2, -H/2],
                      'k-', linewidth=2)

        # 绘制视野锥（从相机中心到图像四角）
        axes[idx].plot([0, -W/2], [0, -H/2], 'r--', alpha=0.5, linewidth=1)
        axes[idx].plot([0, W/2], [0, -H/2], 'r--', alpha=0.5, linewidth=1)
        axes[idx].plot([0, -W/2], [0, H/2], 'r--', alpha=0.5, linewidth=1)
        axes[idx].plot([0, W/2], [0, H/2], 'r--', alpha=0.5, linewidth=1)

        # 标记相机中心
        axes[idx].plot([0], [0], 'ko', markersize=8)

        axes[idx].set_title(f'焦距 f = {f} 像素\nFOV: {fov_x:.1f}° × {fov_y:.1f}°', fontsize=11)
        axes[idx].set_xlabel('u (像素)')
        axes[idx].set_ylabel('v (像素)')
        axes[idx].grid(True, alpha=0.3)

    plt.suptitle('不同焦距对视野的影响', fontsize=14, y=1.02)
    plt.tight_layout()
    plt.show()

    print("\n" + "="*70)
    print("焦距与视野的关键关系：")
    print("="*70)
    print("• 焦距越大 → 视野越小 → 放大效果（长焦镜头）")
    print("• 焦距越小 → 视野越大 → 广角效果（鱼眼镜头）")
    print("• 相同焦距下，分辨率越高，像素密度越大")
    print("• 实际应用中，焦距决定了拍摄场景的范围")

intrinsic_parameters_demo()
```

### 2.2 外参详解

**相机外参**描述相机在世界坐标系中的位置和姿态。

#### 外参组成

外参由两部分组成：

**1. 旋转矩阵 R (3×3)**
- 描述相机的**朝向**
- 将世界坐标系旋转到相机坐标系
- 性质：
  - 正交矩阵：R^T × R = I
  - 行列式：det(R) = 1
  - 逆矩阵：R^(-1) = R^T

**2. 平移向量 t (3×1)**
- 描述相机的**位置**
- 表示相机中心在世界坐标系中的坐标
- 与旋转的关系：t = -R × C，其中C是相机中心

#### 坐标变换过程

```
世界坐标 P_w → 相机坐标 P_c：
P_c = R × P_w + t

逆变换：
P_w = R^T × (P_c - t)
```

#### 欧拉角表示

旋转矩阵可以用欧拉角表示（绕X、Y、Z轴旋转）：

```
R = R_z(ψ) × R_y(θ) × R_x(φ)
```

其中：
- φ (roll)：绕X轴旋转
- θ (pitch)：绕Y轴旋转
- ψ (yaw)：绕Z轴旋转

```python
print("\n=== 相机外参详解 ===")

def extrinsic_parameters_demo():
    """深入讲解外参矩阵的含义和作用"""

    print("外参矩阵 = 旋转R + 平移t")
    print("\n1. 旋转矩阵 R (3×3)")
    print("   • 描述相机朝向")
    print("   • 将世界坐标 → 相机坐标")
    print("   • 性质：正交矩阵，R^T × R = I")
    print("\n2. 平移向量 t (3×1)")
```

## 镜头畸变模型

### 3.1 径向畸变

真实相机镜头并非理想的针孔模型，会引入**畸变**。

#### 畸变的类型

**1. 径向畸变 (Radial Distortion)**
- 沿着半径方向的畸变
- 由镜头形状引起
- 分为两类：

**桶形畸变 (Barrel Distortion)**
- k1 < 0
- 图像边缘向内收缩
- 常见于广角镜头、鱼眼镜头
- 效果：直线变弯曲，向内凹陷

**枕形畸变 (Pincushion Distortion)**
- k1 > 0
- 图像边缘向外扩张
- 常见于长焦镜头
- 效果：直线变弯曲，向外凸出

#### 数学模型

**径向畸变公式：**
```
x_corrected = x × (1 + k1×r² + k2×r⁴ + k3×r⁶)
y_corrected = y × (1 + k1×r² + k2×r⁴ + k3×r⁶)
```

其中：
- r² = x² + y²：到图像中心的距离
- k1, k2, k3：径向畸变系数
- 通常 k1 主导，k2, k3 用于高精度校正

**切向畸变公式：**
```
x_corrected = x + 2×p1×x×y + p2×(r² + 2×x²)
y_corrected = y + p1×(r² + 2×y²) + 2×p2×x×y
```

其中：
- p1, p2：切向畸变系数
- 由镜头与传感器不平行引起

### 3.2 畸变校正

#### 校正原理

畸变校正是一个**反向映射**过程：

1. **畸变过程**（正向）：
   ```
   理想坐标 (x, y) → 畸变坐标 (x_d, y_d)
   ```

2. **校正过程**（反向）：
   ```
   畸变坐标 (x_d, y_d) → 理想坐标 (x, y)
   ```

#### 校正步骤

```
1. 对于输出图像的每个像素 (u, v)
2. 转换为归一化坐标 (x, y)
3. 应用畸变模型得到畸变坐标 (x_d, y_d)
4. 将畸变坐标映射回输入图像
5. 插值得到像素值
```

#### 实际应用

在OpenCV中：
```bash
# 标定得到参数

ret, K, D, rvecs, tvecs = cv2.calibrateCamera(...)

# 校正图像

undistorted = cv2.undistort(img, K, D)
```

```python
print("\n=== 畸变校正 ===")

def distortion_correction_demo():
    """演示畸变校正的完整过程"""

    print("畸变校正原理：")
    print("\n1. 畸变过程（正向映射）：")
    print("   理想坐标 → 畸变坐标")
    print("   (x, y) → (x_d, y_d)")
    print("\n2. 校正过程（反向映射）：")
    print("   畸变坐标 → 理想坐标")
    print("   (x_d, y_d) → (x, y)")
    print("\n为什么需要反向映射？")
    print("  • 正向映射会导致输出图像有空洞")
    print("  • 反向映射确保每个输出像素都有值")
    print("  • 需要插值计算")

    # 创建测试图像（棋盘格）
    def create_chessboard(size=100, square=10):
        """创建棋盘格图案"""
        board = np.zeros((size, size), dtype=np.uint8)
        for i in range(0, size, square):
            for j in range(0, size, square):
                if (i // square + j // square) % 2 == 0:
                    board[i:i+square, j:j+square] = 255
        return board

    board = create_chessboard(100, 10)

    # 应用畸变
    def apply_distortion(img, k1=-0.2, k2=0.05):
        """对图像应用径向畸变"""
        h, w = img.shape
        distorted = np.zeros_like(img)

        # 归一化坐标（中心为0，范围-1到1）
        x_norm = (np.arange(w) - w/2) / (w/2)
        y_norm = (np.arange(h) - h/2) / (h/2)
        xx, yy = np.meshgrid(x_norm, y_norm)

        # 计算半径
        r = np.sqrt(xx**2 + yy**2)

        # 应用畸变公式
        factor = 1 + k1 * r**2 + k2 * r**4
        x_dist = xx * factor
        y_dist = yy * factor

        # 映射回像素坐标
        x_pixel = (x_dist * w/2 + w/2).astype(int)
        y_pixel = (y_dist * h/2 + h/2).astype(int)

        # 插值（最近邻）
        for i in range(h):
            for j in range(w):
                if 0 <= y_pixel[i, j] < h and 0 <= x_pixel[i, j] < w:
                    distorted[i, j] = img[y_pixel[i, j], x_pixel[i, j]]

        return distorted

    distorted = apply_distortion(board, k1=-0.2, k2=0.05)

    # 畸变校正
    def correct_distortion(img, k1=-0.2, k2=0.05):
        """校正图像畸变"""
        h, w = img.shape
        corrected = np.zeros_like(img)

        # 归一化坐标
        x_norm = (np.arange(w) - w/2) / (w/2)
        y_norm = (np.arange(h) - h/2) / (h/2)
        xx, yy = np.meshgrid(x_norm, y_norm)

        # 计算半径
        r = np.sqrt(xx**2 + yy**2)
        factor = 1 + k1 * r**2 + k2 * r**4

        # 反向映射：从畸变坐标映射回理想坐标
        # 理想坐标 = 畸变坐标 / 因子
        x_ideal = xx / factor
        y_ideal = yy / factor

        # 映射回像素坐标
        x_pixel = (x_ideal * w/2 + w/2).astype(int)
        y_pixel = (y_ideal * h/2 + h/2).astype(int)

        # 插值
        for i in range(h):
            for j in range(w):
                if 0 <= y_pixel[i, j] < h and 0 <= x_pixel[i, j] < w:
                    corrected[i, j] = img[y_pixel[i, j], x_pixel[i, j]]

        return corrected

    corrected = correct_distortion(distorted, k1=-0.2, k2=0.05)

    # 可视化
    fig, axes = plt.subplots(1, 3, figsize=(15, 5))

    axes[0].imshow(board, cmap='gray')
    axes[0].set_title('原始棋盘格\n(无畸变)', fontsize=12)
    axes[0].axis('off')

    axes[1].imshow(distorted, cmap='gray')
    axes[1].set_title('畸变后\n(桶形畸变)', fontsize=12)
    axes[1].axis('off')

    axes[2].imshow(corrected, cmap='gray')
    axes[2].set_title('校正后\n(恢复原状)', fontsize=12)
    axes[2].axis('off')

    plt.tight_layout()
    plt.show()

    # 误差分析
    def compute_error(img1, img2):
        """计算两幅图像的平均差异"""
        return np.mean(np.abs(img1.astype(float) - img2.astype(float)))

    error_dist = compute_error(board, distorted)
    error_corr = compute_error(board, corrected)

    print("\n" + "="*70)
    print("校正效果评估：")
    print("="*70)
    print(f"原始 vs 畸变: 误差 = {error_dist:.2f}")
    print(f"原始 vs 校正: 误差 = {error_corr:.2f}")
    print(f"改善比例: {(1 - error_corr/error_dist)*100:.1f}%")
    print("\n畸变校正流程：")
    print("  1. 拍摄畸变图像")
    print("  2. 检测特征点（如棋盘格角点）")
    print("  3. 估计畸变参数 (k1, k2, p1, p2)")
    print("  4. 构建反向映射表")
    print("  5. 插值校正图像")
```

## 相机标定方法

### 4.1 棋盘格标定

**相机标定**是通过已知的3D-2D对应点来估计相机参数的过程。

#### 标定原理

**已知条件：**
- 3D世界坐标：棋盘格角点（已知尺寸）
- 2D图像坐标：检测到的角点

**求解目标：**
- 内参 K
- 畸变参数 D
- 外参 R, t（每个视角）

#### 数学模型

对于每个角点，投影方程为：
```
s × [u; v; 1] = K × [R|t] × [X; Y; Z; 1]
```

这是一个**超定线性方程组**，需要至少：
- 6个点（未知数：K有4个，R有3个，t有3个，共10个）
- 但R是旋转矩阵（有约束），实际需要更多点

#### 棋盘格的优势

1. **角点明确**：黑白交界处角点清晰
2. **亚像素精度**：可检测到0.1像素精度
3. **3D坐标已知**：每个角点的世界坐标可计算
4. **多视角**：不同角度提供丰富信息

```python
print("\n=== 棋盘格标定 ===")

def chessboard_calibration_demo():
    """演示棋盘格标定的原理和过程"""

    print("棋盘格标定原理：")
    print("\n1. 已知条件：")
    print("   • 棋盘格物理尺寸（如25mm）")
    print("   • 每个角点的世界坐标")
    print("   • 图像中检测到的角点坐标")
    print("\n2. 求解目标：")
    print("   • 内参 K (fx, fy, cx, cy)")
    print("   • 畸变参数 D (k1, k2, p1, p2)")
    print("   • 外参 R, t（每个视角）")
    print("\n3. 投影方程：")
    print("   s[u, v, 1]^T = K[R|t][X, Y, Z, 1]^T")

    # 生成3D棋盘格角点
    square_size = 25  # mm
    rows, cols = 6, 8  # 6行8列

    # 世界坐标（Z=0平面）
    world_points = []
    for i in range(rows):
        for j in range(cols):
            world_points.append([j * square_size,, i * square_size, 0])
    world_points = np.array(world_points, dtype=np.float32)

    print(f"\n棋盘格配置：")
    print(f"  角点数量: {rows} × {cols} = {len(world_points)}")
    print(f"  方格尺寸: {square_size} mm")
    print(f"  总尺寸: {(cols-1)*square_size} × {(rows-1)*square_size} mm")

    # 模拟多个视角
    np.random.seed(42)
    num_views = 5

    # 真实相机参数（用于生成模拟数据）
    K_true = np.array([
        [800, 0, 320],
        [0, 800, 240],
        [0, 0, 1]
    ])
    dist_true = np.array([-0.2, 0.05, 0.01, -0.01, 0])

    image_points_all = []

    print(f"\n模拟拍摄 {num_views} 个不同视角：")
    print("-" * 60)

    # 为每个视角生成图像点
    for view in range(num_views):
        # 随机外参（模拟不同拍摄角度）
        angle_x = np.random.uniform(-0.3, 0.3)  # 俯仰角
        angle_y = np.random.uniform(-0.3, 0.3)  # 偏航角
        angle_z = np.random.uniform(-0.3, 0.3)  # 侧倾角

        # 旋转矩阵（欧拉角）
        Rx = np.array([[1, 0, 0],
                       [0, np.cos(angle_x), -np.sin(angle_x)],
                       [0, np.sin(angle_x), np.cos(angle_x)]])
        Ry = np.array([[np.cos(angle_y), 0, np.sin(angle_y)],
                       [0, 1, 0],
                       [-np.sin(angle_y), 0, np.cos(angle_y)]])
        Rz = np.array([[np.cos(angle_z), -np.sin(angle_z), 0],
                       [np.sin(angle_z), np.cos(angle_z), 0],
                       [0, 0, 1]])
        R = Rz @ Ry @ Rx

        # 平移（相机位置）
        t = np.array([0, 0, 500 + np.random.uniform(-50, 50)])

        # 投影到图像
        image_points = []
        for point_3d in world_points:
            # 世界 → 相机
            point_camera = R @ point_3d + t

            # 相机 → 图像（无畸变）
            x = K_true[0, 0] * point_camera[0] / point_camera[2] + K_true[0, 2]
            y = K_true[1, 1] * point_camera[1] / point_camera[2] + K_true[1, 2]

            # 添加测量噪声
            x += np.random.normal(0, 0.5)
            y += np.random.normal(0, 0.5)

            image_points.append([x, y])

        image_points_all.append(np.array(image_points, dtype=np.float32))

        # 计算旋转角度（度）
        angle_deg = np.sqrt(angle_x**2 + angle_y**2 + angle_z**2) * 180 / np.pi
        print(f"视角 {view+1}: 旋转≈{angle_deg:.1f}°, 距离≈{t[2]:.0f}mm, "
              f"有效点数: {len(image_points)}")

    # 可视化一个视角
    fig, axes = plt.subplots(1, 2, figsize=(12, 5))

    # 3D世界点
    axes[0].scatter(world_points[:, 0], world_points[:, 1], c='blue', s=30)
    axes[0].set_xlabel('X (mm)')
    axes[0].set_ylabel('Y (mm)')
    axes[0].set_title('世界坐标系中的棋盘格')
    axes[0].set_aspect('equal')
    axes[0].grid(True, alpha=0.3)

    # 2D图像点（视角1）
```

### 4.2 标定流程与OpenCV实现

#### 完整标定流程

```
1. 准备标定板
   - 棋盘格或圆点阵列
   - 已知物理尺寸

2. 拍摄多张照片
   - 不同角度（旋转）
   - 不同距离（平移）
   - 覆盖整个视野
   - 建议15-20张

3. 检测角点
   - 粗检测：findChessboardCorners
   - 精细化：cornerSubPix（亚像素）

4. 建立方程组
   - 每个点一个投影方程
   - 超定系统

5. 求解参数
   - 最小化重投影误差

6. 评估质量
   - 重投影误差 < 0.5像素
   - 检查参数合理性

7. 应用
   - 图像去畸变
   - 3D重建
   - 精确测量
```

#### 重投影误差

**定义**：使用估计参数将3D点投影到2D，与观测点的差异。

```
误差 = ||观测点 - 重投影点||
```

**意义**：
- 评估标定质量
- 指导参数优化
- 典型阈值：< 0.5像素

```python
def practice2_distortion_correction():
    """练习：畸变校正"""

    # 创建测试图案
    def create_pattern(size=200):
        pattern = np.ones((size, size, 3), dtype=np.uint8) * 200
        # 网格
        for i in range(0, size, 20):
            pattern[i:i+2, :] = [100, 100, 100]
            pattern[:, i:i+2] = [100, 100, 100]
        # 圆圈
        center = size // 2
        y, x = np.ogrid[:size, :size]
        circle = (x - center)**2 + (y - center)**2 < (size/4)**2
        pattern[circle] = [150, 150, 255]
        return pattern

    original = create_pattern()

    # 应用畸变
    def distort_image(img, k1=-0.3, k2=0.1):
        h, w = img.shape[:2]
        distorted = np.zeros_like(img)
        K = np.array([[800, 0, w/2], [0, 800, h/2], [0, 0, 1]])
        D = np.array([k1, k2, 0, 0, 0])

        for i in range(h):
            for j in range(w):
                x = (j - K[0, 2]) / K[0, 0]
                y = (i - K[1, 2]) / K[1, 1]
                r2 = x**2 + y**2
                radial = 1 + D[0] * r2 + D[1] * r2**2
                x_dist = x * radial
                y_dist = y * radial
                map_x = K[0, 0] * x_dist + K[0, 2]
                map_y = K[1, 1] * y_dist + K[1, 2]
                if 0 <= map_y < h and 0 <= map_x < w:
                    distorted[i, j] = img[int(map_y), int(map_x)]
        return distorted

    distorted = distort_image(original, k1=-0.3, k2=0.1)

    # 校正
    def undistort_image(img, k1=-0.3, k2=0.1):
        h, w = img.shape[:2]
        undistorted = np.zeros_like(img)
        K = np.array([[800, 0, w/2], [0, 800, h/2], [0, 0, 1]])
        D = np.array([k1, k2, 0, 0, 0])

        for i in range(h):
            for j in range(w):
                x = (j - K[0, 2]) / K[0, 0]
                y = (i - K[1, 2]) / K[1, 1]
                r2 = x**2 + y**2
                radial = 1 + D[0] * r2 + D[1] * r2**2
                x_dist = x / radial  # 反向
                y_dist = y / radial
                map_x = K[0, 0] * x_dist + K[0, 2]
                map_y = K[1, 1] * y_dist + K[1, 2]
                if 0 <= map_y < h and 0 <= map_x < w:
                    undistorted[i, j] = img[int(map_y), int(map_x)]
        return undistorted

    corrected = undistort_image(distorted)

    # 可视化
    fig, axes = plt.subplots(1, 3, figsize=(15, 5))
    axes[0].imshow(original)
    axes[0].set_title('原始图像')
    axes[0].axis('off')
    axes[1].imshow(distorted)
    axes[1].set_title('畸变后 (k1=-0.3)')
    axes[1].axis('off')
    axes[2].imshow(corrected)
    axes[2].set_title('校正后')
    axes[2].axis('off')
    plt.tight_layout()
    plt.show()

    # 误差
    error_dist = np.mean(np.abs(original.astype(float) - distorted.astype(float)))
    error_corr = np.mean(np.abs(original.astype(float) - corrected.astype(float)))
    print(f"\n畸变误差: {error_dist:.2f}")
    print(f"校正误差: {error_corr:.2f}")
    print(f"改善: {(1 - error_corr/error_dist)*100:.1f}%")
```

```python
def practice3_calibration_simulation():

    D_true = np.array([-0.2, 0.05, 0.01, -0.01, 0])

    # 标定板
    square_size = 25
    board_shape = (6, 8)
    world_points = []
    for i in range(board_shape[0]):
        for j in range(board_shape[1]):
            world_points.append([j * square_size, i * square_size, 0])
    world_points = np.array(world_points, dtype=np.float32)

    # 生成多个视角
    num_views = 6
    objpoints = []
    imgpoints = []

    print("生成标定数据：")
    for view in range(num_views):
        angle = np.random.uniform(-0.4, 0.4, 3)
        R = np.array([[1, 0, 0],
                      [0, np.cos(angle[0]), -np.sin(angle[0])],
                      [0, np.sin(angle[0]), np.cos(angle[0])]])
        t = np.array([np.random.uniform(-50, 50),
                      np.random.uniform(-50, 50),
                      500 + np.random.uniform(-100, 100)])

        img_pts = []
        for wp in world_points:
            cp = R @ wp + t
            x = cp[0] / cp[2]
            y = cp[1] / cp[2]
            r2 = x**2 + y**2
            radial = 1 + D_true[0] * r2 + D_true[1] * r2**2
            x_dist = x * radial
            y_dist = y * radial
            u = K_true[0, 0] * x_dist + K_true[0, 2]
            v = K_true[1, 1] * y_dist + K_true[1, 2]
            u += np.random.normal(0, 0.3)
            v += np.random.normal(0, 0.3)
            img_pts.append([u, v])

        objpoints.append(world_points)
        imgpoints.append(np.array(img_pts, dtype=np.float32))
        print(f"  视角 {view+1}: t=[{t[0]:.0f}, {t[1]:.0f}, {t[2]:.0f}]")

    # 简化标定（估计内参）
    all_img = np.vstack(imgpoints)
    all_obj = np.vstack(objpoints)

    A = []
    b = []
    for i in range(len(all_img)):
        X, Y, Z = all_obj[i]
        u, v = all_img[i]
        if Z != 0:
            A.append([X/Z, 0, 1, 0])
            b.append(u)
            A.append([0, Y/Z, 0, 1])
            b.append(v)

    A = np.array(A)
    b = np.array(b)
    params, _, _, _ = np.linalg.lstsq(A, b, rcond=None)
    fx_est, fy_est, cx_est, cy_est = params[0], params[0], params[1], params[2]

                    error = np.sqrt((u_proj - img[i, 0])**2 + (v_proj - img[i, 1])**2)
                    total_error += error
                    count += 1
        return total_error / count if count > 0 else 0

    error_true = reproject_error(K_true, objpoints, imgpoints)
    error_est = reproject_error(K_est, objpoints, imgpoints)
```

## 本章总结

### 核心知识点

#### 1. **相机模型**

- ✅ **针孔模型**：几何成像原理，相似三角形
- ✅ **投影矩阵**：P = K[R|t]，统一表示投影
- ✅ **内参**：fx, fy（焦距），cx, cy（主点）
- ✅ **外参**：R（旋转），t（平移）

#### 2. **畸变模型**

- ✅ **径向畸变**：k1, k2, k3（桶形/枕形）
- ✅ **切向畸变**：p1, p2（镜头不平行）
- ✅ **校正方法**：反向映射 + 插值

#### 3. **标定技术**

- ✅ **棋盘格**：角点明确，亚像素精度
- ✅ **标定流程**：拍摄→检测→求解→评估
- ✅ **重投影误差**：质量评估指标
