## 🎯 场景选择决策树

```
需要图像分类？
    ↓
数据集大小？
    ├─ 小数据集 (<10k) → ResNet50 + 迁移学习
    └─ 大数据集 (>100k) → 继续判断
    
硬件资源？
    ├─ 移动端/边缘设备 → MobileNetV2 / EfficientNet
    ├─ GPU服务器 → 继续判断
    └─ CPU → ResNet18 / MobileNetV2
    
精度要求？
    ├─ 高精度 (>80%) → ResNet101 / DenseNet201
    ├─ 平衡 → ResNet50
    └─ 快速原型 → ResNet18
    
任务类型？
    ├─ 目标检测 → ResNet50 / ResNet101
    ├─ 图像分割 → DenseNet121
    └─ 特征提取 → VGG16 / ResNet50
    
部署环境？
    ├─ 生产环境 → ResNet50 (稳定)
    ├─ 移动端 → MobileNetV2 (轻量)
    └─ 研究 → DenseNet121 (高效)
```

## 🚀 实际应用推荐

### 1. 工业落地首选

```bash
# 推荐1: ResNet50 - 最佳平衡

model = torchvision.models.resnet50(pretrained=True)
# 适用: 90%的图像分类任务
# 优点: 稳定、文档丰富、社区支持好

# 推荐2: ResNet18 - 快速推理

model = torchvision.models.resnet18(pretrained=True)
# 适用: 实时应用，移动端
# 优点: 速度快、参数少

# 推荐3: DenseNet121 - 医学图像

model = torchvision.models.densenet121(pretrained=True)
# 适用: 医学影像分割
# 优点: 参数效率高、特征复用强

```

### 2. 学习路径建议

```
入门阶段:
LeNet-5 (理解基础) → AlexNet (理解深度学习) → VGG (理解深度)

进阶阶段:
ResNet-50 (掌握残差) → DenseNet (理解特征复用)

实战阶段:
使用torchvision加载预训练模型 → 迁移学习 → 微调
```

### 3. 性能优化建议

| 优化策略 | 适用架构 | 效果 |
|----------|----------|------|
| **预训练+微调** | 所有 | 精度↑5-10% |
| **混合精度** | ResNet/DenseNet | 速度↑2-3倍 |
| **模型量化** | ResNet18/34 | 体积↓4倍 |
| **知识蒸馏** | ResNet50→ResNet18 | 精度↑2-3% |

## 📋 选择检查清单

### 步骤1: 明确需求

- [ ] 数据集大小？
  - <1k: 需要迁移学习
  - 1k-10k: 小数据集
  - 10k-100k: 中等数据集
  - >100k: 大数据集

- [ ] 硬件资源？
  - 移动端: <1GB内存
  - 服务器: >8GB显存
  - 边缘设备: 低功耗

- [ ] 精度要求？
  - >90%: 高精度
  - 80-90%: 标准
  - <80%: 快速原型

- [ ] 推理速度？
  - 实时: <10ms
  - 准实时: <100ms
  - 离线: 无限制

- [ ] 部署环境？
  - 生产环境
  - 移动端
  - 嵌入式

### 步骤2: 初步筛选

根据需求选择:

**数据集小 (<10k)**:
- [ ] ResNet50 + 迁移学习
- [ ] DenseNet121 + 迁移学习
- [ ] 避免: VGG (过拟合)

**移动端部署**:
- [ ] MobileNetV2 (不在本文档，但推荐)
- [ ] ResNet18
- [ ] 避免: VGG16, ResNet50

**高精度要求**:
- [ ] ResNet101/152
- [ ] DenseNet201
- [ ] 避免: LeNet, AlexNet

**医学图像**:
- [ ] DenseNet121
- [ ] ResNet50
- [ ] 避免: AlexNet

**快速原型**:
- [ ] ResNet18
- [ ] AlexNet
- [ ] 避免: VGG16

### 步骤3: 验证选择

- [ ] 参数量是否符合预算？
- [ ] 计算量是否满足速度？
- [ ] 是否支持预训练？
- [ ] 社区支持度如何？
- [ ] 文档是否完善？
- [ ] 有无现成实现？

## 💡 实用建议

### 1. 新手入门

**推荐**: ResNet50
- 理由: 文档丰富、预训练模型多、社区支持好
- 学习曲线平缓
- 适用场景广泛

### 2. 工业项目

**推荐**: ResNet50/101
- 理由: 稳定可靠、性能均衡、易于部署
- 有成熟的优化方案
- 团队协作友好

### 3. 移动端

**推荐**: MobileNetV2/EfficientNet
- 理由: 轻量高效、量化支持好
- 虽然不在本文档，但值得了解

### 4. 研究创新

**推荐**: 理解所有架构
- 理由: 掌握设计思想
- 便于改进和创新
- 理解演进脉络

## 🎯 最终选择建议

### 如果只能选一个

**ResNet50** - 最佳平衡点
- 参数量适中 (25.6M)
- 计算量合理 (3.9G)
- 精度足够 (76.2%)
- 应用广泛
- 学习资源丰富

### 如果资源受限

**ResNet18** - 轻量快速
- 参数量少 (11.7M)
- 速度快 (2ms)
- 精度尚可 (70.8%)
- 适合移动端

### 如果追求极致

**DenseNet201** - 参数效率
- 参数量少 (20M)
- 精度高 (77.3%)
- 特征复用强
- 适合医学图像

### 如果学习优先

**LeNet-5 → AlexNet → ResNet18 → ResNet50**
- 循序渐进
- 理解演进
- 掌握核心
