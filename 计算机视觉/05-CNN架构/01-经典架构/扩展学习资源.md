### 基础阶段

#### 1. LeNet-5 (1998)

**论文**: "Gradient-Based Learning Applied to Document Recognition"  
**作者**: Yann LeCun, Léon Bottou, Yoshua Bengio, Patrick Haffner  
**链接**: http://yann.lecun.com/exdb/lenet/

**核心贡献**:
- 首次证明CNN在图像识别上的有效性
- 提出局部感受野、权值共享、池化等核心概念
- 在MNIST上达到99.2%准确率

**阅读重点**:
- [ ] 理解CNN的基本范式
- [ ] 掌握卷积和池化的数学原理
- [ ] 学习梯度下降在CNN中的应用

### 进阶扩展

#### 6. Inception (2014-2016)

**论文**: "Going Deeper with Convolutions" (Inception v1)  
**作者**: Christian Szegedy et al.

**核心思想**: 多尺度特征提取（1×1, 3×3, 5×5卷积并行）

**相关变体**:
- Inception v2/v3: 批量归一化
- Inception v4: 与ResNet结合
- Inception-ResNet: 最佳实践

---

#### 7. MobileNet (2017)

**论文**: "MobileNets: Efficient Convolutional Neural Networks for Mobile Vision Applications"  
**作者**: Andrew G. Howard et al.

**核心思想**: 深度可分离卷积

**关键参数**:
- 宽度乘子 (0-1): 控制通道数
- 分辨率乘子 (0-1): 控制输入尺寸

**应用场景**: 移动端、边缘设备

---

#### 8. EfficientNet (2019)

**论文**: "EfficientNet: Rethinking Model Scaling for Convolutional Neural Networks"  
**作者**: Mingxing Tan, Quoc V. Le

**核心思想**: 复合缩放（深度、宽度、分辨率）

**优势**: 用更少参数达到更高精度

---

#### 9. Vision Transformer (2020)

**论文**: "An Image is Worth 16x16 Words: Transformers for Image Recognition at Scale"  
**作者**: Alexey Dosovitskiy et al.

**核心思想**: 将Transformer应用于图像

**影响**: 开启ViT时代，挑战CNN地位

---

**作者**: Zhuang Liu et al.

### 2. 特征可视化

```python
def visualize_feature_maps(model, image, layer_names):
    """可视化指定层的特征图"""
    features = {}
    hooks = []
    
    def hook_fn(name):
        def hook(module, input, output):
            features[name] = output.detach()
        return hook
    
    # 注册hook
    for name, module in model.named_modules():
        if name in layer_names:
            hooks.append(module.register_forward_hook(hook_fn(name)))
    
    # 前向传播
    with torch.no_grad():
        model(image)
    
    # 移除hooks
    for hook in hooks:
        hook.remove()
    
    # 可视化
    import matplotlib.pyplot as plt
    for name, feature in features.items():
        # 取第一个样本，前64个通道
        feature = feature[0, :64]
        n_cols = 8
        n_rows = 8
        
        fig, axes = plt.subplots(n_rows, n_cols, figsize=(12, 12))
        for i in range(n_rows):
            for j in range(n_cols):
                idx = i * n_cols + j
                if idx < feature.shape[0]:
                    axes[i, j].imshow(feature[idx].cpu().numpy(), cmap='viridis')
                    axes[i, j].axis('off')
        
        plt.suptitle(f'Feature Maps: {name}')
        plt.tight_layout()
        plt.savefig(f'features_{name.replace(".", "_")}.png', dpi=150)
        plt.show()

# 使用示例

model = torch.hub.load('pytorch/vision', 'resnet50', pretrained=True)
image = torch.randn(1, 3, 224, 224)
layers = ['conv1', 'layer1.0.conv1', 'layer2.0.conv1']
visualize_feature_maps(model, image, layers)
```

**作用**:
- 理解网络学习了什么
- 对比不同层的特征
- 调试网络问题

### 3. 梯度可视化

```python
def visualize_gradients(model, image, target_class):
    """可视化梯度"""
    model.eval()
    image.requires_grad = True
    
    output = model(image)
    loss = output[0, target_class]
    loss.backward()
    
    gradients = image.grad[0].permute(1, 2, 0).cpu().numpy()
    gradients = np.abs(gradients).mean(axis=2)  # 取绝对值均值
    
    # 可视化
    plt.figure(figsize=(10, 5))
    plt.subplot(1, 2, 1)
    plt.imshow(image[0].permute(1, 2, 0).cpu().numpy())
    plt.title('Original Image')
    plt.axis('off')
    
    plt.subplot(1, 2, 2)
    plt.imshow(gradients, cmap='hot')
    plt.title('Gradient Magnitude')
    plt.axis('off')
    
    plt.tight_layout()
    plt.savefig('gradient_visualization.png', dpi=300)
    plt.show()

# 使用

model = torch.hub.load('pytorch/vision', 'resnet50', pretrained=True)
image = torch.randn(1, 3, 224, 224)
visualize_gradients(model, image, target_class=282)  # 282 = 'tabby cat'
```

**用途**:
- 理解模型关注区域
- 解释模型决策
- 调试分类错误

### 4. 混淆矩阵

```python
from sklearn.metrics import confusion_matrix
import seaborn as sns

def plot_confusion_matrix(model, dataloader, classes):
    """绘制混淆矩阵"""
    model.eval()
    all_preds = []
    all_labels = []
    
    with torch.no_grad():
        for inputs, labels in dataloader:
            outputs = model(inputs)
            _, preds = torch.max(outputs, 1)
            all_preds.extend(preds.cpu().numpy())
            all_labels.extend(labels.cpu().numpy())
    
    cm = confusion_matrix(all_labels, all_preds)
    
    plt.figure(figsize=(10, 8))
    sns.heatmap(cm, annot=True, fmt='d', cmap='Blues',
                xticklabels=classes, yticklabels=classes)
    plt.title('Confusion Matrix')
    plt.xlabel('Predicted')
    plt.ylabel('True')
    plt.tight_layout()
    plt.savefig('confusion_matrix.png', dpi=300)
    plt.show()
    
    return cm

# 使用

classes = ['airplane', 'automobile', 'bird', 'cat', 'deer',
           'dog', 'frog', 'horse', 'ship', 'truck']
cm = plot_confusion_matrix(model, val_loader, classes)
```

**分析**:
- 识别易混淆类别
- 发现模型弱点
- 指导数据增强

```bash
    print(f"是否包含NaN: {torch.isnan(output).any()}")
```

### 3. 性能优化

```bash
# 自动混合精度

from torch.cuda.amp import autocast, GradScaler

scaler = GradScaler()
for inputs, labels in train_loader:
    with autocast():
        outputs = model(inputs)
        loss = criterion(outputs, labels)
    
    scaler.scale(loss).backward()
    scaler.step(optimizer)
    scaler.update()
```
