# 计算机视觉学习资源库

> 从入门到精通的系统化计算机视觉学习资料整理

## 📁 目录结构

```
计算机视觉/
├── 01-基础概念/              # 数学基础、编程基础、图像基础
├── 02-图像处理基础/          # 预处理、滤波、边缘检测
├── 03-传统计算机视觉/        # 特征提取、分割、匹配
├── 04-深度学习基础/          # 神经网络、训练技巧、优化算法
├── 05-CNN架构/              # 经典网络、现代架构、Transformer
├── 06-目标检测/              # R-CNN、YOLO、SSD等
├── 07-图像分割/              # 语义分割、实例分割
├── 08-姿态估计/              # 人体关键点检测
├── 09-视频分析/              # 目标跟踪、动作识别
├── 10-3D视觉/                # 立体视觉、点云处理
├── 11-实战项目/              # 实际应用案例
├── 12-进阶主题/              # 前沿技术、高级算法
├── 练习题/                   # 习题集、代码练习
├── 参考资料/                 # 论文、书籍、教程链接
└── 工具软件/                 # 常用工具、框架、环境配置
```

## 📖 学习计划

详细的学习路线请查看：[学习计划_从入门到精通.md](学习计划_从入门到精通.md)

## 🎯 学习阶段

### 阶段一：基础入门（1-2个月）
- 数学基础 + Python编程 + 图像基础

### 阶段二：传统CV（2-3个月）
- 图像处理 + 特征提取 + 经典算法

### 阶段三：深度学习（3-4个月）
- CNN原理 + 经典架构 + 框架使用

### 阶段四：核心应用（2-3个月）
- 目标检测 + 图像分割 + 姿态估计

### 阶段五：进阶实战（1-2个月）
- 高级主题 + 工程部署 + 实战项目

## 🚀 快速开始

1. **查看学习计划**：
   ```bash
   cd 计算机视觉
   cat 学习计划_从入门到精通.md
   ```

2. **按目录顺序学习**：
   - 从 `01-基础概念` 开始
   - 按数字顺序推进
   - 每个阶段完成后进入下一阶段

3. **实践建议**：
   - 理论学习 + 代码实践同步进行
   - 每学完一个模块做对应练习
   - 定期复盘和总结

## 🛠️ 环境要求

- Python 3.8+
- PyTorch 1.9+ 或 TensorFlow 2.6+
- OpenCV
- NumPy, Matplotlib, Pandas
- Jupyter Notebook

## 💡 学习建议

1. **循序渐进**：不要跳过基础直接学高级内容
2. **动手实践**：每个概念都要写代码实现
3. **项目驱动**：用实际问题驱动学习
4. **社区交流**：参与GitHub、Kaggle等社区
5. **持续学习**：关注前沿技术发展
