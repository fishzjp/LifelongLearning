## 🎯 一句话总结

| 概念 | 一句话理解 |
|------|-----------|
| **神经元** | 加权求和 + 激活函数 |
| **前向传播** | 输入 → 计算 → 输出 |
| **反向传播** | 从后向前计算梯度 |
| **梯度下降** | 沿负梯度方向更新参数 |
| **损失函数** | 衡量预测有多错 |
| **正则化** | 防止过拟合的技术 |
| **Dropout** | 随机关闭神经元 |

---

## 🔧 常用公式

### 前向传播

```
z = W·x + b
a = activation(z)
```

### 反向传播

```
∂L/∂W = ∂L/∂a × ∂a/∂z × ∂z/∂W
```

### 梯度下降

```
W = W - η × ∂L/∂W
```

### Softmax

```
softmax(z)_i = exp(z_i) / Σexp(z_j)
```

---

## 📊 激活函数对比

| 函数 | 公式 | 输出范围 | 适用场景 |
|------|------|---------|---------|
| **ReLU** | max(0, x) | [0, ∞) | 隐藏层（默认） |
| **Sigmoid** | 1/(1+e^-x) | (0, 1) | 二分类输出 |
| **Softmax** | exp(x)/sum | (0, 1) | 多分类输出 |
| **Tanh** | tanh(x) | (-1, 1) | 较少使用 |

---

## 🎲 损失函数选择

### 回归任务

- **MSE**: 标准选择，对异常值敏感
- **MAE**: 鲁棒，对异常值不敏感
- **Huber**: 两者结合

### 分类任务

- **BCE**: 二分类
- **交叉熵**: 多分类
- **Focal Loss**: 类别不平衡

## 🛡️ 正则化技术

| 方法 | 作用 | 参数 |
|------|------|------|
| **L2** | 权重衰减 | λ=0.01 |
| **L1** | 特征选择 | λ=0.01 |
| **Dropout** | 防共适应 | p=0.2-0.5 |
| **早停** | 防过拟合 | patience=10 |

## 🚀 优化器选择

### 推荐顺序

1. **Adam** (默认，最常用)
2. **SGD + Momentum** (需要精细调参)
3. **RMSprop** (RNN常用)

### 学习率

- **Adam**: 3e-4 (0.0003)
- **SGD**: 0.01-0.1
- **搜索范围**: 1e-5 到 1e-1

## 📦 批次大小

| 大小 | 特点 | 适用 |
|------|------|------|
| **小 (1-32)** | 噪声大，泛化好 | 小数据 |
| **中 (32-256)** | 平衡 | 默认 |
| **大 (256+)** | 快，需内存 | 大数据 |

## 🎨 数据预处理

### 标准化

```python
X = (X - mean) / std
```

### 归一化

```python
X = (X - min) / (max - min)
```

### 数据增强

- 翻转、旋转、平移
- 亮度、对比度
- 添加噪声

## 🐛 调试指南

### 损失不下降

- 学习率太小

- 网络结构问题

### 损失震荡

- 学习率太大
- 批次太小

- 过拟合
- 需要正则化

### 梯度爆炸

- 梯度裁剪
- 降低学习率
- 检查初始化

```
∂L/∂x = ∂L/∂a × ∂a/∂b × ∂b/∂x
```
