## 📋 快速参考卡片

### 线性代数

```bash
# 矩阵运算

A + B  # 对应位置相加
A - B  # 对应位置相减
A @ B  # 矩阵乘法
A.T    # 转置
np.linalg.inv(A)  # 逆矩阵
np.linalg.eig(A)  # 特征值/向量

# 图像表示

灰度图像: (H, W)
彩色图像: (H, W, 3)
```

### 微积分

```bash
# 导数定义

f'(x) = lim(h→0) [f(x+h) - f(x)] / h

# 链式法则
# y = f(g(x))  =>  dy/dx = f'(g(x)) × g'(x)

# 梯度下降

w_new = w_old - learning_rate × ∇L(w)
```

### 概率统计

```bash
# 贝叶斯定理

P(A|B) = P(B|A) × P(A) / P(B)

# Softmax

softmax(z)_i = exp(z_i) / Σ_j exp(z_j)

# 正态分布

N(x|μ, σ²) = (1/(σ√(2π))) × exp(-(x-μ)²/(2σ²))
```
