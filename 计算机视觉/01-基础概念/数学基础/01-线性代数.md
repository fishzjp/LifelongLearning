## 1.1 什么是矩阵？

### 基本概念

**矩阵（Matrix）** 就是一个矩形的数字表格，就像Excel表格一样。

```python
import numpy as np

# 创建一个简单的2x3矩阵（2行3列）

matrix = np.array([
    [1, 2, 3],  # 第1行
    [4, 5, 6]   # 第2行
])

print("矩阵的样子：")
print(matrix)
print(f"\n矩阵的形状：{matrix.shape}")  # (2, 3) 表示2行3列
```

**矩阵在计算机视觉中的意义：**
- **灰度图像**：一个矩阵，每个数字代表一个像素的亮度（0-255）
- **彩色图像**：三个矩阵叠加，分别代表红、绿、蓝三个通道
- **3D图像/视频**：更多维度的矩阵

### 矩阵的基本运算

```bash
# 创建两个2x2矩阵

A = np.array([[1, 2],
              [3, 4]])
B = np.array([[5, 6],
              [7, 8]])

print("矩阵A：")
print(A)
print("\n矩阵B：")
print(B)

# 1. 矩阵加法（对应位置相加）

print("\n矩阵加法 A + B：")
print(A + B)
# 结果：[[6, 8], [10, 12]]

# 2. 矩阵减法（对应位置相减）

print("\n矩阵减法 A - B：")
print(A - B)
# 结果：[[-4, -4], [-4, -4]]

# 3. 矩阵乘法（不是对应位置相乘！）

print("\n矩阵乘法 A @ B：")
print(A @ B)
# 结果：[[19, 22], [43, 50]]
# 计算规则：第i行 × 第j列 的点积

```

**矩阵乘法的详细解释：**
```
A @ B 的计算过程：
A的第1行 [1, 2] 乘以 B的第1列 [5, 7]：
1×5 + 2×7 = 5 + 14 = 19

A的第1行 [1, 2] 乘以 B的第2列 [6, 8]：
1×6 + 2×8 = 6 + 16 = 22

A的第2行 [3, 4] 乘以 B的第1列 [5, 7]：
3×5 + 4×7 = 15 + 28 = 43

A的第2行 [3, 4] 乘以 B的第2列 [6, 8]：
3×6 + 4×8 = 18 + 32 = 50
```

## 1.2 图像就是矩阵

### 灰度图像示例

```python
import matplotlib.pyplot as plt

# 创建一个简单的5x5灰度图像（0=黑色，255=白色）
# 这是一个"X"形状

gray_image = np.array([
    [255,   0,   0,   0, 255],
    [  0, 255,   0, 255,   0],
    [  0,   0, 255,   0,   0],
    [  0, 255,   0, 255,   0],
    [255,   0,   0,   0, 255]
])

print("灰度图像矩阵：")
print(gray_image)

# 显示图像

plt.figure(figsize=(8, 4))

# 左边显示矩阵数值

plt.subplot(1, 2, 1)
plt.text(0.5, 0.5, str(gray_image),
         ha='center', va='center', fontfamily='monospace', fontsize=8)
plt.axis('off')
plt.title('矩阵数值')

# 右边显示图像

plt.subplot(1, 2, 2)
plt.imshow(gray_image, cmap='gray')
plt.title('实际图像')
plt.axis('off')

plt.show()
```

**解释：**
- 矩阵中的每个数字代表一个**像素**（图像的基本单位）
- 0 = 黑色，255 = 白色，中间值 = 灰色
- 这个5x5的矩阵就是一张5像素×5像素的小图片

### 彩色图像示例

```bash
# 创建一个3x3的彩色图像
# 每个像素有3个值：[红, 绿, 蓝]

color_image = np.array([
    [[255,   0,   0], [  0, 255,   0], [  0,   0, 255]],  # 红、绿、蓝
    [[255, 255,   0], [255,   0, 255], [  0, 255, 255]],  # 黄、紫、青
    [[  0,   0,   0], [128, 128, 128], [255, 255, 255]]   # 黑、灰、白
])

print("彩色图像形状：", color_image.shape)  # (3, 3, 3) 表示3行3列3个通道

# 显示

plt.figure(figsize=(6, 6))
plt.imshow(color_image)
plt.title('3x3彩色图像')
plt.axis('off')
plt.show()

# 查看特定像素

print(f"\n左上角像素 [0,0] 的RGB值：{color_image[0, 0]}")
print(f"中间像素 [1,1] 的RGB值：{color_image[1, 1]}")
```

## 1.3 特征值与特征向量

### 为什么要学这个？

特征值和特征向量在**图像压缩**、**人脸识别**（PCA算法）中非常重要。

### 直观理解

想象一个拉伸变换：
- 有些方向在变换中**方向不变**，只是长度变化
- 这些**不变的方向**就是特征向量
- **长度变化的比例**就是特征值

```bash
# 创建一个2x2矩阵

A = np.array([[2, 1],
              [1, 2]])

# 计算特征值和特征向量

eigenvalues, eigenvectors = np.linalg.eig(A)

print("矩阵A：")
print(A)
print(f"\n特征值：{eigenvalues}")
print("特征向量：")
print(eigenvectors)

# 验证：A × 特征向量 = 特征值 × 特征向量

print("\n验证：")
for i in range(len(eigenvalues)):
    v = eigenvectors[:, i]  # 第i个特征向量
    lambda_v = eigenvalues[i] * v  # 特征值 × 特征向量
    Av = A @ v  # A × 特征向量

    print(f"特征值 {eigenvalues[i]:.2f}:")
    print(f"  λ × v = {lambda_v}")
    print(f"  A × v = {Av}")
    print(f"  相等吗？ {np.allclose(lambda_v, Av)}")
```

**实际应用：**
- **主成分分析（PCA）**：用特征向量找到数据的主要变化方向
- **图像压缩**：保留大的特征值，忽略小的特征值
- **人脸识别**：找到"人脸"的主要特征
