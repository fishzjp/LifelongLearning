## 线性代数

### 1.1 什么是矩阵？

#### 基本概念
**矩阵（Matrix）** 就是一个矩形的数字表格，就像Excel表格一样。

```python
import numpy as np

# 创建一个简单的2x3矩阵（2行3列）
matrix = np.array([
    [1, 2, 3],  # 第1行
    [4, 5, 6]   # 第2行
])

print("矩阵的样子：")
print(matrix)
print(f"\n矩阵的形状：{matrix.shape}")  # (2, 3) 表示2行3列
```

**矩阵在计算机视觉中的意义：**
- **灰度图像**：一个矩阵，每个数字代表一个像素的亮度（0-255）
- **彩色图像**：三个矩阵叠加，分别代表红、绿、蓝三个通道
- **3D图像/视频**：更多维度的矩阵

#### 矩阵的基本运算

```python
# 创建两个2x2矩阵
A = np.array([[1, 2],
              [3, 4]])
B = np.array([[5, 6],
              [7, 8]])

print("矩阵A：")
print(A)
print("\n矩阵B：")
print(B)

# 1. 矩阵加法（对应位置相加）
print("\n矩阵加法 A + B：")
print(A + B)
# 结果：[[6, 8], [10, 12]]

# 2. 矩阵减法（对应位置相减）
print("\n矩阵减法 A - B：")
print(A - B)
# 结果：[[-4, -4], [-4, -4]]

# 3. 矩阵乘法（不是对应位置相乘！）
print("\n矩阵乘法 A @ B：")
print(A @ B)
# 结果：[[19, 22], [43, 50]]
# 计算规则：第i行 × 第j列 的点积
```

**矩阵乘法的详细解释：**
```
A @ B 的计算过程：
A的第1行 [1, 2] 乘以 B的第1列 [5, 7]：
1×5 + 2×7 = 5 + 14 = 19

A的第1行 [1, 2] 乘以 B的第2列 [6, 8]：
1×6 + 2×8 = 6 + 16 = 22

A的第2行 [3, 4] 乘以 B的第1列 [5, 7]：
3×5 + 4×7 = 15 + 28 = 43

A的第2行 [3, 4] 乘以 B的第2列 [6, 8]：
3×6 + 4×8 = 18 + 32 = 50
```

### 1.3 特征值与特征向量

#### 为什么要学这个？
特征值和特征向量在**图像压缩**、**人脸识别**（PCA算法）中非常重要。

#### 直观理解
想象一个拉伸变换：
- 有些方向在变换中**方向不变**，只是长度变化
- 这些**不变的方向**就是特征向量
- **长度变化的比例**就是特征值

```python
# 创建一个2x2矩阵
A = np.array([[2, 1],
              [1, 2]])

# 计算特征值和特征向量
eigenvalues, eigenvectors = np.linalg.eig(A)

print("矩阵A：")
print(A)
print(f"\n特征值：{eigenvalues}")
print("特征向量：")
print(eigenvectors)

# 验证：A × 特征向量 = 特征值 × 特征向量
print("\n验证：")
for i in range(len(eigenvalues)):
    v = eigenvectors[:, i]  # 第i个特征向量
    lambda_v = eigenvalues[i] * v  # 特征值 × 特征向量
    Av = A @ v  # A × 特征向量

    print(f"特征值 {eigenvalues[i]:.2f}:")
    print(f"  λ × v = {lambda_v}")
    print(f"  A × v = {Av}")
    print(f"  相等吗？ {np.allclose(lambda_v, Av)}")
```

**实际应用：**
- **主成分分析（PCA）**：用特征向量找到数据的主要变化方向
- **图像压缩**：保留大的特征值，忽略小的特征值
- **人脸识别**：找到"人脸"的主要特征

## 微积分

### 2.1 导数和梯度

#### 什么是导数？
导数描述函数在某一点的**变化率**，也就是**斜率**。

```python
# 定义一个简单的函数：f(x) = x²
def f(x):
    return x**2

# 导数：f'(x) = 2x
def df(x):
    return 2*x

# 可视化
x = np.linspace(-3, 3, 100)
y = f(x)

plt.figure(figsize=(10, 6))
plt.plot(x, y, label='f(x) = x²', linewidth=2)

# 在x=1处画切线
x0 = 1
y0 = f(x0)
slope = df(x0)  # 斜率 = 2

# 切线方程：y - y0 = slope * (x - x0)
x_tangent = np.linspace(0, 2, 50)
y_tangent = slope * (x_tangent - x0) + y0

plt.plot(x_tangent, y_tangent, 'r--', label=f'x={x0}处的切线，斜率={slope}')
plt.scatter([x0], [y0], color='red', s=100, zorder=5)
plt.axvline(x0, color='gray', linestyle=':', alpha=0.5)
plt.axhline(y0, color='gray', linestyle=':', alpha=0.5)

plt.xlabel('x')
plt.ylabel('f(x)')
plt.title('函数及其切线')
plt.legend()
plt.grid(True, alpha=0.3)
plt.show()

print(f"在x={x0}处：")
print(f"  函数值 f({x0}) = {y0}")
print(f"  导数值 f'({x0}) = {slope}")
print(f"  这意味着：在x={x0}附近，x每增加1，f(x)大约增加{slope}")
```

#### 梯度：多维导数
对于多变量函数，梯度就是各个方向导数组成的向量。

```python
# 二元函数：f(x, y) = x² + y²
def f(x, y):
    return x**2 + y**2

# 梯度：∇f = [∂f/∂x, ∂f/∂y] = [2x, 2y]
def gradient(x, y):
    return np.array([2*x, 2*y])

# 可视化
fig = plt.figure(figsize=(12, 5))

# 3D曲面
ax1 = fig.add_subplot(121, projection='3d')
x = np.linspace(-2, 2, 20)
y = np.linspace(-2, 2, 20)
X, Y = np.meshgrid(x, y)
Z = f(X, Y)

ax1.plot_surface(X, Y, Z, cmap='viridis', alpha=0.8)
ax1.set_xlabel('x')
ax1.set_ylabel('y')
ax1.set_zlabel('f(x,y)')
ax1.set_title('f(x,y) = x² + y²')

# 梯度场
ax2 = fig.add_subplot(122)
x = np.linspace(-2, 2, 10)
y = np.linspace(-2, 2, 10)
X, Y = np.meshgrid(x, y)

# 计算梯度
grad_x = 2*X
grad_y = 2*Y

ax2.contour(X, Y, Z, levels=20, cmap='viridis')
ax2.quiver(X, Y, grad_x, grad_y, color='red', alpha=0.6)
ax2.set_xlabel('x')
ax2.set_ylabel('y')
ax2.set_title('梯度场（红色箭头）')
ax2.set_aspect('equal')

plt.tight_layout()
plt.show()

# 示例：在点(1,1)的梯度
point = (1, 1)
grad = gradient(point[0], point[1])
print(f"在点{point}处：")
print(f"  梯度 = {grad}")
print(f"  梯度方向指向函数值增长最快的方向")
print(f"  梯度大小 = {np.linalg.norm(grad):.2f} 表示变化的快慢")
```

### 2.2 链式法则

#### 为什么要学链式法则？
在神经网络中，我们需要计算**损失函数对权重的导数**，但损失函数是通过多层网络计算得到的。链式法则帮助我们"传递"导数。

#### 直观理解
想象一个复合函数：y = f(g(x))
- 先计算 g(x) = u
- 再计算 f(u) = y
- 那么 dy/dx = df/du × du/dx

```python
# 例子：f(g(x)) = (2x + 1)²
def g(x):
    return 2*x + 1

def f(u):
    return u**2

def composite(x):
    return f(g(x))

# 链式法则计算导数
def composite_derivative(x):
    # f'(u) = 2u
    # g'(x) = 2
    # f'(g(x)) × g'(x) = 2(2x+1) × 2 = 4(2x+1)
    return 4*(2*x + 1)

# 数值验证
x = 2
h = 0.0001
numerical = (composite(x + h) - composite(x)) / h
analytical = composite_derivative(x)

print(f"函数：f(g(x)) = (2x + 1)²")
print(f"在x={x}处：")
print(f"  解析导数：{analytical}")
print(f"  数值导数：{numerical:.6f}")
print(f"  误差：{abs(analytical - numerical):.10f}")
```

#### 神经网络中的链式法则
```python
# 模拟一个简单的神经网络
def sigmoid(z):
    """Sigmoid激活函数"""
    return 1 / (1 + np.exp(-z))

def sigmoid_derivative(z):
    """Sigmoid的导数"""
    s = sigmoid(z)
    return s * (1 - s)

# 网络：y = sigmoid(w*x + b)
def network(x, w, b):
    z = w * x + b
    y = sigmoid(z)
    return y

# 损失函数：L = (y - target)²
def loss(y, target):
    return (y - target)**2

# 计算损失对w的导数（使用链式法则）
def compute_gradient(x, w, b, target):
    # 前向传播
    z = w * x + b
    y = sigmoid(z)
    L = loss(y, target)

    # 反向传播（链式法则）
    dL_dy = 2 * (y - target)          # ∂L/∂y
    dy_dz = sigmoid_derivative(z)     # ∂y/∂z
    dz_dw = x                         # ∂z/∂w
    dz_db = 1                         # ∂z/∂b

    # 链式法则：∂L/∂w = ∂L/∂y × ∂y/∂z × ∂z/∂w
    dL_dw = dL_dy * dy_dz * dz_dw
    dL_db = dL_dy * dy_dz * dz_db

    return dL_dw, dL_db, L

# 示例
x, w, b, target = 2.0, 0.5, 1.0, 1.0
dL_dw, dL_db, L = compute_gradient(x, w, b, target)

print("简单神经网络：y = sigmoid(w*x + b)")
print(f"输入：x={x}, 权重：w={w}, 偏置：b={b}, 目标：{target}")
print(f"损失：{L:.6f}")
print(f"损失对w的梯度：{dL_dw:.6f}")
print(f"损失对b的梯度：{dL_db:.6f}")
print("\n梯度告诉我们：")
print(f"  如果w增加一点，损失大约变化{dL_dw:.6f}")
print(f"  如果b增加一点，损失大约变化{dL_db:.6f}")
```

### 2.3 梯度下降

#### 什么是梯度下降？
梯度下降是一种**优化算法**，用于找到使函数值最小的参数。

**核心思想：**
- 梯度指向函数值**增长最快**的方向
- 所以，**负梯度**指向函数值**下降最快**的方向
- 沿着负梯度方向逐步调整参数

```python
def gradient_descent_demo():
    """梯度下降可视化"""

    # 目标函数：f(x) = x² + 2x + 1
    def f(x):
        return x**2 + 2*x + 1

    def df(x):
        return 2*x + 2

    # 梯度下降
    x = 5.0  # 初始点
    learning_rate = 0.1  # 学习率（步长）
    n_steps = 10

    trajectory = [x]
    print("梯度下降过程：")
    print(f"初始点：x = {x}, f(x) = {f(x):.4f}")

    for i in range(n_steps):
        grad = df(x)  # 计算梯度
        x = x - learning_rate * grad  # 沿负梯度方向更新
        trajectory.append(x)
        print(f"步骤{i+1}: x = {x:.4f}, f(x) = {f(x):.4f}, 梯度 = {grad:.4f}")

    # 可视化
    x_range = np.linspace(-6, 6, 100)
    y_range = f(x_range)

    plt.figure(figsize=(12, 5))

    # 左图：函数曲线和下降路径
    plt.subplot(1, 2, 1)
    plt.plot(x_range, y_range, label='f(x) = x² + 2x + 1')
    trajectory_y = [f(x) for x in trajectory]
    plt.plot(trajectory, trajectory_y, 'ro-', label='下降路径')
    plt.scatter(trajectory, trajectory_y, s=50, c='red')

    # 标注每一步
    for i, (x_val, y_val) in enumerate(zip(trajectory, trajectory_y)):
        plt.annotate(f'{i}', (x_val, y_val), xytext=(5, 5),
                    textcoords='offset points', fontsize=8)

    plt.xlabel('x')
    plt.ylabel('f(x)')
    plt.title('梯度下降：寻找最小值')
    plt.legend()
    plt.grid(True, alpha=0.3)

    # 右图：损失下降过程
    plt.subplot(1, 2, 2)
    plt.plot(range(len(trajectory_y)), trajectory_y, 'o-')
    plt.xlabel('迭代次数')
    plt.ylabel('函数值')
    plt.title('损失下降曲线')
    plt.grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

gradient_descent_demo()
```

**关键参数：**
- **学习率（步长）**：太大→震荡不收敛，太小→收敛太慢
- **初始点**：可能陷入局部最优（但二次函数只有一个最优）

### 3.2 贝叶斯定理：从已知推断未知

#### 为什么要学贝叶斯？
贝叶斯定理是**机器学习分类器**的理论基础，特别是朴素贝叶斯分类器。在计算机视觉中，它帮助我们：
- **图像分类**：根据像素特征判断图片内容
- **目标检测**：从局部特征推断目标身份
- **噪声处理**：从含噪图像恢复原始信息

#### 直观理解：贝叶斯思维的本质

想象你在玩一个猜谜游戏：
- **先验概率**：游戏开始前的猜测（基于常识）
- **新证据**：游戏过程中获得的线索
- **后验概率**：结合线索后的更新猜测

**核心思想：用新证据更新你的信念**

```
贝叶斯公式：
                似然 × 先验
    后验概率 = ——————————————
                   证据

P(A|B) = P(B|A) × P(A) / P(B)

其中：
- P(A)：先验概率 - 事件A发生的初始概率
- P(B|A)：似然 - 如果A发生，观察到B的可能性
- P(B)：证据 - 观察到B的总概率（归一化因子）
- P(A|B)：后验概率 - 观察到B后，事件A发生的概率
```

#### 为什么贝叶斯如此强大？

**案例：罕见病检测的陷阱**

假设某种罕见病发病率仅1%，检测准确率99%：
- 你检测结果为阳性，真的生病了吗？

```python
def bayes_medical_deep_dive():
    """深入理解贝叶斯：罕见病检测"""

    # ===== 先验知识 =====
    P_disease = 0.01      # 1%的人患病（罕见！）
    P_healthy = 0.99      # 99%的人健康

    # ===== 检测性能 =====
    P_positive_given_disease = 0.99    # 真患病时阳性（99%敏感度）
    P_positive_given_healthy = 0.01    # 健康时阳性（1%误报率）

    print("="*50)
    print("贝叶斯分析：罕见病检测")
    print("="*50)
```

```python
def normal_distribution_demo():

    x = np.linspace(-4, 4, 100)

    x_2sig = x[(x >= -2) & (x <= 2)]
    x_3sig = x[(x >= -3) & (x <= 3)]

                     alpha=0.3, color='green', label='68%')
```

```python
def softmax_demo():
    """Softmax函数详解"""

    def softmax(logits):
        """将logits转换为概率分布"""
        # 减去最大值提高数值稳定性（防止溢出）
        exp_logits = np.exp(logits - np.max(logits))
        return exp_logits / np.sum(exp_logits)

    # 示例：3类分类问题
    logits = np.array([2.0, 1.0, 0.1])
    probabilities = softmax(logits)

    print("Softmax函数演示：")
    print(f"原始logits: {logits}")
    print(f"Softmax概率: {probabilities}")
    print(f"概率和: {np.sum(probabilities):.6f} (必须等于1)")
```

```python
提示：
```

```python
- 数值梯度：(f(x+h, y) - f(x, y)) / h
"""

def gradient_practice():
    # TODO: 你的代码在这里

    # 1. 定义函数
    def f(x, y):
        return x**2 + 2*y**2 + x*y

    # 2. 解析梯度
    def gradient(x, y):
        df_dx = 2*x + y
        df_dy = 4*y + x
        return np.array([df_dx, df_dy])

    # 3. 在点(1, 2)计算
    point = (1, 2)
    grad = gradient(point[0], point[1])

    print(f"函数：f(x, y) = x² + 2y² + xy")
    print(f"在点{point}处的解析梯度：{grad}")

    # 4. 数值验证
    h = 1e-5
    f_point = f(point[0], point[1])

    # x方向数值梯度
    df_dx_numerical = (f(point[0] + h, point[1]) - f_point) / h

    # y方向数值梯度
    df_dy_numerical = (f(point[0], point[1] + h) - f_point) / h

    numerical_grad = np.array([df_dx_numerical, df_dy_numerical])

    print(f"数值梯度：{numerical_grad}")
    print(f"误差：{np.abs(grad - numerical_grad)}")
    print(f"验证通过：{np.allclose(grad, numerical_grad)}")
```

```python
    decision2 = "猫" if P_cat_given_not_upright > P_dog_given_not_upright else "狗"
    confidence2 = max(P_cat_given_not_upright, P_dog_given_not_upright)
    print(f"决策：{decision2}，置信度：{confidence2:.1%}")

    # 可视化对比
    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(12, 5))
```

### 练习3扩展：多特征贝叶斯分类器
```python
"""
练习3扩展：多特征贝叶斯分类器

目标：理解朴素贝叶斯的多特征扩展

任务：
现在我们有两个特征：
- 特征1：竖直耳朵（是/否）
- 特征2：瞳孔圆形（是/否）

已知信息：
- 先验：P(猫)=0.4, P(狗)=0.6
- 特征1的似然：P(竖直|猫)=0.7, P(竖直|狗)=0.3
- 特征2的似然：P(圆形|猫)=0.8, P(圆形|狗)=0.4

问题：
1. 假设两个特征独立，计算P(猫|竖直,圆形)和P(狗|竖直,圆形)
2. 比较单特征 vs 多特征的分类效果
3. 为什么需要"朴素"假设（特征独立）？
"""

def bayes_practice_multi_feature():
    # TODO: 你的代码在这里

    # 先验概率
    P_cat = 0.4
    P_dog = 0.6

    # 特征1：竖直耳朵
    P_upright_given_cat = 0.7
    P_upright_given_dog = 0.3

    # 特征2：瞳孔圆形
    P_round_given_cat = 0.8
    P_round_given_dog = 0.4

    print("="*60)
    print("多特征贝叶斯分类器")
    print("="*60)

    # 观测：两个特征都为真
    print("\n观测：竖直耳朵 + 瞳孔圆形")

    # 朴素贝叶斯：假设特征独立
    # P(猫|竖直,圆形) ∝ P(竖直|猫) × P(圆形|猫) × P(猫)

    # 计算未归一化的后验
    cat_score = P_upright_given_cat * P_round_given_cat * P_cat
    dog_score = P_upright_given_dog * P_round_given_dog * P_dog

    # 归一化
    total = cat_score + dog_score
    P_cat_given_features = cat_score / total
    P_dog_given_features = dog_score / total

    print(f"\n【朴素贝叶斯计算】")
    print(f"  P(猫|特征) ∝ {P_upright_given_cat:.2f} × {P_round_given_cat:.2f} × {P_cat:.2f} = {cat_score:.4f}")
    print(f"  P(狗|特征) ∝ {P_upright_given_dog:.2f} × {P_round_given_dog:.2f} × {P_dog:.2f} = {dog_score:.4f}")
    print(f"\n归一化后：")
    print(f"  P(猫|特征) = {P_cat_given_features:.3f}")
    print(f"  P(狗|特征) = {P_dog_given_features:.3f}")

    # 对比单特征
    print(f"\n【对比：单特征 vs 多特征】")

    # 单特征1：仅竖直耳朵
    P_upright = (P_upright_given_cat * P_cat + P_upright_given_dog * P_dog)
    P_cat_given_upright = (P_upright_given_cat * P_cat) / P_upright

    # 单特征2：仅瞳孔圆形
    P_round = (P_round_given_cat * P_cat + P_round_given_dog * P_dog)
    P_cat_given_round = (P_round_given_cat * P_cat) / P_round

    print(f"  仅竖直耳朵：P(猫) = {P_cat_given_upright:.3f}")
    print(f"  仅瞳孔圆形：P(猫) = {P_cat_given_round:.3f}")
    print(f"  两个特征：P(猫) = {P_cat_given_features:.3f}")

    print(f"\n【结论】")
    print(f"  多特征提供了更多信息，分类更自信！")
    print(f"  朴素假设简化计算，但现实中特征可能相关")

    # 可视化
    fig, ax = plt.subplots(figsize=(10, 6))

    methods = ['仅竖直耳朵', '仅瞳孔圆形', '两个特征']
    cat_probs = [P_cat_given_upright, P_cat_given_round, P_cat_given_features]
    dog_probs = [1-p for p in cat_probs]

    x = np.arange(len(methods))
    width = 0.35

    ax.bar(x - width/2, cat_probs, width, label='猫', color='orange', alpha=0.8)
    ax.bar(x + width/2, dog_probs, width, label='狗', color='blue', alpha=0.8)

    ax.set_xlabel('特征组合')
    ax.set_ylabel('分类概率')
    ax.set_title('不同特征组合的分类效果对比')
    ax.set_xticks(x)
    ax.set_xticklabels(methods)
    ax.legend()
    ax.grid(True, alpha=0.3, axis='y')
    ax.set_ylim(0, 1)

    # 标注数值
    for i, (cat_p, dog_p) in enumerate(zip(cat_probs, dog_probs)):
        ax.text(i - width/2, cat_p + 0.02, f'{cat_p:.2f}', ha='center', va='bottom')
        ax.text(i + width/2, dog_p + 0.02, f'{dog_p:.2f}', ha='center', va='bottom')

    plt.tight_layout()
    plt.show()

# 运行练习
bayes_practice_multi_feature()
```

### 练习4：Softmax实现
```python
"""
练习4：Softmax实现

目标：手动实现Softmax函数

任务：
1. 实现Softmax函数
2. 测试不同输入，观察输出
3. 验证输出的概率和为1
4. 探索温度参数对分布的影响

提示：
softmax(x) = exp(x) / sum(exp(x))
温度参数：softmax(x/T) = exp(x/T) / sum(exp(x/T))
"""

def softmax_practice():
    # TODO: 你的代码在这里

    def softmax(x, temperature=1.0):
        """Softmax函数，支持温度参数"""
        x = x / temperature  # 温度调整
        exp_x = np.exp(x - np.max(x))  # 数值稳定性
        return exp_x / np.sum(exp_x)

    # 测试数据
    logits = np.array([2.0, 1.0, 0.1, 3.0])

    print("Softmax练习：")
    print(f"原始logits: {logits}")

    # 不同温度下的结果
    temperatures = [0.5, 1.0, 2.0, 5.0]

    fig, axes = plt.subplots(2, 2, figsize=(12, 10))
    axes = axes.flatten()

    for i, T in enumerate(temperatures):
        probs = softmax(logits, T)

        # 绘制
        axes[i].bar(range(len(logits)), probs, color='lightblue')
        axes[i].set_title(f'温度 T={T}')
        axes[i].set_xlabel('类别')
        axes[i].set_ylabel('概率')
        axes[i].set_ylim(0, 1)
        axes[i].set_xticks(range(len(logits)))

        # 标注数值
        for j, prob in enumerate(probs):
            axes[i].text(j, prob + 0.02, f'{prob:.3f}',
                        ha='center', va='bottom', fontsize=9)

        print(f"\n温度 {T}: {probs}")
        print(f"概率和: {np.sum(probs):.6f}")

    plt.tight_layout()
    plt.show()

    print("\n温度参数的作用：")
    print("- T < 1: 分布更集中（更自信）")
    print("- T = 1: 标准Softmax")
    print("- T > 1: 分布更均匀（更不确定）")

# 运行练习
softmax_practice()
```
