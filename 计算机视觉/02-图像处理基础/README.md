## 📊 技术对比表

| 技术 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| 均值滤波 | 快速、简单 | 模糊边缘 | 去除高斯噪声 |
| 高斯滤波 | 自然平滑 | 计算稍慢 | 保留细节去噪 |
| 中值滤波 | 去椒盐噪声 | 对高斯噪声弱 | 椒盐噪声去除 |
| 双边滤波 | 保边去噪 | 计算复杂 | 高质量去噪 |
| Harris角点 | 稳定、旋转不变 | 尺度敏感 | 特征匹配 |
| Shi-Tomasi | 角点质量好 | 计算稍慢 | 稀疏特征 |
| FAST | 极快 | 无方向 | 实时检测 |
| Canny边缘 | 精确、单像素 | 参数敏感 | 精确边缘 |
| Sobel边缘 | 快速、简单 | 边缘较粗 | 快速检测 |

## 🚀 常见问题解答

**Q: 图像读取后显示异常？**
A: 检查数据类型和范围，使用`plt.imshow(img, vmin=0, vmax=255)`

**Q: 滤波后图像变暗？**
A: 可能是数据类型转换问题，确保使用`np.uint8`

**Q: 角点检测结果不理想？**
A: 调整阈值参数，或先进行图像增强

**Q: 形态学操作效果不明显？**
A: 尝试不同的结构元素大小和形状
