## 🎓 学习技巧

### 1. 不要跳过代码

**错误做法**：
- 只看理论
- 不运行代码
- 觉得"看懂了"

**正确做法**：
- 每行代码都运行
- 修改参数观察变化
- 自己重写一遍

### 2. 多问为什么

看到每个概念时问自己：
- 为什么需要这个？
- 如果没有会怎样？
- 有没有替代方案？

**示例**：
- 为什么需要激活函数？
- 为什么用ReLU而不是Sigmoid？
- 为什么需要正则化？

### 3. 做笔记

推荐格式：

```markdown
## 概念：梯度下降

**理解**：
- 就像蒙眼下山
- 梯度=最陡上坡方向
- 负梯度=下坡方向

**关键参数**：
- 学习率：步长
- 太大→震荡
- 太小→慢

**代码**：
```python
x = x - lr * grad
```

**疑问**：
- 如何自动选择学习率？
```

### 4. 教是最好的学

尝试向别人解释：
- 什么是反向传播？
- Dropout如何工作？
- 为什么用Adam？

如果你能讲清楚，说明真正理解了。

## 🔧 常见问题解决

### 问题1：代码运行报错

**检查清单**：
- [ ] 库已安装？
- [ ] 导入语句正确？
- [ ] 变量名拼写正确？
- [ ] 数据类型匹配？

**解决方法**：
```python
# 打印变量检查
print(f"类型: {type(x)}")
print(f"形状: {x.shape}")
print(f"值: {x}")
```

### 问题2：理解困难

**应对策略**：
1. 放慢速度，多读几遍
2. 画图辅助理解
3. 从简单例子开始
4. 搜索相关视频教程

### 问题3：训练效果不好

**调试步骤**：
1. 检查数据：打印样本，看是否正常
2. 检查损失：是否在下降？
3. 检查学习率：是否合适？
4. 检查网络：是否太简单/复杂？
