## 🔧 核心技术速查

### 1. 神经网络基础

```bash
# 单层网络

z = W @ x + b
a = activation(z)

# 多层网络

a1 = relu(W1 @ x + b1)
a2 = softmax(W2 @ a1 + b2)
```

**激活函数选择**：
- 隐藏层：**ReLU**（默认）
- 输出层（二分类）：**Sigmoid**
- 输出层（多分类）：**Softmax**

---

### 2. 反向传播

```bash
# 链式法则

∂L/∂W = ∂L/∂a × ∂a/∂z × ∂z/∂W

# 完整流程

1. 前向传播：计算预测
2. 计算损失：预测 vs 真实
3. 反向传播：计算梯度
4. 更新参数：W = W - lr × ∂L/∂W
```

**优化器选择**：
- **Adam**：最常用，自适应学习率
- **SGD + Momentum**：经典，需要调参
- **RMSprop**：适合RNN

---

### 3. 损失函数

| 任务类型 | 推荐损失 | 备选方案 |
|---------|---------|---------|
| 回归（干净数据） | MSE | MAE |
| 回归（有异常值） | Huber | MAE |
| 二分类 | BCE | Focal Loss |
| 多分类 | 交叉熵 | Focal Loss |

---

### 4. 正则化技术

| 方法 | 作用 | 使用场景 |
|-----|------|---------|
| L2 | 权重衰减 | 通用 |
| L1 | 特征选择 | 高维数据 |
| Dropout | 防共适应 | 深层网络 |
| 数据增强 | 增加样本 | 图像/文本 |
| 早停 | 防过拟合 | 所有场景 |

---

### 5. 训练技巧

**学习率**：
- 搜索范围：1e-5 到 1e-1
- Adam默认：3e-4
- 调度：余弦退火或阶梯衰减

**批次大小**：
- 默认：64或128
- 内存不足：梯度累积
- 小数据：32或更小

**初始化**：
- ReLU网络：He初始化
- Sigmoid/Tanh：Xavier
- 避免：全0、过大/过小

## 🐛 常见问题

**Q: 损失不下降怎么办？**
A: 检查学习率（太小）、数据加载、网络结构

**Q: 损失震荡怎么办？**
A: 学习率太大，或批次太小

**Q: 验证损失上升？**
A: 过拟合，增加正则化

**Q: 梯度爆炸？**
A: 梯度裁剪，降低学习率，检查初始化

**Q: 训练太慢？**
A: 增大批次，使用GPU，优化数据加载
