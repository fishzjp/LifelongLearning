## 📚 学习路线概述

本计划为期6-12个月，分为4个阶段，循序渐进地掌握计算机视觉核心技术。

---

## 🎯 阶段一：基础入门（1-2个月）

### 1.1 数学基础

- **线性代数**：矩阵运算、向量空间、特征值分解
- **微积分**：梯度、链式法则、优化理论
- **概率统计**：概率分布、贝叶斯定理、统计推断

### 1.2 编程基础

- **Python基础**：NumPy、Pandas、Matplotlib
- **开发环境**：Anaconda、Jupyter、VS Code
- **版本控制**：Git、GitHub基础使用

### 1.3 图像基础概念

- **数字图像表示**：像素、通道、色彩空间（RGB、HSV、Lab）
- **图像格式**：JPEG、PNG、BMP的特点与区别
- **基本操作**：读取、显示、保存、缩放、裁剪

**📁 相关目录**：`01-基础概念/`、`02-图像处理基础/`

---

## 🎯 阶段二：传统计算机视觉（2-3个月）

### 2.1 图像预处理

- **空间滤波**：均值滤波、高斯滤波、中值滤波
- **边缘检测**：Sobel、Prewitt、Canny算子
- **形态学操作**：腐蚀、膨胀、开闭运算

### 2.2 特征提取

- **手工特征**：HOG、SIFT、SURF、ORB
- **角点检测**：Harris角点、Shi-Tomasi
- **特征描述子**：特征匹配、RANSAC

### 2.3 图像分割与识别

- **阈值分割**：全局阈值、自适应阈值
- **区域生长**：分水岭算法
- **模板匹配**：相关性匹配、几何匹配

**📁 相关目录**：`03-传统计算机视觉/`

---

## 🎯 阶段三：深度学习与CNN（3-4个月）

### 3.1 深度学习基础

- **神经网络基础**：感知机、多层网络、反向传播
- **训练技巧**：梯度消失/爆炸、权重初始化、正则化
- **优化算法**：SGD、Adam、学习率调度

### 3.2 卷积神经网络（CNN）

- **卷积原理**：卷积层、池化层、全连接层
- **经典架构**：LeNet、AlexNet、VGG、ResNet
- **现代架构**：EfficientNet、MobileNet、Vision Transformer

### 3.3 实战框架

- **PyTorch**：张量操作、自动求导、模型定义
- **TensorFlow/Keras**：模型构建、训练流程
- **数据增强**：翻转、旋转、色彩抖动

**📁 相关目录**：`04-深度学习基础/`、`05-CNN架构/`

---

## 🎯 阶段四：核心应用领域（2-3个月）

### 4.1 目标检测

- **两阶段检测器**：R-CNN系列（Fast R-CNN、Faster R-CNN）
- **单阶段检测器**：YOLO系列（v3-v8）、SSD、RetinaNet
- **评估指标**：IoU、mAP、PR曲线

### 4.2 图像分割

- **语义分割**：FCN、U-Net、DeepLab系列
- **实例分割**：Mask R-CNN、SOLO
- **全景分割**：Panoptic FPN

### 4.3 其他核心任务

- **姿态估计**：OpenPose、HRNet
- **人脸识别**：FaceNet、ArcFace
- **图像生成**：GAN、Diffusion Models

**📁 相关目录**：`06-目标检测/`、`07-图像分割/`、`08-姿态估计/`

---

## 🎯 阶段五：进阶与实战（1-2个月）

### 5.1 高级主题

- **注意力机制**：Self-Attention、Transformer
- **多模态学习**：CLIP、BLIP
- **自监督学习**：SimCLR、MoCo
- **小样本学习**：Meta Learning

### 5.2 工程化部署

- **模型压缩**：剪枝、量化、知识蒸馏
- **推理加速**：TensorRT、ONNX、OpenVINO
- **部署方案**：TensorFlow Serving、TorchServe

### 5.3 实战项目

- **项目1**：智能安防系统（人脸检测+识别）
- **项目2**：医学图像分析（病灶检测）
- **项目3**：自动驾驶感知（目标检测+跟踪）
- **项目4**：工业质检（缺陷检测）

**📁 相关目录**：`09-视频分析/`、`10-3D视觉/`、`11-实战项目/`、`12-进阶主题/`

## 📖 每周学习建议

### 学习节奏

- **理论学习**：每周15-20小时
- **代码实践**：每周10-15小时
- **项目实战**：每周5-10小时

### 学习方法

1. **理论结合实践**：每学一个概念立即动手实现
2. **论文阅读**：每周精读1-2篇经典论文
3. **代码复现**：从零实现经典算法
4. **项目驱动**：用实际问题驱动学习
