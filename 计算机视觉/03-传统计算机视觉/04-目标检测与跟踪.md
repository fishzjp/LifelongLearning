## 传统目标检测方法

### 1.1 目标检测概述

#### 什么是目标检测？

**目标检测（Object Detection）** 是在图像中定位并识别目标物体的任务，包含两个核心子任务：
- **分类（Classification）**：判断图像中是否存在特定类别的物体
- **定位（Localization）**：确定物体在图像中的位置（通常用边界框表示）

#### 传统检测方法的挑战

1. **尺度变化**：同一物体在不同距离下大小不同
   - 解决方案：图像金字塔、多尺度滑动窗口

2. **视角变化**：物体姿态不同导致外观变化
   - 解决方案：特征不变性、多视角模型

3. **光照变化**：明暗变化影响外观
   - 解决方案：归一化、光照不变特征

4. **遮挡问题**：物体部分被遮挡
   - 解决方案：局部特征、部件模型

5. **背景干扰**：背景与目标相似
   - 解决方案：上下文信息、区分性特征

#### 传统检测流程

```
输入图像 → 特征提取 → 分类器判断 → 后处理（非极大值抑制）
```

**滑动窗口检测**：
```
for scale in 多尺度金字塔:
    for position in 图像所有位置:
        提取窗口特征
        分类器判断是否为目标
        记录得分和位置
非极大值抑制去除重叠框
```

## Haar级联分类器

### 2.1 Haar特征原理

#### Haar特征定义

**Haar特征**是基于矩形区域像素和差值的简单特征，模拟图像的局部灰度变化。

**基本类型**：
```
边缘特征：
[1, -1] 或 [1; -1]  (垂直/水平边缘)

线特征：
[1, -1, 1]  (线条检测)

中心环绕特征：
[1, -1, 1; -1, 2, -1; 1, -1, 1]  (中心与周围对比)
```

#### 数学表达

对于矩形区域 R1 和 R2：
```
Haar特征值 = Σ(像素值 in R1) - Σ(像素值 in R2)
```

**示例**：
```
水平边缘特征（2×1）：
特征值 = 左半部分像素和 - 右半部分像素和

垂直边缘特征（1×2）：
特征值 = 上半部分像素和 - 下半部分像素和
```

#### 积分图加速

**积分图（Integral Image）** 是Haar特征计算的关键：
```
ii(x, y) = Σ_{i≤x, j≤y} img(i, j)

任意矩形区域和：
Sum(R) = ii(x2, y2) - ii(x1, y2) - ii(x2, y1) + ii(x1, y1)
```

**优势**：无论矩形大小，计算时间恒定（4次查表）

```python
print("\n=== Haar特征与积分图 ===")

def integral_image(img):
    """计算积分图"""
    return np.cumsum(np.cumsum(img, axis=0), axis=1)

def haar_feature(img, x, y, w, h, feature_type='horizontal'):
    """计算Haar特征值"""
    if feature_type == 'horizontal':
        # 水平边缘：左-右
        left_sum = img[y:y+h, x:x+w//2].sum()
        right_sum = img[y:y+h, x+w//2:x+w].sum()
        return left_sum - right_sum
    elif feature_type == 'vertical':
        # 垂直边缘：上-下
        top_sum = img[y:y+h//2, x:x+w].sum()
        bottom_sum = img[y+h//2:y+h, x:x+w].sum()
        return top_sum - bottom_sum
    elif feature_type == 'center':
        # 中心环绕
        center_sum = img[y+h//4:y+3*h//4, x+w//4:x+3*w//4].sum()
        surround_sum = (img[y:y+h, x:x+w].sum() - center_sum)
        return center_sum - surround_sum * 0.5
    return 0

def integral_haar_feature(ii, x, y, w, h, feature_type='horizontal'):
    """使用积分图计算Haar特征"""
    if feature_type == 'horizontal':
        # 左半部分
        x1, y1, x2, y2 = x, y, x+w//2, y+h
        left = ii[y2, x2] - ii[y1, x2] - ii[y2, x1] + ii[y1, x1]
        # 右半部分
        x1, y1, x2, y2 = x+w//2, y, x+w, y+h
        right = ii[y2, x2] - ii[y1, x2] - ii[y2, x1] + ii[y1, x1]
        return left - right

    elif feature_type == 'vertical':
        # 上半部分
        x1, y1, x2, y2 = x, y, x+w, y+h//2
        top = ii[y2, x2] - ii[y1, x2] - ii[y2, x1] + ii[y1, x1]
        # 下半部分
        x1, y1, x2, y2 = x, y+h//2, x+w, y+h
        bottom = ii[y2, x2] - ii[y1, x2] - ii[y2, x1] + ii[y1, x1]
        return top - bottom

    return 0
```

### 2.2 级联分类器

#### AdaBoost算法

**AdaBoost（Adaptive Boosting）** 用于组合弱分类器：

```
1. 初始化样本权重 w_i = 1/N
2. 重复T次：
   a. 选择最优弱分类器 h_t（最小加权错误率）
   b. 计算分类器权重 α_t = 0.5 * ln((1-ε_t)/ε_t)
   c. 更新样本权重 w_i *= exp(-α_t * y_i * h_t(x_i))
   d. 归一化权重
3. 最终分类器：H(x) = sign(Σ α_t * h_t(x))
```

**弱分类器**：单个Haar特征 + 阈值
```
h(x) = 1 if p·f(x) < p·θ else -1
其中 p ∈ {±1} 控制方向
```

#### 级联结构

**级联分类器（Cascade）** 是多阶段过滤器：

```
Stage 1: 简单特征，快速排除大部分背景
Stage 2: 稍复杂特征，进一步过滤
...
Stage N: 复杂特征，精确检测
```

**检测流程**：
```
窗口 → Stage 1 → 通过？ → Stage 2 → 通过？ → ... → 检测为正
                     ↓失败                ↓失败
                   排除                排除
```

**优势**：
- 快速：大部分窗口在早期被排除
- 准确：后期使用复杂特征
- 高效：减少计算量

```python
print("\n=== AdaBoost与级联分类器 ===")

class WeakClassifier:
    """弱分类器：基于单个Haar特征"""
    def __init__(self, feature_idx, threshold, polarity):
        self.feature_idx = feature_idx
        self.threshold = threshold
        self.polarity = polarity

    def predict(self, features):
        """预测：1为正，-1为负"""
        feature_val = features[self.feature_idx]
        if self.polarity == 1:
            return 1 if feature_val < self.threshold else -1
        else:
            return 1 if feature_val >= self.threshold else -1

class AdaBoost:
    """AdaBoost算法"""
    def __init__(self, n_weak=10):
        self.n_weak = n_weak
        self.weak_classifiers = []
        self.alphas = []

    def fit(self, features, labels):
        """训练AdaBoost"""
        N = len(labels)
        weights = np.ones(N) / N

        for t in range(self.n_weak):
            # 寻找最佳弱分类器
            best_error = float('inf')
            best_clf = None

            # 简化：遍历所有特征，找最佳阈值
            for f_idx in range(features.shape[1]):
                feature_vals = features[:, f_idx]
                thresholds = np.unique(feature_vals)

                for thresh in thresholds:
                    for polarity in [1, -1]:
                        # 预测
                        preds = np.array([1 if (polarity==1 and val<thresh) or
                                         (polarity==-1 and val>=thresh) else -1
                                         for val in feature_vals])

                        # 计算加权错误率
                        errors = (preds != labels)
                        weighted_error = np.sum(weights * errors) / np.sum(weights)

                        if weighted_error < best_error:
                            best_error = weighted_error
                            best_clf = WeakClassifier(f_idx, thresh, polarity)

            # 计算分类器权重
            alpha = 0.5 * np.log((1 - best_error) / max(best_error, 1e-10))

            # 更新样本权重
            preds = np.array([best_clf.predict(f) for f in features])
            weights = weights * np.exp(-alpha * labels * preds)
            weights = weights / np.sum(weights)

            self.weak_classifiers.append(best_clf)
            self.alphas.append(alpha)

            print(f"  弱分类器{t+1}: 特征{best_clf.feature_idx}, 错误率={best_error:.3f}, 权重={alpha:.3f}")

    def predict(self, features):
        """预测"""
        scores = np.zeros(len(features))
        for clf, alpha in zip(self.weak_classifiers, self.alphas):
            preds = np.array([clf.predict(f) for f in features])
            scores += alpha * preds
        return np.sign(scores)

class CascadeClassifier:
    """级联分类器"""
    def __init__(self, stages):
        self.stages = stages  # 每个stage是一个AdaBoost

    def detect(self, features):
        """级联检测"""
        for i, stage in enumerate(self.stages):
            score = stage.predict(features.reshape(1, -1))[0]
            if score < 0:  # 被当前stage拒绝
                return False, i+1
        return True, len(self.stages)
```

## HOG特征与SVM

### 3.1 HOG特征详解

#### HOG（Histogram of Oriented Gradients）原理

**核心思想**：通过梯度方向分布描述物体形状

**计算流程**：

**步骤1：灰度化与归一化**
```
img_gray = rgb2gray(img)
img_normalized = gamma_correction(img_gray)  # 可选
```

**步骤2：计算梯度**
```
Gx = [-1, 0, 1] * img  (水平梯度)
Gy = [-1; 0; 1] * img  (垂直梯度)

梯度幅值：G = sqrt(Gx² + Gy²)
梯度方向：θ = arctan2(Gy, Gx)  ∈ [0, π]
```

**步骤3：划分细胞（Cell）**
```
将图像划分为8×8像素的细胞
每个细胞计算梯度方向直方图
```

**步骤4：构建直方图**
```
将0-180°（或0-360°）分为9个bin
根据梯度幅值和方向，加权投票到bin
```

**步骤5：块归一化（Block）**
```
将2×2个细胞组成一个块
计算块内所有直方图的L2归一化
```

**步骤6：生成特征向量**
```
所有块的归一化直方图串联 → 最终HOG特征
```

**特征维度计算**：
```
假设图像 64×128
细胞：8×8 → 8×16个细胞
块：2×2细胞 → 7×15个块
每个块：9个bin
特征维度：7×15×9 = 945维
```

```python
print("\n=== HOG特征提取 ===")

def compute_hog_cell(cell_img, bins=9):
    """计算单个细胞的HOG直方图"""
    # 计算梯度
    gy, gx = np.gradient(cell_img.astype(float))
    magnitude = np.sqrt(gx**2 + gy**2)
    direction = np.arctan2(gy, gx)  # [-π, π]

    # 转换到[0, π]
    direction = np.abs(direction)

    # 构建直方图
    hist = np.zeros(bins)
    bin_edges = np.linspace(0, np.pi, bins + 1)
    bin_width = np.pi / bins

    for i in range(cell_img.shape[0]):
        for j in range(cell_img.shape[1]):
            mag = magnitude[i, j]
            ang = direction[i, j]

            # 找到所属bin
            bin_idx = int(ang / bin_width)
            if bin_idx >= bins:
                bin_idx = bins - 1

            # 加权投票
            hist[bin_idx] += mag

    return hist

def hog_visualization(img, cell_size=8, block_size=2, bins=9):
    """HOG特征计算和可视化"""
    h, w = img.shape

    # 计算细胞数量
    cells_y = h // cell_size
    cells_x = w // cell_size

    # 存储所有细胞的直方图
    cell_hists = np.zeros((cells_y, cells_x, bins))

    for i in range(cells_y):
        for j in range(cells_x):
            cell_img = img[i*cell_size:(i+1)*cell_size,
                          j*cell_size:(j+1)*cell_size]
            cell_hists[i, j] = compute_hog_cell(cell_img, bins)

    # 块归一化
    blocks_y = cells_y - block_size + 1
    blocks_x = cells_x - block_size + 1

    hog_features = []
    normalized_blocks = np.zeros((blocks_y, blocks_x, bins))

    for i in range(blocks_y):
        for j in range(blocks_x):
            block_hist = cell_hists[i:i+block_size, j:j+block_size].flatten()
            norm = np.sqrt(np.sum(block_hist**2) + 1e-6)
            normalized_blocks[i, j] = block_hist / norm
            hog_features.extend(normalized_blocks[i, j])

    return np.array(hog_features), cell_hists, normalized_blocks
```

### 3.2 HOG+SVM检测器

#### SVM（支持向量机）原理

**目标**：找到最优超平面分离正负样本

**优化目标**：
```
min ½||w||² + C·Σξ_i
s.t. y_i(w·x_i + b) ≥ 1 - ξ_i, ξ_i ≥ 0
```

**核函数**（非线性SVM）：
```
线性核：K(x, y) = x·y
多项式核：K(x, y) = (x·y + c)^d
RBF核：K(x, y) = exp(-γ||x-y||²)
```

#### HOG+SVM检测流程

**训练阶段**：
```
1. 收集正样本（目标）和负样本（背景）
2. 提取每个样本的HOG特征
3. 训练SVM分类器
4. 保存模型参数
```

**检测阶段**：
```
1. 构建图像金字塔（多尺度）
2. 滑动窗口提取HOG特征
3. SVM分类判断
4. 非极大值抑制（NMS）
```

```python
print("\n=== HOG+SVM目标检测 ===")

class LinearSVM:
    """线性SVM（简化版，使用梯度下降）"""
    def __init__(self, learning_rate=0.01, lambda_param=0.01, n_iter=1000):
        self.lr = learning_rate
        self.lambda_param = lambda_param
        self.n_iter = n_iter
        self.w = None
        self.b = None

    def fit(self, X, y):
        """训练SVM"""
        n_samples, n_features = X.shape

        # 初始化参数
        self.w = np.zeros(n_features)
        self.b = 0

        # 将标签转换为{-1, 1}
        y_ = np.where(y == 0, -1, y)

        # 梯度下降
        for i in range(self.n_iter):
            for idx, x in enumerate(X):
                condition = y_[idx] * (np.dot(self.w, x) + self.b) >= 1

                if condition:
                    # 正确分类，只正则化
                    self.w -= self.lr * (2 * self.lambda_param * self.w)
                else:
                    # 错误分类，更新w和b
                    self.w -= self.lr * (2 * self.lambda_param * self.w - y_[idx] * x)
                    self.b += self.lr * y_[idx]

            # 学习率衰减
            if (i + 1) % 100 == 0:
                self.lr *= 0.95

    def predict(self, X):
        """预测"""
        return np.sign(np.dot(X, self.w) + self.b)

    def decision_function(self, X):
        """决策函数值"""
        return np.dot(X, self.w) + self.b

def non_max_suppression(detections, iou_threshold=0.3):
    """非极大值抑制"""
    if len(detections) == 0:
        return []

    # 按得分排序
    detections = sorted(detections, key=lambda x: x[2], reverse=True)

    keep = []
    while detections:
        # 选择得分最高的
        best = detections.pop(0)
        keep.append(best)

        # 移除与best重叠过高的
        new_detections = []
        for det in detections:
            # 计算IoU（简化）
            x1, y1, _ = best
            x2, y2, _ = det

            # 假设窗口大小相同
            w, h = 32, 32

            # 交集
            inter_x1 = max(x1, x2)
            inter_y1 = max(y1, y2)
            inter_x2 = min(x1+w, x2+w)
            inter_y2 = min(y1+h, y2+h)

            inter_area = max(0, inter_x2 - inter_x1) * max(0, inter_y2 - inter_y1)
            area1 = w * h
            area2 = w * h
            iou = inter_area / (area1 + area2 - inter_area)

            if iou < iou_threshold:
                new_detections.append(det)

        detections = new_detections

    return keep
```

## 目标跟踪算法

### 4.1 KLT光流跟踪

#### 光流法原理

**光流（Optical Flow）**：图像中像素点的运动矢量场

**基本假设**：
1. **亮度恒定**：I(x, y, t) = I(x+dx, y+dy, t+dt)
2. **小运动**：dx, dy 较小
3. **空间一致性**：邻域像素运动相似

#### Lucas-Kanade方法

**推导**：
```
I(x+dx, y+dy, t+dt) ≈ I(x, y, t) + I_x·dx + I_y·dy + I_t·dt = 0

令 u = dx/dt, v = dy/dt，则：
I_x·u + I_y·v + I_t = 0

对于邻域内多个点：
[I_x1 I_y1] [u]   [-I_t1]
[I_x2 I_y2] [v] = [-I_t2]
   ...          ...
[I_xn I_y_n]      [-I_t_n]

最小二乘解：
A^T·A·[u, v]^T = A^T·b
```

**实现步骤**：
1. 计算图像梯度 I_x, I_y, I_t
2. 在每个点构建 2×2 矩阵 A^T·A
3. 求解 (u, v)

```python
print("\n=== KLT光流跟踪 ===")

def lucas_kanade(img1, img2, corners, window_size=5):
    """Lucas-Kanade光流计算"""
    # 计算时空梯度
    Ix, Iy = np.gradient(img1.astype(float))
    It = img2.astype(float) - img1.astype(float)

    flows = []

    for corner in corners:
        y, x = int(corner[0]), int(corner[1])

        # 提取窗口
        half = window_size // 2
        y1, y2 = max(0, y-half), min(img1.shape[0], y+half+1)
        x1, x2 = max(0, x-half), min(img1.shape[1], x+half+1)

        # 提取梯度
        Ix_win = Ix[y1:y2, x1:x2].flatten()
        Iy_win = Iy[y1:y2, x1:x2].flatten()
        It_win = It[y1:y2, x1:x2].flatten()

        # 构建矩阵 A 和向量 b
        A = np.column_stack([Ix_win, Iy_win])
        b = -It_win

        # 最小二乘解
        try:
            flow, _, _, _ = np.linalg.lstsq(A, b, rcond=None)
            flows.append(flow)
        except:
            flows.append([0, 0])

    return np.array(flows)
```

### 4.2 Mean-Shift跟踪

#### Mean-Shift原理

**核心思想**：通过梯度上升找到目标在下一帧的最相似区域

**目标模型**：
```
颜色直方图：q = {q_u}, Σq_u = 1
```

**候选模型**：
```
p(x) = {p_u(x)}, Σp_u = 1
```

**相似度度量**（Bhattacharyya系数）：
```
ρ(p, q) = Σ√(p_u·q_u)
```

**Mean-Shift迭代**：
```
x_{t+1} = x_t + m(x_t)
m(x_t) = Σ w_i·x_i / Σ w_i
w_i = √(q_u / p_u(x_t))
```

```python
print("\n=== Mean-Shift跟踪 ===")

def color_histogram(img, mask, bins=16):
    """计算颜色直方图"""
    # 归一化到0-1
    img_norm = img.astype(float) / 255.0

    # 量化颜色
    hist = np.zeros(bins)
    for i in range(img.shape[0]):
        for j in range(img.shape[1]):
            if mask[i, j] > 0:
                # 简化：使用灰度值
                val = img_norm[i, j]
                bin_idx = int(val * (bins - 1))
                hist[bin_idx] += 1

    # 归一化
    if np.sum(hist) > 0:
        hist = hist / np.sum(hist)

    return hist

def bhattacharyya_distance(p, q):
    """Bhattacharyya距离"""
    rho = np.sum(np.sqrt(p * q))
    return -np.log(max(rho, 1e-10))

def mean_shift_track(img, target_hist, init_pos, window_size, max_iter=10):
    """Mean-Shift跟踪"""
    x, y = init_pos
    h, w = window_size

    for iteration in range(max_iter):
        # 提取当前窗口
        y1, y2 = max(0, y), min(img.shape[0], y+h)
        x1, x2 = max(0, x), min(img.shape[1], x+w)
        window = img[y1:y2, x1:x2]

        # 计算候选直方图
        mask = np.ones(window.shape, dtype=np.uint8)
        candidate_hist = color_histogram(window, mask)

        # 计算权重
        weights = np.zeros_like(window, dtype=float)
        for i in range(window.shape[0]):
            for j in range(window.shape[1]):
                bin_idx = int(window[i, j] / 255.0 * (len(target_hist) - 1))
                if target_hist[bin_idx] > 0:
                    weights[i, j] = np.sqrt(target_hist[bin_idx] / max(candidate_hist[bin_idx], 1e-10))

        # 计算均值偏移
        total_weight = np.sum(weights)
        if total_weight < 1e-6:
            break

        # 计算重心偏移
        y_coords, x_coords = np.indices(window.shape)
        mean_y = np.sum(y_coords * weights) / total_weight
        mean_x = np.sum(x_coords * weights) / total_weight

        # 更新位置
        dx = mean_x - w / 2
        dy = mean_y - h / 2

        x += int(dx)
        y += int(dy)

        # 边界检查
        x = max(0, min(x, img.shape[1] - w))
        y = max(0, min(y, img.shape[0] - h))

        # 收敛判断
        if abs(dx) < 1 and abs(dy) < 1:
            break

    return (x, y)
```

## 背景建模与运动检测

### 5.1 背景减除

#### 背景建模方法

**1. 简单平均法**
```
背景模型 B(x, y) = (1/N) Σ I_t(x, y)
```

**2. 指数加权移动平均（EWMA）**
```
B_t(x, y) = α·I_t(x, y) + (1-α)·B_{t-1}(x, y)
```

**3. 高斯混合模型（GMM）**
```
P(I_t) = Σ w_i · N(I_t; μ_i, σ_i²)
```

#### 运动检测

**前景检测**：
```
如果 |I_t(x, y) - B_t(x, y)| > T:
    前景像素
否则：
    背景像素
```

```python
class BackgroundSubtractor:
    """背景减除器"""
    def __init__(self, alpha=0.05, threshold=25):
        self.alpha = alpha  # EWMA系数
        self.threshold = threshold
        self.background = None

    def update(self, frame):
        """更新背景模型"""
        if self.background is None:
            self.background = frame.astype(float)
        else:
            self.background = (self.alpha * frame +
                             (1 - self.alpha) * self.background)

    def detect(self, frame):
        """检测前景"""
        diff = np.abs(frame.astype(float) - self.background)
        foreground = diff > self.threshold
        return foreground.astype(np.uint8) * 255
```

```python
def practice1_haar_detector():

    print("练习1：Haar特征目标检测")
    print("="*60)

    # 1. 创建训练数据
    def create_samples():
        # 正样本：矩形目标
        pos_samples = []
        for _ in range(50):
            img = np.ones((32, 32), dtype=np.uint8) * 100
            img[8:24, 8:24] = 200  # 目标
            noise = np.random.normal(0, 5, img.shape)
            img = np.clip(img + noise, 0, 255).astype(np.uint8)
            pos_samples.append(img)

        # 负样本：无目标
        neg_samples = []
        for _ in range(50):
            img = np.random.randint(50, 150, (32, 32), dtype=np.uint8)
            neg_samples.append(img)

        return pos_samples, neg_samples

    pos_samples, neg_samples = create_samples()

    # 2. 提取Haar特征（简化：只用水平和垂直边缘）
    def extract_haar_features(img):
        features = []
        # 水平边缘（不同位置和大小）
        for y in [8, 12, 16]:
            for w in [8, 12, 16]:
                if y + w <= 32:
                    # 上半部分 - 下半部分
                    top = img[y:y+w//2, :].sum()
                    bottom = img[y+w//2:y+w, :].sum()
                    features.append(top - bottom)

        # 垂直边缘
        for x in [8, 12, 16]:
            for w in [8, 12, 16]:
                if x + w <= 32:
                    # 左半部分 - 右半部分
                    left = img[:, x:x+w//2].sum()
                    right = img[:, x+w//2:x+w].sum()
                    features.append(left - right)

        return np.array(features)

    # 提取所有样本特征
    print("提取特征...")
    pos_features = np.array([extract_haar_features(s) for s in pos_samples])
    neg_features = np.array([extract_haar_features(s) for s in neg_samples])

    X = np.vstack([pos_features, neg_features])
    y = np.array([1]*len(pos_samples) + [0]*len(neg_samples))

    print("\n训练AdaBoost分类器...")
    ada = AdaBoost(n_weak=5)

    detections = []

        for x in range(0, 68, step):
            window = test_img[y:y+window_size, x:x+window_size]
            features = extract_haar_features(window)
            score = ada.predict(features.reshape(1, -1))[0]

            if score > 0:
                # 计算置信度（简单用特征值和）
                confidence = np.sum(np.abs(features))
                detections.append((x, y, confidence))

    print(f"原始检测数: {len(detections)}")

    # 6. NMS
    def simple_nms(dets, thresh=0.3):
        if len(dets) == 0:
            return []

        dets = sorted(dets, key=lambda x: x[2], reverse=True)
        keep = []

        while dets:
            best = dets.pop(0)
            keep.append(best)

            new_dets = []
            for det in dets:
                # IoU
                x1, y1, _ = best
                x2, y2, _ = det

                inter_x1 = max(x1, x2)
                inter_y1 = max(y1, y2)
                inter_x2 = min(x1+32, x2+32)
                inter_y2 = min(y1+32, y2+32)

                inter = max(0, inter_x2-inter_x1) * max(0, inter_y2-inter_y1)
                iou = inter / (32*32*2 - inter)

                if iou < thresh:
                    new_dets.append(det)

            dets = new_dets

        return keep

    final_dets = simple_nms(detections)
    print(f"NMS后检测数: {len(final_dets)}")
```

```python
    print("="*60)

    # 1. 创建复杂运动序列
    def create_complex_sequence():
        frames = []
        positions = []

        # 轨迹：圆形运动
        center_x, center_y = 40, 40
        radius = 15

        for t in range(20):
            frame = np.zeros((80, 80), dtype=np.uint8)

            # 目标位置
            angle = t * 2 * np.pi / 20
            x = int(center_x + radius * np.cos(angle))
            y = int(center_y + radius * np.sin(angle))
            positions.append((x, y))

            # 绘制目标
            frame[y-3:y+3, x-3:x+3] = 200

            # 添加干扰
            if t % 3 == 0:
                frame[10:15, 10:15] = 150

            # 添加噪声
            noise = np.random.normal(0, 5, frame.shape)
            frame = np.clip(frame + noise, 0, 255).astype(np.uint8)
            frames.append(frame)

        return frames, positions

    frames, true_positions = create_complex_sequence()

    # 2. KLT跟踪
    print("KLT跟踪...")
    klt_positions = [true_positions[0]]

    for i in range(1, len(frames)):
        # 检测角点（第一帧）
        if i == 1:
            corners = np.array([true_positions[0]])

        # 计算光流
        flows = lucas_kanade(frames[i-1], frames[i], corners)

        # 更新位置
        new_pos = (klt_positions[-1][0] + flows[0][1],
                  klt_positions[-1][1] + flows[0][0])
        klt_positions.append(new_pos)

        # 更新角点位置
        corners = np.array([new_pos])

    # 3. Mean-Shift跟踪
    print("Mean-Shift跟踪...")
    # 初始化
    first_frame = frames[0]
    init_pos = true_positions[0]
    target_window = first_frame[init_pos[1]-5:init_pos[1]+5, init_pos[0]-5:init_pos[0]+5]
    target_mask = np.ones(target_window.shape, dtype=np.uint8)
    target_hist = color_histogram(target_window, target_mask)

    ms_positions = [init_pos]
    for i in range(1, len(frames)):
        new_pos = mean_shift_track(frames[i], target_hist, ms_positions[-1], (10, 10))
        ms_positions.append(new_pos)

    # 4. 计算误差
    def compute_errors(positions, true_positions):
        errors = []
        for (x, y), (tx, ty) in zip(positions, true_positions):
            error = np.sqrt((x-tx)**2 + (y-ty)**2)
            errors.append(error)
        return errors

    klt_errors = compute_errors(klt_positions, true_positions)
    ms_errors = compute_errors(ms_positions, true_positions)

    print(f"\nKLT平均误差: {np.mean(klt_errors):.2f} 像素")
    print(f"Mean-Shift平均误差: {np.mean(ms_errors):.2f} 像素")

    # 5. 可视化
    fig, axes = plt.subplots(2, 3, figsize=(15, 10))

    # 显示第0、5、10、15、19帧
    display_frames = [0, 5, 10, 15, 19]
    for idx, frame_idx in enumerate(display_frames):
        row = idx // 3
        col = idx % 3
        if row < 2:
            ax = axes[row, col]
            ax.imshow(frames[frame_idx], cmap='gray', vmin=0, vmax=255)

            # 真实位置
            tx, ty = true_positions[frame_idx]
            ax.plot(tx, ty, 'go', markersize=10, label='真实')

            # KLT位置
            kx, ky = klt_positions[frame_idx]
            ax.plot(kx, ky, 'r^', markersize=8, label='KLT')

            # Mean-Shift位置
            mx, my = ms_positions[frame_idx]
            ax.plot(mx, my, 'bs', markersize=8, label='Mean-Shift')

            ax.set_title(f'帧{frame_idx+1}')
            ax.axis('off')

    axes[0, 0].legend(loc='upper right', fontsize=8)
    plt.tight_layout()
    plt.show()

    # 6. 误差曲线
    fig, axes = plt.subplots(1, 2, figsize=(12, 5))

    # 误差随时间变化
    axes[0].plot(range(1, len(klt_errors)+1), klt_errors, 'r-o', label='KLT')
    axes[0].plot(range(1, len(ms_errors)+1), ms_errors, 'b-s', label='Mean-Shift')
    axes[0].set_xlabel('帧序号')
    axes[0].set_ylabel('跟踪误差（像素）')
    axes[0].set_title('跟踪误差随时间变化')
    axes[0].legend()
    axes[0].grid(True, alpha=0.3)

    # 误差分布
    axes[1].hist(klt_errors, bins=10, alpha=0.6, label='KLT', color='red')
    axes[1].hist(ms_errors, bins=10, alpha=0.6, label='Mean-Shift', color='blue')
    axes[1].set_xlabel('误差（像素）')
    axes[1].set_ylabel('频数')
    axes[1].set_title('误差分布')
    axes[1].legend()
    axes[1].grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

    # 7. 性能对比
    print("\n" + "="*50)
    print("算法对比分析")
    print("="*50)
    print(f"{'指标':<20} {'KLT':<15} {'Mean-Shift':<15}")
    print("-"*50)
    print(f"{'平均误差':<20} {np.mean(klt_errors):<15.2f} {np.mean(ms_errors):<15.2f}")
    print(f"{'最大误差':<20} {np.max(klt_errors):<15.2f} {np.max(ms_errors):<15.2f}")
    print(f"{'误差标准差':<20} {np.std(klt_errors):<15.2f} {np.std(ms_errors):<15.2f}")
    print(f"{'成功率':<20} {np.mean(np.array(klt_errors)<5):<15.2%} {np.mean(np.array(ms_errors)<5):<15.2%}")

    print("\n适用场景建议：")
    print("KLT: 快速运动、小目标、需要高帧率")
    print("Mean-Shift: 部分遮挡、外观变化、实时性要求不高")
```
