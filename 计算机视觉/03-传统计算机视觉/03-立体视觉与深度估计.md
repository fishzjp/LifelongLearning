## 立体视觉基础

### 1.1 双目立体成像原理

#### 什么是立体视觉？

**立体视觉（Stereo Vision）** 模拟人类双眼的深度感知能力。人类通过左右眼看到的图像略有差异（视差），大脑利用这种差异计算深度信息。计算机视觉同样利用这一原理，通过两个相机从不同角度拍摄同一场景，计算物体的三维位置。

#### 核心概念

**1. 视差（Disparity）**
- 定义：同一3D点在左右图像中的水平位置差异
- 单位：像素
- 关键特性：距离越近，视差越大；距离越远，视差越小

**2. 基线（Baseline）**
- 定义：左右相机光心之间的距离
- 单位：毫米或米
- 影响：基线越大，相同深度下的视差越大，深度测量越精确

**3. 焦距（Focal Length）**
- 定义：相机光心到成像平面的距离
- 单位：像素
- 作用：影响图像的放大倍数和视差计算

#### 数学原理

对于空间中的一个点 P(X, Y, Z)，它在左右相机中的投影坐标为：

```
左相机：x_L = f × X_L / Z_L + c_x
右相机：x_R = f × X_R / Z_R + c_x

视差：d = x_L - x_R = f × B / Z
```

其中：
- f：焦距（像素）
- B：基线长度
- Z：深度（到相机的距离）
- d：视差

### 1.2 视差与深度关系

#### 数学关系推导

视差与深度的关系是立体视觉的核心：

```
深度 Z = (基线 B × 焦距 f) / 视差 d
```

**关键特性：**
1. **反比关系**：深度与视差成反比
2. **非线性**：相同视差变化在不同深度产生的深度误差不同
3. **精度问题**：远处物体视差小，深度测量精度低

#### 误差分析

**深度误差对视差的影响：**
- 深度测量误差 ΔZ 会导致视差误差 Δd
- 近处物体：视差大，对误差不敏感
- 远处物体：视差小，对误差非常敏感

```python
print("\n=== 视差与深度关系 ===")

def disparity_depth_demo():
    """演示视差与深度的关系"""

    # 参数
    baseline = 100  # 基线（mm）
    focal_length = 500  # 焦距（像素）

    # 深度范围
    depths = np.linspace(50, 500, 100)

    # 计算对应的视差
    disparities = baseline * focal_length / depths

    # 可视化
    fig, axes = plt.subplots(1, 2, figsize=(12, 5))

    # 深度-视差关系
    axes[0].plot(depths, disparities, 'b-', linewidth=2)
    axes[0].set_xlabel('深度 (mm)')
    axes[0].set_ylabel('视差 (像素)')
    axes[0].set_title('深度 vs 视差')
    axes[0].grid(True, alpha=0.3)

    # 标注关键点
    sample_depths = [100, 200, 300, 400, 500]
    for d in sample_depths:
        disp = baseline * focal_length / d
        axes[0].plot(d, disp, 'ro')
        axes[0].text(d, disp + 5, f'{disp:.1f}', ha='center', fontsize=8)

    # 深度误差对视差的影响
    depth_errors = np.linspace(0, 10, 50)  # 深度误差百分比
    true_depth = 200  # 真实深度
    true_disp = baseline * focal_length / true_depth

    # 计算不同深度误差下的视差变化
    disp_errors = []
    for err in depth_errors:
        noisy_depth = true_depth * (1 + err/100)
        noisy_disp = baseline * focal_length / noisy_depth
        disp_errors.append(abs(noisy_disp - true_disp))

    axes[1].plot(depth_errors, disp_errors, 'g-', linewidth=2)
    axes[1].set_xlabel('深度误差 (%)')
    axes[1].set_ylabel('视差误差 (像素)')
    axes[1].set_title(f'深度误差对视差的影响 (深度={true_depth}mm)')
    axes[1].grid(True, alpha=0.3)

    # 标注
    axes[1].axvline(x=5, color='r', linestyle='--', alpha=0.5)
    axes[1].text(5, max(disp_errors)/2, '5%深度误差', rotation=90, ha='center')

    plt.tight_layout()
    plt.show()

    print("关键公式：")
    print("深度 = (基线 × 焦距) / 视差")
    print(f"示例：基线={baseline}mm, 焦距={focal_length}像素")
    print(f"视差1像素 → 深度 = {baseline * focal_length / 1:.1f}mm")
    print(f"视差10像素 → 深度 = {baseline * focal_length / 10:.1f}mm")
    print(f"视差100像素 → 深度 = {baseline * focal_length / 100:.1f}mm")

disparity_depth_demo()
```

**代码解析：**
- 左图：展示深度与视差的反比关系曲线
- 右图：展示深度误差百分比与视差误差的关系
- 关键发现：深度误差会导致视差误差，且这种关系是非线性的

**实际应用建议：**
- 基线选择：根据测量距离范围选择合适的基线
- 焦距选择：影响测量精度和视野范围
- 视差范围：需要根据深度范围设定匹配搜索范围

## 极线几何

### 2.1 极线约束原理

#### 什么是极线几何？

**极线几何（Epipolar Geometry）** 描述了两个相机之间的几何约束关系。对于空间中的任意一点，它在左右图像中的对应点之间存在严格的几何约束。

#### 核心概念

**1. 极点（Epipole）**
- 定义：一个相机的光心在另一个相机图像平面上的投影点
- 特性：所有极线都通过极点
- 意义：对应点在另一图像中的搜索范围约束

**2. 极线（Epipolar Line）**
- 定义：包含3D点和两个相机光心的平面（极平面）与图像平面的交线
- 特性：左图像中的点对应右图像中的一条极线
- 意义：将2D搜索降为1D搜索

**3. 极平面（Epipolar Plane）**
- 定义：由3D点和两个相机光心确定的平面
- 作用：连接左右图像的对应关系

#### 极线约束

**极线约束方程：**
```
x₂ᵀ F x₁ = 0
```

其中：
- x₁：左图像点的齐次坐标 [u₁, v₁, 1]ᵀ
- x₂：右图像点的齐次坐标 [u₂, v₂, 1]ᵀ
- F：3×3基础矩阵

**几何意义：**
对于左图像中的任意点 x₁，它在右图像中的对应点 x₂ 必定位于极线 l₂ = F x₁ 上。

### 2.2 基础矩阵与本质矩阵

#### 矩阵层次结构

**1. 本质矩阵 E（Essential Matrix）**
- 作用：描述相机坐标系中的几何约束
- 维度：3×3
- 公式：E = [t]× R

其中：
- [t]×：平移向量的叉积矩阵（反对称矩阵）
- R：旋转矩阵

**2. 基础矩阵 F（Fundamental Matrix）**
- 作用：描述像素坐标系中的几何约束
- 维度：3×3
- 公式：F = K⁻ᵀ E K⁻¹

其中：
- K：相机内参矩阵
- K⁻¹：内参矩阵的逆
- K⁻ᵀ：内参矩阵逆的转置

#### 数学推导

**从本质矩阵到基础矩阵：**

```
已知：E = [t]× R

相机坐标系约束：x₂ᵀ E x₁ = 0
其中 x₁, x₂ 是归一化坐标

像素坐标系：x = K x_norm

代入得：
(K⁻¹ x_pixel₂)ᵀ E (K⁻¹ x_pixel₁) = 0
x_pixel₂ᵀ (K⁻ᵀ E K⁻¹) x_pixel₁ = 0

因此：F = K⁻ᵀ E K⁻¹
```

```python
print("\n=== 基础矩阵与本质矩阵 ===")

def fundamental_matrix_demo():
    """演示基础矩阵计算"""

    # 相机内参
    K = np.array([
        [500, 0, 320],
        [0, 500, 240],
        [0, 0, 1]
    ])

    # 相机外参（右相机相对于左相机）
    # 平移
    t = np.array([100, 0, 0])  # 基线100mm
    # 旋转（轻微旋转）
    theta = 0.1
    R = np.array([
        [1, 0, 0],
        [0, np.cos(theta), -np.sin(theta)],
        [0, np.sin(theta), np.cos(theta)]
    ])

    # 本质矩阵 E = [t]× R
    def skew_symmetric(v):
        """叉积矩阵"""
        return np.array([
            [0, -v[2], v[1]],
            [v[2], 0, -v[0]],
            [-v[1], v[0], 0]
        ])

    E = skew_symmetric(t) @ R

    # 基础矩阵 F = K^(-T) * E * K^(-1)
    K_inv = np.linalg.inv(K)
    F = K_inv.T @ E @ K_inv

    print("本质矩阵 E:")
    print(E)
    print("\n基础矩阵 F:")
    print(F)

    # 验证极线约束：x2^T * F * x1 = 0
    # 生成一些3D点
    points_3d = np.array([
        [50, 30, 200],
        [80, 40, 250],
        [20, 10, 150],
        [60, 50, 300]
    ])

    # 投影到左右图像
    points_left = []
    points_right = []

    for p in points_3d:
        # 左相机投影
        p_left = K @ p
        p_left = p_left / p_left[2]
        points_left.append(p_left[:2])

        # 右相机投影
        p_cam = R @ p + t
        p_right = K @ p_cam
        p_right = p_right / p_right[2]
        points_right.append(p_right[:2])

    points_left = np.array(points_left)
    points_right = np.array(points_right)

    # 验证极线约束
    print("\n验证极线约束 (x2^T * F * x1 = 0):")
    for i in range(len(points_left)):
```

## 立体匹配算法

### 3.1 块匹配算法

#### 什么是立体匹配？

**立体匹配（Stereo Matching）** 是在左右图像中找到对应像素点的过程，目标是为每个像素计算视差值。

#### 块匹配原理

**基本思想：**
对于左图像中的每个像素（或小块），在右图像中寻找最相似的对应块，计算水平位移作为视差。

**算法步骤：**
1. 选择左图像中的一个像素点
2. 以该点为中心，提取一个小窗口（如 5×5）
3. 在右图像的同一行上，滑动窗口计算相似度
4. 找到相似度最高的位置
5. 计算水平位移作为视差

**相似度度量：**

**1. SAD（Sum of Absolute Differences）**
```
SAD(d) = Σ |I_L(x,y) - I_R(x-d,y)|
```
- 优点：计算简单
- 缺点：对噪声敏感

**2. SSD（Sum of Squared Differences）**
```
SSD(d) = Σ (I_L(x,y) - I_R(x-d,y))²
```
- 优点：放大较大差异
- 缺点：计算稍复杂

**3. NCC（Normalized Cross-Correlation）**
```
NCC(d) = Σ (I_L - μ_L)(I_R - μ_R) / (σ_L σ_R)
```
- 优点：光照不变性
- 缺点：计算复杂

```python
print("\n=== 立体匹配算法 ===")

def block_matching_demo():
    """块匹配立体匹配演示"""

    # 创建模拟立体图像对
    def create_stereo_pair():
        """创建立体图像对"""
        h, w = 100, 150

        # 左图像
        left = np.zeros((h, w), dtype=np.uint8)

        # 添加一些特征
        left[20:40, 30:50] = 150
        left[60:80, 80:100] = 200
        left[40:60, 120:140] = 100

        # 添加渐变背景
        for i in range(h):
            left[i, :] = 50 + i * 0.5

        # 添加噪声
        left = add_gaussian_noise(left, sigma=5)

        # 右图像（平移+轻微变化）
        disparity_map = np.zeros((h, w))
        # 不同区域不同视差
        disparity_map[20:40, 30:50] = 8
        disparity_map[60:80, 80:100] = 12
        disparity_map[40:60, 120:140] = 5

        right = np.zeros((h, w), dtype=np.uint8)
        for i in range(h):
            for j in range(w):
                d = disparity_map[i, j]
                if j - d >= 0:
                    right[i, j] = left[i, int(j - d)]
                else:
                    right[i, j] = left[i, j]

        # 右图像也加噪声（但不同）
        right = add_gaussian_noise(right, sigma=3)

        return left, right, disparity_map

    left_img, right_img, true_disp = create_stereo_pair()

    # 块匹配算法
    def block_matching(left, right, window_size=5, max_disp=20):
        """块匹配立体匹配"""
        h, w = left.shape
        disparity = np.zeros((h, w))

        pad = window_size // 2

        for i in range(pad, h - pad):
            for j in range(pad, w - pad):
                # 左图像块
                left_block = left[i-pad:i+pad+1, j-pad:j+pad+1]

                best_disp = 0
                best_cost = float('inf')

                # 在右图像中搜索
                for d in range(min(max_disp, j - pad)):
                    if j - d - pad >= 0:
                        # 右图像块
                        right_block = right[i-pad:i+pad+1, j-d-pad:j-d+pad+1]

                        # 计算SAD（绝对差和）
                        cost = np.sum(np.abs(left_block.astype(float) - right_block.astype(float)))

                        if cost < best_cost:
                            best_cost = cost
                            best_disp = d

                disparity[i, j] = best_disp

        return disparity

    # 执行匹配
    print("执行块匹配...")
    estimated_disp = block_matching(left_img, right_img, window_size=5, max_disp=15)

    # 可视化
    fig, axes = plt.subplots(2, 3, figsize=(15, 10))

    axes[0, 0].imshow(left_img, cmap='gray', vmin=0, vmax=255)
    axes[0, 0].set_title('左图像')
    axes[0, 0].axis('off')

    axes[0, 1].imshow(right_img, cmap='gray', vmin=0, vmax=255)
    axes[0, 1].set_title('右图像')
    axes[0, 1].axis('off')

    axes[0, 2].imshow(true_disp, cmap='jet', vmin=0, vmax=15)
    axes[0, 2].set_title('真实视差图')
    axes[0, 2].axis('off')
    plt.colorbar(axes[0, 2].imshow(true_disp, cmap='jet', vmin=0, vmax=15),
                 ax=axes[0, 2], label='视差')

    axes[1, 0].imshow(estimated_disp, cmap='jet', vmin=0, vmax=15)
    axes[1, 0].set_title('估计视差图')
    axes[1, 0].axis('off')
    plt.colorbar(axes[1, 0].imshow(estimated_disp, cmap='jet', vmin=0, vmax=15),
                 ax=axes[1, 0], label='视差')

    # 误差图
    error = np.abs(true_disp - estimated_disp)
    axes[1, 1].imshow(error, cmap='hot', vmin=0, vmax=5)
    axes[1, 1].set_title('误差图')
    axes[1, 1].axis('off')
    plt.colorbar(axes[1, 1].imshow(error, cmap='hot', vmin=0, vmax=5),
                 ax=axes[1, 1], label='误差')

    # 误差统计
    axes[1, 2].hist(error.flatten(), bins=20, alpha=0.7, color='red')
    axes[1, 2].set_xlabel('视差误差')
    axes[1, 2].set_ylabel('像素数量')
    axes[1, 2].set_title('误差分布')
    axes[1, 2].grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

    # 统计
    valid_pixels = error > 0
    mean_error = np.mean(error[valid_pixels])
    std_error = np.std(error[valid_pixels])
    correct_rate = np.sum(error < 1) / np.sum(valid_pixels) * 100

    print(f"\n匹配结果统计：")
    print(f"平均误差: {mean_error:.3f} 像素")
    print(f"误差标准差: {std_error:.3f}")
    print(f"正确率(<1像素): {correct_rate:.1f}%")
```

### 3.2 更高级的匹配算法

#### 算法对比

**1. SAD（绝对差和）**
```
cost = Σ |I_L - I_R|
```
- 特点：线性、对大差异不敏感
- 速度：快
- 精度：中等

**2. SSD（平方差和）**
```
cost = Σ (I_L - I_R)²
```
- 特点：放大差异、对异常值敏感
- 速度：中等
- 精度：较高

**3. NCC（归一化互相关）**
```
cost = Σ (I_L - μ_L)(I_R - μ_R) / (σ_L σ_R)
```
- 特点：光照不变性、计算复杂
- 速度：慢
- 精度：高

```python
print("\n=== 高级立体匹配 ===")

def advanced_stereo_matching():
    """演示更高级的匹配方法"""

    # 创建更复杂的立体图像
    def create_complex_stereo():
        h, w = 120, 180
        left = np.zeros((h, w), dtype=np.uint8)

        # 添加多个不同深度的物体
        # 远处物体（小视差）
        left[20:40, 40:60] = 80
        # 中等距离（中等视差）
        left[50:70, 80:100] = 150
        # 近处物体（大视差）
        left[80:100, 130:150] = 200

        # 添加纹理
        for i in range(0, h, 10):
            left[i:i+2, :] = 30

        left = add_gaussian_noise(left, sigma=8)

        # 视差图
        disp = np.zeros((h, w))
        disp[20:40, 40:60] = 3
        disp[50:70, 80:100] = 8
        disp[80:100, 130:150] = 15

        # 右图像
        right = np.zeros((h, w), dtype=np.uint8)
        for i in range(h):
            for j in range(w):
                d = disp[i, j]
                if j - d >= 0:
                    right[i, j] = left[i, int(j - d)]
                else:
                    right[i, j] = left[i, j]

        right = add_gaussian_noise(right, sigma=5)

        return left, right, disp

    left_img, right_img, true_disp = create_complex_stereo()

    # 1. SAD（绝对差和）
    def sad_matching(left, right, win=5, max_d=20):
        h, w = left.shape
        disp = np.zeros((h, w))
        pad = win // 2

        for i in range(pad, h-pad):
            for j in range(pad, w-pad):
                left_patch = left[i-pad:i+pad+1, j-pad:j+pad+1]
                best_d, best_cost = 0, float('inf')

                for d in range(min(max_d, j-pad)):
                    if j-d-pad >= 0:
                        right_patch = right[i-pad:i+pad+1, j-d-pad:j-d+pad+1]
                        cost = np.sum(np.abs(left_patch - right_patch))
                        if cost < best_cost:
                            best_cost, best_d = cost, d
                disp[i, j] = best_d
        return disp

    # 2. SSD（平方差和）
    def ssd_matching(left, right, win=5, max_d=20):
        h, w = left.shape
        disp = np.zeros((h, w))
        pad = win // 2

        for i in range(pad, h-pad):
            for j in range(pad, w-pad):
                left_patch = left[i-pad:i+pad+1, j-pad:j+pad+1]
                best_d, best_cost = 0, float('inf')

                for d in range(min(max_d, j-pad)):
                    if j-d-pad >= 0:
                        right_patch = right[i-pad:i+pad+1, j-d-pad:j-d+pad+1]
                        cost = np.sum((left_patch.astype(float) - right_patch.astype(float))**2)
                        if cost < best_cost:
                            best_cost, best_d = cost, d
                disp[i, j] = best_d
        return disp

    # 3. NCC（归一化互相关）
    def ncc_matching(left, right, win=5, max_d=20):
        h, w = left.shape
        disp = np.zeros((h, w))
        pad = win // 2

        for i in range(pad, h-pad):
            for j in range(pad, w-pad):
                left_patch = left[i-pad:i+pad+1, j-pad:j+pad+1].astype(float)
                left_mean = np.mean(left_patch)
                left_norm = left_patch - left_mean

                best_d, best_score = 0, -1

                for d in range(min(max_d, j-pad)):
                    if j-d-pad >= 0:
                        right_patch = right[i-pad:i+pad+1, j-d-pad:j-d+pad+1].astype(float)
                        right_mean = np.mean(right_patch)
                        right_norm = right_patch - right_mean

                        # NCC
                        numerator = np.sum(left_norm * right_norm)
                        denominator = np.sqrt(np.sum(left_norm**2) * np.sum(right_norm**2))

                        if denominator > 0:
                            score = numerator / denominator
                            if score > best_score:
                                best_score, best_d = score, d

                disp[i, j] = best_d
        return disp

    # 执行三种匹配

    print("计算SSD...")

    # 可视化
    fig, axes = plt.subplots(2, 3, figsize=(15, 10))

    axes[0, 0].imshow(left_img, cmap='gray', vmin=0, vmax=255)
    axes[0, 0].set_title('左图像')
    axes[0, 0].axis('off')

    axes[0, 1].imshow(right_img, cmap='gray', vmin=0, vmax=255)
    axes[0, 1].set_title('右图像')

    axes[1, 0].set_title(f'SAD\\n误差: {np.mean(np.abs(true_disp-disp_sad)):.2f}')
    axes[1, 0].axis('off')

    axes[1, 1].imshow(disp_ssd, cmap='jet', vmin=0, vmax=15)
```

## 深度图生成

### 4.1 视差图转深度图

#### 转换公式

视差图到深度图的转换是立体视觉的最后一步：

```
深度 Z = (基线 B × 焦距 f) / 视差 d
```

**注意事项：**
1. **单位一致性**：确保所有参数单位匹配
2. **有效范围**：视差为0或负值时深度无穷大
3. **精度问题**：远处物体视差小，深度误差大

#### 深度图特性

**1. 深度图格式**
- 单通道浮点图像
- 值表示到相机的距离
- 无效值通常用0或NaN表示

**2. 深度图应用**
- 3D重建：点云生成
- 障碍物检测：深度阈值分割
- 测量：物体尺寸计算
- AR：虚拟物体放置

```python
def disparity_to_depth_demo():

    mask_near = center_dist < 40
    disparity_map[mask_near] = 15

    # 中间环（中等）
    mask_mid = (center_dist >= 40) & (center_dist < 80)
    disparity_map[mask_mid] = 8

    # 外环（远）
    mask_far = (center_dist >= 80) & (center_dist < 120)

    ax3d.set_ylabel('Y')

    ax3d.set_title('3D深度表面')
    ax3d.view_init(elev=30, azim=45)

    axes[1, 0].hist(depth_map[valid_mask].flatten(), bins=30, alpha=0.7, color='blue')
    axes[1, 0].set_xlabel('深度 (mm)')
    axes[1, 0].set_ylabel('像素数量')
    axes[1, 0].set_title('深度分布')
    axes[1, 0].grid(True, alpha=0.3)

    # 深度误差分析（假设视差有噪声）
    disparity_noise = np.linspace(0, 1, 50)
    true_depth = 200  # 假设真实深度200mm
    depth_errors = []

    for noise in disparity_noise:
        noisy_disp = (baseline * focal_length) / true_depth + noise
        estimated_depth = (baseline * focal_length) / noisy_disp
        depth_errors.append(abs(estimated_depth - true_depth))
```

### 4.2 深度图后处理

#### 为什么需要后处理？

原始深度图通常存在以下问题：
1. **噪声**：匹配误差导致的随机误差
2. **空洞**：纹理贫乏区域无法匹配
3. **边缘模糊**：物体边界不清晰
4. **不一致性**：左右视图不一致

#### 后处理方法

**1. 中值滤波（Median Filter）**
- 作用：去除椒盐噪声
- 原理：用邻域中值替换中心值
- 优点：保持边缘

**2. 空洞填充（Hole Filling）**
- 方法：邻域插值、区域生长
- 策略：从边缘向内填充
- 挑战：保持物体形状

**3. 双边滤波（Bilateral Filter）**
- 作用：平滑同时保持边缘
- 原理：考虑空间距离和值域相似性
- 优点：边缘保持好

```python
print("\n=== 深度图后处理 ===")

def depth_post_processing():
    """深度图后处理演示"""

    # 创建带噪声的深度图
    h, w = 150, 150
    true_depth = np.zeros((h, w))

    # 真实深度
    y, x = np.ogrid[:h, :w]
    circle = (x - w/2)**2 + (y - h/2)**2 < 40**2
    true_depth[circle] = 200
    true_depth[~circle] = 400

    # 添加噪声和空洞
    noisy_depth = true_depth + np.random.normal(0, 10, (h, w))

    # 模拟空洞（某些像素无深度）
    hole_mask = np.random.random((h, w)) < 0.1
    noisy_depth[hole_mask] = 0

    # 1. 中值滤波去噪
    from scipy.ndimage import median_filter
    filtered_depth = median_filter(noisy_depth, size=3)

    # 2. 空洞填充（最近邻）
    filled_depth = filtered_depth.copy()
    for i in range(1, h-1):
        for j in range(1, w-1):
            if filled_depth[i, j] == 0:
                # 取周围非零最小值
                neighbors = filtered_depth[i-1:i+2, j-1:j+2]
                valid_neighbors = neighbors[neighbors > 0]
                if len(valid_neighbors) > 0:
                    filled_depth[i, j] = np.mean(valid_neighbors)

    # 3. 边缘保持平滑（双边滤波简化版）
    def bilateral_depth(depth, sigma_d=3, sigma_r=20):
        """简化版双边滤波"""
        h, w = depth.shape
        result = np.zeros_like(depth)

        for i in range(1, h-1):
            for j in range(1, w-1):
                if depth[i, j] == 0:
                    result[i, j] = 0
                    continue

                total_weight = 0
                total_value = 0

                for di in range(-1, 2):
                    for dj in range(-1, 2):
                        ni, nj = i + di, j + dj
                        if ni < 0 or ni >= h or nj < 0 or nj >= w or depth[ni, nj] == 0:
                            continue

                        # 空间权重
                        spatial_dist = np.sqrt(di**2 + dj**2)
                        spatial_weight = np.exp(-spatial_dist**2 / (2 * sigma_d**2))

                        # 强度权重
                        intensity_dist = abs(depth[i, j] - depth[ni, nj])
                        intensity_weight = np.exp(-intensity_dist**2 / (2 * sigma_r**2))

                        weight = spatial_weight * intensity_weight
                        total_weight += weight
                        total_value += weight * depth[ni, nj]

                if total_weight > 0:
                    result[i, j] = total_value / total_weight
                else:
                    result[i, j] = depth[i, j]

        return result

    bilateral_depth = bilateral_depth(filled_depth)

    # 可视化
    fig, axes = plt.subplots(2, 3, figsize=(15, 10))

    axes[0, 0].imshow(true_depth, cmap='plasma', vmin=150, vmax=450)
    axes[0, 0].set_title('真实深度')
    axes[0, 0].axis('off')

    axes[0, 1].imshow(noisy_depth, cmap='plasma', vmin=150, vmax=450)
    axes[0, 1].set_title('带噪声和空洞')
    axes[0, 1].axis('off')

    axes[0, 2].imshow(filtered_depth, cmap='plasma', vmin=150, vmax=450)
    axes[0, 2].set_title('中值滤波后')
    axes[0, 2].axis('off')

    axes[1, 0].imshow(filled_depth, cmap='plasma', vmin=150, vmax=450)
    axes[1, 0].set_title('空洞填充后')
    axes[1, 0].axis('off')

    axes[1, 1].imshow(bilateral_depth, cmap='plasma', vmin=150, vmax=450)
    axes[1, 1].set_title('双边滤波后')
    axes[1, 1].axis('off')

    # 误差对比
    error_noisy = np.abs(true_depth - noisy_depth)
    error_filled = np.abs(true_depth - filled_depth)
    error_bilateral = np.abs(true_depth - bilateral_depth)

    axes[1, 2].bar(['噪声', '填充', '双边'],
                   [np.mean(error_noisy[true_depth>0]),
                    np.mean(error_filled[true_depth>0]),
                    np.mean(error_bilateral[true_depth>0])],
                   color=['red', 'orange', 'green'])
    axes[1, 2].set_ylabel('平均误差 (mm)')
    axes[1, 2].set_title('处理效果对比')
    axes[1, 2].grid(True, alpha=0.3, axis='y')

    plt.tight_layout()
    plt.show()

    print("后处理方法总结：")
    print("1. 中值滤波：去除椒盐噪声，保持边缘")
    print("2. 空洞填充：基于邻域插值")
    print("3. 双边滤波：平滑同时保持边缘")
    print("\n处理效果：")
    print(f"原始噪声误差: {np.mean(error_noisy[true_depth>0]):.2f}mm")
    print(f"填充后误差: {np.mean(error_filled[true_depth>0]):.2f}mm")
    print(f"双边滤波后误差: {np.mean(error_bilateral[true_depth>0]):.2f}mm")
```

## 三维重建

### 5.1 三角测量

#### 什么是三角测量？

**三角测量（Triangulation）** 是从两个已知相机位置拍摄的2D图像点，计算对应的3D空间点坐标的过程。

#### 数学原理

**已知条件：**
- 两个相机的投影矩阵 P₁ 和 P₂
- 左右图像中的对应点 x₁ 和 x₂

**投影方程：**
```
x₁ = P₁ X
x₂ = P₂ X
```

其中 X 是3D点的齐次坐标 [X, Y, Z, 1]ᵀ

**DLT（Direct Linear Transform）方法：**

将投影方程展开为线性方程组：

```
x₁ × (P₁ X) = 0
x₂ × (P₂ X) = 0
```

每个方程提供2个独立约束，4个方程可求解X。

**矩阵形式：**
```
A X = 0
```

通过SVD求解，取最小奇异值对应的右奇异向量。

```python
print("\n=== 三角测量 ===")

def triangulation_demo():
    """三角测量演示"""

    # 相机参数
    K = np.array([
        [500, 0, 320],
        [0, 500, 240],
        [0, 0, 1]
    ])

    # 相机位姿
    # 左相机：原点
    R1 = np.eye(3)
    t1 = np.zeros(3)

    # 右相机：沿X轴平移100mm
    R2 = np.eye(3)
    t2 = np.array([100, 0, 0])

    # 3D点
    points_3d = np.array([
        [50, 30, 200],
        [80, 40, 250],
        [20, 10, 150],
        [60, 50, 300]
    ])

    # 投影到图像
    points_left = []
    points_right = []

    for p in points_3d:
        # 左图像
        p_left = K @ (R1 @ p + t1)
        p_left = p_left / p_left[2]
        points_left.append(p_left[:2])

        # 右图像
        p_right = K @ (R2 @ p + t2)
        p_right = p_right / p_right[2]
        points_right.append(p_right[:2])

    points_left = np.array(points_left)
    points_right = np.array(points_right)

    # 三角测量（从2D点恢复3D）
    def triangulate(left_pts, right_pts, K, R1, t1, R2, t2):
        """DLT三角测量"""
        points_3d_reconstructed = []

        for i in range(len(left_pts)):
            # 构建投影矩阵 P = K[R|t]
            P1 = K @ np.hstack([R1, t1.reshape(3, 1)])
            P2 = K @ np.hstack([R2, t2.reshape(3, 1)])

            # DLT
            x1, y1 = left_pts[i]
            x2, y2 = right_pts[i]

            A = np.array([
                [x1 * P1[2, 0] - P1[0, 0], x1 * P1[2, 1] - P1[0, 1],
                 x1 * P1[2, 2] - P1[0, 2], x1 * P1[2, 3] - P1[0, 3]],
                [y1 * P1[2, 0] - P1[1, 0], y1 * P1[2, 1] - P1[1, 1],
                 y1 * P1[2, 2] - P1[1, 2], y1 * P1[2, 3] - P1[1, 3]],
                [x2 * P2[2, 0] - P2[0, 0], x2 * P2[2, 1] - P2[0, 1],
                 x2 * P2[2, 2] - P2[0, 2], x2 * P2[2, 3] - P2[0, 3]],
                [y2 * P2[2, 0] - P2[1, 0], y2 * P2[2, 1] - P2[1, 1],
                 y2 * P2[2, 2] - P2[1, 2], y2 * P2[2, 3] - P2[1, 3]]
            ])

            # SVD求解
            U, S, Vt = np.linalg.svd(A)
            X = Vt[-1, :4]
            X = X / X[3]

            points_3d_reconstructed.append(X[:3])

        return np.array(points_3d_reconstructed)

    # 执行三角测量
    points_3d_rec = triangulate(points_left, points_right, K, R1, t1, R2, t2)

    # 可视化
    fig = plt.figure(figsize=(14, 6))

    # 3D重建结果
    ax1 = fig.add_subplot(1, 2, 1, projection='3d')

    # 原始点
    ax1.scatter(points_3d[:, 0], points_3d[:, 1], points_3d[:, 2],
               c='blue', s=100, marker='o', label='原始3D点')

    # 重建点
    ax1.scatter(points_3d_rec[:, 0], points_3d_rec[:, 1], points_3d_rec[:, 2],
               c='red', s=80, marker='x', label='重建3D点')

    # 连接线（误差）
    for i in range(len(points_3d)):
        ax1.plot([points_3d[i, 0], points_3d_rec[i, 0]],
                 [points_3d[i, 1], points_3d_rec[i, 1]],
                 [points_3d[i, 2], points_3d_rec[i, 2]],
                 'g--', alpha=0.5)

    # 相机
    ax1.scatter([0], [0], [0], c='blue', s=100, marker='^', label='左相机')
    ax1.scatter([100], [0], [0], c='green', s=100, marker='^', label='右相机')

    ax1.set_xlabel('X (mm)')
    ax1.set_ylabel('Y (mm)')
    ax1.set_zlabel('Z (mm)')
    ax1.set_title('三角测量重建结果')
    ax1.legend()
    ax1.grid(True, alpha=0.3)

    # 误差分析
    errors = np.linalg.norm(points_3d - points_3d_rec, axis=1)

    ax2 = fig.add_subplot(1, 2, 2)
    bars = ax2.bar(range(1, len(errors)+1), errors, color='steelblue')
    ax2.set_xlabel('点索引')
    ax2.set_ylabel('重建误差 (mm)')
    ax2.set_title('三角测量误差分析')
    ax2.grid(True, alpha=0.3, axis='y')

    # 添加数值标签
    for bar, error in zip(bars, errors):
        height = bar.get_height()
        ax2.text(bar.get_x() + bar.get_width()/2., height + 0.1,
                f'{error:.2f}', ha='center', va='bottom', fontsize=9)

    plt.tight_layout()
    plt.show()

    print("三角测量结果：")
    for i in range(len(points_3d)):
        print(f"点{i+1}:")
        print(f"  原始: {points_3d[i]}")
        print(f"  重建: {points_3d_rec[i]}")
        print(f"  误差: {errors[i]:.3f}mm")

    print(f"\n平均重建误差: {np.mean(errors):.3f}mm")

triangulation_demo()
```

**代码解析：**
- 已知：相机位姿和图像对应点
- 计算：投影矩阵 P₁ 和 P₂

**误差来源：**
1. **图像噪声**：像素定位误差

4. **量化误差**：有限精度计算

### 5.2 多视角立体重建

#### 为什么要多视角？

双目立体视觉的局限：
- 遮挡问题：某些区域在一幅图像中可见，在另一幅中不可见
- 纹理贫乏：单一基线可能无法匹配
- 精度限制：单次测量误差大

多视角优势：
- 提高鲁棒性：多个匹配机会
- 提高精度：多约束优化
- 完整重建：覆盖更多区域

#### 多视角重建流程

**1. 图像采集**
- 多个相机或单相机多位置
- 覆盖目标区域
- 保持重叠

**2. 特征匹配**
- 跨视角特征检测
- 多对多匹配
- RANSAC剔除外点

**3. 三角测量**
- 对每对匹配计算3D点
- 融合多视角结果

**4. 光束法平差（Bundle Adjustment）**
- 联合优化3D点和相机位姿
- 最小化重投影误差

**5. 稠密重建**
- 稠密匹配
- 点云生成
- 表面重建

```python
print("\n=== 多视角立体重建 ===")

def multi_view_stereo():
    """多视角立体重建演示"""

    # 模拟多视角图像
    def create_multi_view_images():
        """创建多视角图像"""
        h, w = 100, 100

        # 3D物体（立方体）
        cube_size = 30
        cube_center = np.array([0, 0, 100])

        # 相机位置（环绕）
        num_views = 6
        angles = np.linspace(0, 2*np.pi, num_views, endpoint=False)

        images = []
        poses = []

        for angle in angles:
            # 相机位置（圆形轨迹）
            cam_pos = np.array([50 * np.cos(angle), 50 * np.sin(angle), 0])

            # 相机朝向中心
            forward = cube_center - cam_pos
            forward = forward / np.linalg.norm(forward)

            # 构建相机坐标系
            up = np.array([0, 0, 1])
            right = np.cross(forward, up)
            right = right / np.linalg.norm(right)
            up = np.cross(right, forward)

            R = np.vstack([right, up, forward]).T
            t = -R @ cam_pos

            # 投影立方体顶点
            cube_vertices = []
            for dx in [-cube_size/2, cube_size/2]:
                for dy in [-cube_size/2, cube_size/2]:
                    for dz in [-cube_size/2, cube_size/2]:
                        cube_vertices.append(cube_center + np.array([dx, dy, dz]))
            cube_vertices = np.array(cube_vertices)

            # 投影到图像
            img = np.zeros((h, w), dtype=np.uint8)
            K = np.array([[300, 0, w/2], [0, 300, h/2], [0, 0, 1]])

            projected = []
            for v in cube_vertices:
                # 世界到相机
                v_cam = R @ v + t
                if v_cam[2] > 0:  # 在相机前方
                    # 相机到图像
                    v_img = K @ v_cam
                    v_img = v_img / v_img[2]
                    if 0 <= v_img[0] < w and 0 <= v_img[1] < h:
                        projected.append(v_img[:2])
                        img[int(v_img[1]), int(v_img[0])] = 255

            # 绘制轮廓
            if len(projected) > 0:
                projected = np.array(projected)
                min_x, max_x = int(projected[:, 0].min()), int(projected[:, 0].max())
                min_y, max_y = int(projected[:, 1].min()), int(projected[:, 1].max())
                img[min_y:max_y+1, min_x:max_x+1] = 200

            images.append(img)
            poses.append((R, t))

        return images, poses, K

    images, poses, K = create_multi_view_images()

    # 简化的多视角匹配
    def multi_view_matching(images, poses, K):
        """多视角特征匹配"""

        # 提取特征（简化：使用角点）
        all_features = []

        for img in images:
            # 使用Shi-Tomasi检测角点
            corners = cv2.goodFeaturesToTrack(img.astype(np.uint8), maxCorners=20,
                                             qualityLevel=0.01, minDistance=5)
            if corners is not None:
                corners = corners.reshape(-1, 2)
            else:
                corners = np.array([])
            all_features.append(corners)

        # 匹配特征
        matches = []
        for i in range(len(images)):
            for j in range(i+1, len(images)):
                if len(all_features[i]) > 0 and len(all_features[j]) > 0:
                    # 简单最近邻匹配
                    for fi, f1 in enumerate(all_features[i]):
                        distances = np.linalg.norm(all_features[j] - f1, axis=1)
                        if len(distances) > 0:
                            min_idx = np.argmin(distances)
                            if distances[min_idx] < 10:  # 阈值
                                matches.append({
                                    'view1': i,
                                    'view2': j,
                                    'pt1': f1,
                                    'pt2': all_features[j][min_idx],
                                    'dist': distances[min_idx]
                                })

        return matches, all_features

    matches, features = multi_view_matching(images, poses, K)

    # 可视化
    fig, axes = plt.subplots(2, 3, figsize=(15, 10))

    for i in range(min(6, len(images))):
        ax = axes[i//3, i%3]
        ax.imshow(images[i], cmap='gray', vmin=0, vmax=255)

        # 绘制特征点
        if len(features[i]) > 0:
```

```python
"""
练习1：完整立体匹配流程

目标：实现从立体图像对到深度图的完整流程

任务：
1. 创建立体图像对
2. 实现块匹配算法
3. 视差图转深度图
4. 后处理优化
5. 评估精度
"""

def practice1_stereo_pipeline():
    print("="*60)
    print("练习1：完整立体匹配流程")
    print("="*60)

    # 1. 创建立体图像对
    def create_test_scene():
        h, w = 120, 160
        left = np.zeros((h, w), dtype=np.uint8)

        # 添加不同深度的物体
        # 近处（大视差）
        left[30:50, 40:60] = 200
        # 中等
        left[70:90, 90:110] = 150
        # 远处（小视差）
        left[50:70, 130:150] = 100

        # 添加纹理
        for i in range(0, h, 8):
            left[i:i+2, :] = 30

        left = add_gaussian_noise(left, sigma=10)

        # 视差图
        disp = np.zeros((h, w))
        disp[30:50, 40:60] = 12
        disp[70:90, 90:110] = 7
        disp[50:70, 130:150] = 3

        # 右图像
        right = np.zeros((h, w), dtype=np.uint8)
        for i in range(h):
            for j in range(w):
                d = disp[i, j]
                if j - d >= 0:
                    right[i, j] = left[i, int(j - d)]
                else:
                    right[i, j] = left[i, j]

        right = add_gaussian_noise(right, sigma=5)

        return left, right, disp

    left_img, right_img, true_disp = create_test_scene()

    # 2. 立体匹配
    def stereo_match(left, right, win=5, max_d=20):
        h, w = left.shape
        disp = np.zeros((h, w))
        pad = win // 2

        for i in range(pad, h-pad):
            for j in range(pad, w-pad):
                left_patch = left[i-pad:i+pad+1, j-pad:j+pad+1]
                best_d, best_cost = 0, float('inf')

                for d in range(min(max_d, j-pad)):
                    if j-d-pad >= 0:
                        right_patch = right[i-pad:i+pad+1, j-d-pad:j-d+pad+1]
                        cost = np.sum(np.abs(left_patch - right_patch))
                        if cost < best_cost:
                            best_cost, best_d = cost, d
                disp[i, j] = best_d
        return disp

    estimated_disp = stereo_match(left_img, right_img)

    # 3. 视差转深度
    baseline = 100
    focal_length = 500
    depth_map = np.zeros_like(estimated_disp)
    valid = estimated_disp > 0.1
    depth_map[valid] = (baseline * focal_length) / estimated_disp[valid]

    # 4. 后处理
    from scipy.ndimage import median_filter
    depth_filtered = median_filter(depth_map, size=3)

    # 5. 评估
    error = np.abs(true_disp - estimated_disp)
    mean_error = np.mean(error[error > 0])
    correct_rate = np.sum(error < 1) / np.sum(error > 0) * 100

    # 可视化
    fig, axes = plt.subplots(2, 3, figsize=(15, 10))

    axes[0, 0].imshow(left_img, cmap='gray', vmin=0, vmax=255)
    axes[0, 0].set_title('左图像')
    axes[0, 0].axis('off')

    axes[0, 1].imshow(right_img, cmap='gray', vmin=0, vmax=255)
    axes[0, 1].set_title('右图像')
    axes[0, 1].axis('off')

    axes[0, 2].imshow(true_disp, cmap='jet', vmin=0, vmax=15)
    axes[0, 2].set_title('真实视差')
    axes[0, 2].axis('off')

    axes[1, 0].imshow(estimated_disp, cmap='jet', vmin=0, vmax=15)
    axes[1, 0].set_title(f'估计视差\\n误差:{mean_error:.2f}')
    axes[1, 0].axis('off')

    axes[1, 1].imshow(depth_map, cmap='plasma')
    axes[1, 1].set_title('深度图')
    axes[1, 1].axis('off')

    axes[1, 2].imshow(depth_filtered, cmap='plasma')
    axes[1, 2].set_title('滤波后深度')
    axes[1, 2].axis('off')

    plt.tight_layout()
    plt.show()

    print(f"\n结果统计：")
    print(f"平均视差误差: {mean_error:.3f} 像素")
    print(f"正确率(<1像素): {correct_rate:.1f}%")
    print(f"处理图像尺寸: {left_img.shape}")
```

```python
"""
练习2：极线几何验证

目标：验证极线约束并理解其在立体匹配中的作用

任务：
1. 生成3D点和相机位姿
2. 计算基础矩阵
3. 验证极线约束
4. 可视化极线
"""

def practice2_epipolar_validation():
    print("="*60)
    print("练习2：极线几何验证")
    print("="*60)

    # 相机参数
    K = np.array([
        [800, 0, 320],
        [0, 800, 240],
        [0, 0, 1]
    ])

    # 相机位姿
    t = np.array([150, 0, 0])  # 基线
    R = np.eye(3)

    # 生成3D点
    np.random.seed(42)
    points_3d = np.random.uniform(-50, 50, (20, 3))
    points_3d[:, 2] += 200  # Z > 0

    # 投影到左右图像
    points_left = []
    points_right = []

    for p in points_3d:
        # 左图像
        p_left = K @ p
        p_left = p_left / p_left[2]
        points_left.append(p_left[:2])

        # 右图像
        p_right = K @ (R @ p + t)
        p_right = p_right / p_right[2]
        points_right.append(p_right[:2])

    points_left = np.array(points_left)
    points_right = np.array(points_right)

    # 计算基础矩阵
    def compute_fundamental(pts1, pts2):
        """8点法计算基础矩阵"""
        # 归一化
        mean1 = np.mean(pts1, axis=0)
        mean2 = np.mean(pts2, axis=0)
        std1 = np.mean(np.sqrt(np.sum((pts1 - mean1)**2, axis=1)))
        std2 = np.mean(np.sqrt(np.sum((pts2 - mean2)**2, axis=1)))

        T1 = np.array([
            [1/std1, 0, -mean1[0]/std1],
            [0, 1/std1, -mean1[1]/std1],
            [0, 0, 1]
        ])
        T2 = np.array([
            [1/std2, 0, -mean2[0]/std2],
            [0, 1/std2, -mean2[1]/std2],
            [0, 0, 1]
        ])

        pts1_norm = np.hstack([pts1, np.ones((len(pts1), 1))]).T
        pts2_norm = np.hstack([pts2, np.ones((len(pts2), 1))]).T

        pts1_norm = T1 @ pts1_norm
        pts2_norm = T2 @ pts2_norm

        # 构建A矩阵
        A = np.zeros((len(pts1), 9))
        for i in range(len(pts1)):
            x1, y1, w1 = pts1_norm[:, i]
            x2, y2, w2 = pts2_norm[:, i]
            A[i] = [x1*x2, x1*y2, x1*w1, y1*x2, y1*y2, y1*w1, w1*x2, w1*y2, w1*w1]

        # SVD求解
        U, S, Vt = np.linalg.svd(A)
        F_norm = Vt[-1].reshape(3, 3)

        # 强制秩为2
        U, S, Vt = np.linalg.svd(F_norm)
        S[2] = 0
        F_norm = U @ np.diag(S) @ Vt

        # 反归一化
        F = T2.T @ F_norm @ T1

        return F

    F = compute_fundamental(points_left, points_right)

    print("计算得到的基础矩阵 F:")
    print(F)

    # 验证极线约束
    print("\n验证极线约束 (x2^T * F * x1 = 0):")
    errors = []
    for i in range(len(points_left)):
        x1 = np.append(points_left[i], 1)
        x2 = np.append(points_right[i], 1)
        constraint = x2.T @ F @ x1
        errors.append(abs(constraint))
        print(f"点{i+1:2d}: {constraint:10.6f}")

    print(f"\n平均误差: {np.mean(errors):.6f}")

    # 可视化
    fig, axes = plt.subplots(1, 2, figsize=(12, 5))

    # 左图像
    axes[0].scatter(points_left[:, 0], points_left[:, 1],
                   c='blue', s=50, marker='o', label='左图像点')

    # 绘制右极线（通过左图像点）
    for i, x1 in enumerate(points_left):
        x1_h = np.append(x1, 1)
        l = F @ x1_h
        a, b, c = l

        # 极线
        y_vals = np.linspace(100, 380, 100)
        if abs(b) > 1e-6:
            x_vals = -(a * y_vals + c) / b
            axes[0].plot(x_vals, y_vals, 'g--', alpha=0.3, linewidth=0.5)

    axes[0].set_xlim(150, 490)
    axes[0].set_ylim(100, 380)
    axes[0].set_xlabel('u (像素)')
    axes[0].set_ylabel('v (像素)')
    axes[0].set_title('左图像 + 右极线')
    axes[0].legend()
    axes[0].grid(True, alpha=0.3)

    # 右图像
    axes[1].scatter(points_right[:, 0], points_right[:, 1],
                   c='red', s=50, marker='x', label='右图像点')

    # 绘制左极线（通过右图像点）
    for i, x2 in enumerate(points_right):
        x2_h = np.append(x2, 1)
        # l^T * x2 = 0 => l = F^T * x2
        l = F.T @ x2_h
        a, b, c = l

        y_vals = np.linspace(100, 380, 100)
        if abs(b) > 1e-6:
            x_vals = -(a * y_vals + c) / b
            axes[1].plot(x_vals, y_vals, 'b--', alpha=0.3, linewidth=0.5)

    axes[1].set_xlim(150, 490)
    axes[1].set_ylim(100, 380)
    axes[1].set_xlabel('u (像素)')
    axes[1].set_ylabel('v (像素)')
    axes[1].set_title('右图像 + 左极线')
    axes[1].legend()
    axes[1].grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

    print("\n极线几何要点：")
    print("✓ 基础矩阵F描述了极线约束关系")
    print("✓ 极线约束：对应点在极线上")
    print("✓ 立体匹配时，搜索范围从2D降为1D")
    print("✓ 极线通过极点（相机中心投影）")
```

```python
"""
练习3：深度图质量评估

目标：评估深度图的质量并分析误差来源

任务：
1. 生成不同质量的深度图
2. 计算多种评估指标
3. 分析误差分布
4. 提出改进方案
"""

def practice3_depth_quality_assessment():
    print("="*60)
    print("练习3：深度图质量评估")
    print("="*60)

    # 创建真实深度图
    h, w = 150, 150
    true_depth = np.zeros((h, w))

    # 分区深度
    y, x = np.ogrid[:h, :w]
    center_dist = np.sqrt((x - w/2)**2 + (y - h/2)**2)

    true_depth[center_dist < 30] = 150  # 近
    true_depth[(center_dist >= 30) & (center_dist < 60)] = 250  # 中
    true_depth[(center_dist >= 60) & (center_dist < 90)] = 350  # 远

    # 生成不同质量的深度图
    # 1. 完美
    depth_perfect = true_depth.copy()

    # 2. 带噪声
    depth_noisy = true_depth + np.random.normal(0, 10, (h, w))

    # 3. 带空洞
    depth_holes = true_depth.copy()
    hole_mask = np.random.random((h, w)) < 0.15
    depth_holes[hole_mask] = 0

    # 4. 边缘模糊
    depth_blurred = gaussian_filter(true_depth, sigma=2)

    # 评估函数
    def evaluate_depth(depth_pred, depth_true):
        """评估深度图质量"""
        valid_mask = depth_true > 0

        # 1. 均方根误差
        rmse = np.sqrt(np.mean((depth_pred[valid_mask] - depth_true[valid_mask])**2))

        # 2. 平均绝对误差
        mae = np.mean(np.abs(depth_pred[valid_mask] - depth_true[valid_mask]))

        # 3. 相对误差
        rel = np.mean(np.abs(depth_pred[valid_mask] - depth_true[valid_mask]) / depth_true[valid_mask])

        # 4. 空洞率
        hole_rate = np.sum(depth_pred == 0) / np.sum(valid_mask)

        # 5. 保留率（<1.25倍）
        threshold = 1.25
        accurate = np.sum((depth_pred[valid_mask] / depth_true[valid_mask] <= threshold) &
                         (depth_true[valid_mask] / depth_pred[valid_mask] <= threshold))
        accuracy = accurate / np.sum(valid_mask)

        return {
            'RMSE': rmse,
            'MAE': mae,
            'Rel': rel,
            'Hole': hole_rate,
            'Accuracy': accuracy
        }

    # 评估所有
    metrics = {
        '完美': evaluate_depth(depth_perfect, true_depth),
        '带噪声': evaluate_depth(depth_noisy, true_depth),
        '带空洞': evaluate_depth(depth_holes, true_depth),
        '边缘模糊': evaluate_depth(depth_blurred, true_depth)
    }

    # 可视化
    fig, axes = plt.subplots(3, 4, figsize=(16, 12))

    depth_maps = [depth_perfect, depth_noisy, depth_holes, depth_blurred]
    titles = ['完美', '带噪声', '带空洞', '边缘模糊']

    # 显示深度图
    for idx, (depth, title) in enumerate(zip(depth_maps, titles)):
        im = axes[0, idx].imshow(depth, cmap='plasma', vmin=100, vmax=400)
        axes[0, idx].set_title(f'{title}\\n深度图')
        axes[0, idx].axis('off')
        plt.colorbar(im, ax=axes[0, idx], fraction=0.046)

    # 显示误差图
    for idx, (depth, title) in enumerate(zip(depth_maps, titles)):
        error = np.abs(depth - true_depth)
        im = axes[1, idx].imshow(error, cmap='hot', vmin=0, vmax=50)
        axes[1, idx].set_title(f'误差图\\n均值={np.mean(error):.1f}mm')
        axes[1, idx].axis('off')
        plt.colorbar(im, ax=axes[1, idx], fraction=0.046)

    # 显示误差分布
    for idx, (depth, title) in enumerate(zip(depth_maps, titles)):
        error = (depth - true_depth).flatten()
        error = error[error != 0]  # 移除空洞
        axes[2, idx].hist(error, bins=30, alpha=0.7, color='steelblue', range=(-50, 50))
        axes[2, idx].axvline(x=0, color='red', linestyle='--', alpha=0.5)
        axes[2, idx].set_title('误差分布')
        axes[2, idx].set_xlabel('误差')
        axes[2, idx].grid(True, alpha=0.3)

    plt.tight_layout()
    plt.show()

    # 打印评估结果
    print("\n深度图质量评估结果：")
    print(f"{'方法':<10} {'RMSE':<8} {'MAE':<8} {'相对误差':<8} {'空洞率':<8} {'准确率':<8}")
    print("-" * 60)
    for name, metric in metrics.items():
        print(f"{name:<10} {metric['RMSE']:<8.2f} {metric['MAE']:<8.2f} "
              f"{metric['Rel']:<8.3f} {metric['Hole']:<8.3f} {metric['Accuracy']:<8.3f}")

    print("\n质量分析：")
    print("1. RMSE：整体误差水平")
    print("2. MAE：平均绝对误差")
    print("3. 相对误差：与真实深度的比例")
    print("4. 空洞率：缺失数据比例")
    print("5. 准确率：<1.25倍的比例")

    print("\n改进方向：")
    print("- 噪声：使用滤波、多帧平均")
    print("- 空洞：插值、区域生长")
    print("- 边缘：双边滤波、引导滤波")
```
