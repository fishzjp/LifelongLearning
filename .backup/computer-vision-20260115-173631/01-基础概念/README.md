**从零开始讲解计算机视觉必需的数学知识**

- **概率统计**：概率=可能性、贝叶斯=推理、分布=规律
- **实践练习**：4个动手练习，每个都有详细提示

- **图像格式对比**：PNG vs JPEG，何时用哪个
- **基础操作**：读写、缩放、旋转、调色
- **实践练习**：4个综合练习

**特点**：
- ✅ 从"手机拍照"引入，贴近生活

- ✅ 格式对比有实际文件大小数据
- ✅ 操作演示有前后对比图
- ✅ 练习题有完整代码框架

## 🎯 学习路径建议

### 第一阶段：数学基础（1-2天）

1. 复习线性代数核心概念
2. 理解梯度和链式法则
3. 掌握基本的概率统计知识
4. 完成练习题

### 第二阶段：编程基础（2-3天）

1. 熟悉NumPy数组操作
2. 掌握Pandas数据处理
3. 学习Matplotlib绘图
4. 了解OpenCV基本用法
5. 完成编程练习

### 第三阶段：图像概念（2-3天）

1. 理解像素和分辨率
2. 掌握色彩空间转换
3. 熟悉图像格式特点
4. 练习基础图像操作
5. 完成综合练习

## 📝 学习建议

### 理论学习

- **不要跳过数学**：虽然枯燥，但很重要
- **理解而非记忆**：理解原理才能灵活应用
- **多做笔记**：记录关键概念和公式

### 编程实践

- **动手写代码**：不要只看不练
- **从简单开始**：先实现基础功能，再优化
- **调试技巧**：学会使用print和断点调试

### 图像处理

- **可视化**：多画图理解处理效果
- **参数实验**：尝试不同参数观察变化
- **实际应用**：用真实图像练习
