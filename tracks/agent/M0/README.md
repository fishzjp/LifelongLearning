# M0 · 懂并用 AI 编程助手

> **过关后你能**：向别人讲清 AI 编程助手为什么能读代码改文件（Agent 循环 + 上下文工程）；亲手写一个能被触发的 skill，并按"渐进式披露"设计它的结构。

**前置**：会用一个 AI 编程工具（TRAE/Claude Code/Cursor 任一）；想看懂代码示例需一点编程基础，但比喻层人人可读。
**投入**：每周 6h 约 1-2 周。

## 项目：写一个自己的 skill

选一个你重复做的任务（周报格式、代码规范检查、部署检查单…），做一个能触发、能干活的 skill。

**验收标准**：
- description 写明"做什么 + 何时触发"，能被模型稳定命中（测 5 次中 4 次）
- 正文遵循渐进式披露：索引常驻，细节按需
- 有至少一个 scripts/ 脚本代替模型重复写代码
- 附一页"踩坑记录"：哪次没触发、为什么、怎么修的 description
