## 项目：完整测试计划

选一个你熟悉的小型产品（或开源 App），产出 [test-strategy](../../../references/templates/test-strategy.md) 格式的完整测试计划。

**验收标准**：
- 范围里有明确的"不测什么"及理由
- 风险评估与优先级对应（高风险功能分到更多用例）
- 有准入/准出标准（什么时候能开始测、什么时候算测完）
- 工作量估算能自圆其说
