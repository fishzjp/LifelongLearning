> **过关后你能**：把测试嵌进 CI/CD 流水线；为一个系统设计整体测试架构；带团队时建立度量而不误伤质量。从执行者到设计者的最后一关。

**前置**：T1、T2 过关（或 2 年以上测试经验直接进入）。
**投入**：约 3 周。

## 项目：完整测试方案设计

选一个中等规模系统（或 L6 的案例场景），产出端到端测试方案。

**验收标准**：
- 有分层策略（单测/接口/UI 的比例与理由）
- 有 CI 集成设计（哪一步跑什么、门禁卡什么指标）
- 有度量指标及"这个指标可能如何被 gaming"的分析
- 对照 L5 反模式清单自查并说明规避方式

## 过关清单

- [ ] 解释测试金字塔为什么底座是单测而不是 UI 测试
- [ ] 设计一条"提交即触发"的流水线并说明各阶段时长预算
- [ ] 对"缺陷逃逸率"指标给出一个反例（它什么时候会误导团队）
- [ ] 项目四条验收全过
- [ ] 读 L6 两个案例，各写 3 条"如果是我会怎么做不同"的笔记
