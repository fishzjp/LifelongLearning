## 项目：自动化脚本套件

对一个公开网站（或本地起的 demo 站）建一套可重复运行的自动化。

**验收标准**：
- 覆盖一条核心业务流（登录 → 操作 → 登出）
- 采用 Page Object 分层，不是一坨线性脚本
- 一条命令跑完全部用例并出报告（pytest + allure 或 HTML 报告）
- 断言失败时报告足以定位问题

## 过关清单

- [ ] 说清自动化适合回归与冒烟、不适合探索性测试的原因
- [ ] 写出三层定位策略（id > css > xpath）并解释为什么
- [ ] 用 pytest fixture 管理登录态，避免每个用例重复登录
- [ ] 接口测试覆盖正常、边界、异常三组场景
- [ ] 读懂 JMeter 报告的 TPS、响应时间分位线，指出瓶颈迹象
- [ ] 项目四条验收全过
