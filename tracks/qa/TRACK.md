# 测试轨道 · 建立找缺陷的系统方法

**学会的标志**：拿到任何一个被测系统，你能独立产出"测试策略 → 用例集 → 执行与缺陷跟踪 → 自动化补充"的完整交付，并让开发信服你的缺陷报告。

**适合谁**：零基础转行者（从 T0 开始，最快 3 个月可求职）、在职手工测试工程师（直接进 T2 补自动化）、开发/架构师（读 T0 + T3 理解可测试性）。
**投入**：每周 8h，T0-T2 约 3 个月（求职最低配置）；全程约 5 个月。

## 路径变体

- **转行求职**：T0 → T1 → T2（自动化+接口两篇必学）+ [practice/](practice/README.md) 四个练习全部做完——那就是你的面试作品集。
- **在职手工测试**：直接 T2，Python 生疏先看 [prep/python/](../../prep/python/Python入门.md) 前半部分。
- **开发转测试 / 提升可测试性**：T0（建立语言）→ T3（架构与左移）。

## 动手原则

本轨道的每过一关都要"拿真实 App 练"：用例方法学一个，立刻在身边的 App（登录页、购物车）上用一个。看懂和会设计之间隔着一次独立练习。
