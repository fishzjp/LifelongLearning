# M0 · 让计算机看见

> **过关后你能**：解释"图像就是数字矩阵"，独立完成"读图 → 处理 → 保存"的完整流程，并训练出你的第一个图像分类器（MNIST，准确率 98%+）。

**前置**：无（Python/数学不熟 → 按需进 [prep/](../../../prep/README.md)）。
**投入**：每周 8h 约 2-3 周。

## 课表

| # | 课 | 学完你能 | 
| --- | --- | --- |
| L1 | [图像即矩阵](L01-图像即矩阵.md) | 说清像素、分辨率、色彩空间、存储格式 |
| L2 | [图像基础操作](L02-图像基础操作.md) | 用 OpenCV 完成读存裁转、画框写字（BGR 陷阱！） |
| L3 | [第一个程序](L03-第一个程序.md) | 10 分钟跑通 CV Hello World |

学完 L1-L3 停一下：**用自己的一张照片**跑完"读入 → 转灰度 → 缩放 → 加文字 → 保存"。

## 项目：MNIST 手写数字分类器

完整步骤见 [PROJECT-MNIST](PROJECT-MNIST.md)。这是本库的第一个作品——代码不到 100 行，但它就是所有深度学习项目的骨架。

**验收标准**：
- 测试集准确率 ≥ 98%
- 能向别人解释代码里每个模块（DataLoader/Model/Train/Eval）在干什么
- 故意把学习率改大 100 倍，观察并解释发生了什么
