## Hello World程序
### 完整代码
创建文件 `hello_world.py`：

```python

# 依赖: cv2, matplotlib, numpy
# 安装: pip install cv2 matplotlib numpy
import cv2
import numpy as np

print("=== 计算机视觉 Hello World ===\n")

# 1. 读取图像
print("1️⃣ 读取图像...")
img = cv2.imread('test_image.jpg')

if img is None:
    print("❌ 错误：无法读取图像，请检查文件路径")
    exit()

print(f"   ✅ 图像尺寸: {img.shape}")
print(f"   📊 图像大小: {img.size} 像素")

# 2. 转换为灰度图
print("\n2️⃣ 转换为灰度图...")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
print(f"   ✅ 灰度图尺寸: {gray.shape}")

# 3. 调整图像尺寸
print("\n3️⃣ 调整图像尺寸...")
resized = cv2.resize(img, (200, 200))
print(f"   ✅ 调整后尺寸: {resized.shape}")

# 4. 保存处理后的图像
print("\n4️⃣ 保存处理后的图像...")
cv2.imwrite('gray_image.jpg', gray)
cv2.imwrite('resized_image.jpg', resized)
print("   ✅ 已保存: gray_image.jpg")
print("   ✅ 已保存: resized_image.jpg")

# 5. 显示图像（可选）
print("\n5️⃣ 显示图像...")
print("   💡 提示：按任意键关闭窗口")

# 创建一个2x2的网格显示所有图像
import matplotlib.pyplot as plt

fig, axes = plt.subplots(2, 2, figsize=(10, 10))

# 原始图像
axes[0, 0].imshow(cv2.cvtColor(img, cv2.COLOR_BGR2RGB))
axes[0, 0].set_title('原始图像')
axes[0, 0].axis('off')

# 灰度图
axes[0, 1].imshow(gray, cmap='gray')
axes[0, 1].set_title('灰度图')
axes[0, 1].axis('off')

# 调整尺寸后的图像
axes[1, 0].imshow(cv2.cvtColor(resized, cv2.COLOR_BGR2RGB))
axes[1, 0].set_title('调整尺寸 (200x200)')
axes[1, 0].axis('off')

# 隐藏最后一个子图
axes[1, 1].axis('off')

plt.tight_layout()
plt.savefig('hello_world_result.png', dpi=100, bbox_inches='tight')
print("   ✅ 结果图已保存: hello_world_result.png")

# 如果在Jupyter中运行，可以直接显示
# plt.show()
print("\n🎉 Hello World 完成！")
```

## 代码说明
### 1. 读取图像 `cv2.imread()`
```python
img = cv2.imread('test_image.jpg')
```

**参数说明**:
- `test_image.jpg`: 图像文件路径
- 返回值: NumPy数组，形状为 (height, width, channels)
  - height: 图像高度（像素）
  - width: 图像宽度（像素）
  - channels: 通道数（3表示BGR彩色图）

**关键点**:
- OpenCV默认使用**BGR**格式（蓝-绿-红），不是RGB
- 如果读取失败，返回 `None`

### 2. 转换为灰度图 `cv2.cvtColor()`
```python
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
```

**作用**: 将彩色图像转换为灰度图像

**转换公式**:
$$Gray = 0.299 \times R + 0.587 \times G + 0.114 \times B$$

**为什么需要灰度图？**
- 减少数据量（3通道→1通道）
- 简化后续处理
- 许多算法只需要灰度信息

### 3. 调整图像尺寸 `cv2.resize()`
```python
resized = cv2.resize(img, (200, 200))
```

**参数说明**:
- `(200, 200)`: 目标尺寸 (width, height)
- 返回值: 调整后的图像

**常用场景**:
- 统一不同图像的尺寸
- 降低计算量
- 适应网络输入要求

### 4. 保存图像 `cv2.imwrite()`
```python
cv2.imwrite('output.jpg', image)
```

**格式支持**:
- JPEG: `.jpg`, `.jpeg` (有损压缩)
- PNG: `.png` (无损压缩)
- BMP: `.bmp` (无压缩)

## 理解图像数据
### 图像是数字数组
```python

# 依赖: numpy
# 安装: pip install numpy
import numpy as np

# 创建一个简单的3x3彩色图像
img = np.array([
    [[255, 0, 0], [0, 255, 0], [0, 0, 255]],  # 第一行：红、绿、蓝
    [[255, 255, 0], [255, 0, 255], [0, 255, 255]],  # 第二行：黄、品红、青
    [[255, 255, 255], [128, 128, 128], [0, 0, 0]]  # 第三行：白、灰、黑
], dtype=np.uint8)

print("图像形状:", img.shape)  # (3, 3, 3) - 3行3列3通道
print("第一个像素:", img[0, 0])  # [255, 0, 0] - 蓝色=255, 绿色=0, 红色=0
```

### 访问图像像素
```python
# 获取像素值
pixel = img[0, 0]  # 第一个像素的BGR值
print(f"像素值: {pixel}")  # [255, 0, 0] = 蓝色

# 修改像素值
img[0, 0] = [0, 0, 255]  # 改为红色

# 获取单个通道
blue_channel = img[0, 0, 0]  # 蓝色通道
green_channel = img[0, 0, 1]  # 绿色通道
red_channel = img[0, 0, 2]  # 红色通道
```

## 常见操作示例
### 1. 裁剪图像
```python
# 裁剪图像中心区域
h, w = img.shape[:2]
crop_h, crop_w = h // 2, w // 2

start_y, start_x = (h - crop_h) // 2, (w - crop_w) // 2
cropped = img[start_y:start_y+crop_h, start_x:start_x+crop_w]

cv2.imwrite('cropped.jpg', cropped)
print(f"✅ 裁剪后尺寸: {cropped.shape}")
```

### 2. 旋转图像
```python
# 旋转90度
rotated_90 = cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE)

# 旋转180度
rotated_180 = cv2.rotate(img, cv2.ROTATE_180)

cv2.imwrite('rotated_90.jpg', rotated_90)
print("✅ 图像已旋转")
```

### 3. 翻转图像
```python
# 水平翻转
flipped_h = cv2.flip(img, 1)

# 垂直翻转
flipped_v = cv2.flip(img, 0)

# 同时水平垂直翻转
flipped_hv = cv2.flip(img, -1)

cv2.imwrite('flipped_horizontal.jpg', flipped_h)
print("✅ 图像已翻转")
```

### 4. 调整亮度
```python
# 增加亮度
brightened = cv2.convertScaleAbs(img, alpha=1, beta=50)
# alpha: 对比度（1表示不变）
# beta: 亮度（正值增加，负值减少）
cv2.imwrite('brightened.jpg', brightened)
print("✅ 亮度已调整")
```

## 常见问题
### Q1: cv2.imread返回None？
**原因**: 文件路径错误或文件不存在

**解决方案**:
```python
# 检查文件是否存在
import os
print(os.path.exists('test_image.jpg'))  # 应该返回True

# 使用绝对路径
img = cv2.imread('/完整路径/test_image.jpg')

# 或使用相对路径
img = cv2.imread('./test_image.jpg')
```

### Q2: 图像显示为黑蓝色？
**原因**: OpenCV使用BGR格式，但matplotlib使用RGB格式

**解决方案**:
```python
# 转换BGR到RGB
img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
plt.imshow(img_rgb)  # 现在颜色正确
```

### Q3: 内存不足？
**原因**: 图像太大

**解决方案**:
```python
# 先调整尺寸
img = cv2.imread('large_image.jpg')
img = cv2.resize(img, (0, 0), fx=0.5, fy=0.5)  # 缩小到50%
```
