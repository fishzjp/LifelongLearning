# M1 · 从像素到特征

> **过关后你能**：诊断常见图像质量问题（噪点、过暗、模糊）并选择正确的处理手段；解释深度学习之前 CV 靠什么"认图"（手工特征），并实现图像拼接的核心一环——特征匹配。

**前置**：M0 过关。
**投入**：约 2 周。

## 项目：图像处理小工具

用 [L3 实战案例](L03-实战案例.md) 为骨架，做一个命令行小工具：输入一张随手拍的文档照片，输出矫正、增强后的清晰版本。

**验收标准**：
- 对 3 张不同角度/光照的文档照片都有效
- 每一步处理参数有依据（为什么是这个核大小/阈值）
- 附 README 说明用法
