# 视觉轨道 · 让计算机看见世界

**学会的标志**：面对一个图像任务（分类、检测、分割），你能独立完成"选方案 → 训练模型 → 评估 → 部署"的完整闭环，并说清每一步的原理。

**适合谁**：零基础转行者（从 M0 开始）、有编程基础想转 AI 者（直接进 M2）、在职开发者（按需选 M3/M4）。
**投入**：每周 8-10 小时，全程约 6-9 个月；到 M2 结束即具备初级岗笔试能力。

## 路径变体

- **求职冲刺**（每周 >15h）：M0 → M2 → M3，用 M3 两个项目撑作品集；M1 浏览即可，M4 以后补。
- **在职提升**：按任务选——做检测进 M3，做部署读 M4 + [debug-cv](../../references/debug-cv.md)。
- **研究向**：全部过关后，重点读 M4 与 [classics/扩展资源](M3/classics/扩展资源.md)。

## 数学怎么办

不要求先补数学。M2 之前你会遇到导数与矩阵——届时按 [README](../../prep/math/README.md) 精读对应分册（每册 1 小时），带着问题学，效率最高。Python 不熟同样处理：[prep/python/](../../prep/python/Python入门.md)。
