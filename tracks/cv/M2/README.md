## 项目：手写反向传播

[practice](practice.md) 练习 2。不用 PyTorch 的 autograd，纯 NumPy 实现一个两层网络在小型数据集上收敛。

**验收标准**：
- 训练损失持续下降，最终准确率与框架版差距 < 2%
- 能在白板上画出计算图并标出每步的梯度流向
- 能解释：把激活函数去掉后发生了什么、为什么
