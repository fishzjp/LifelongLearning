## 项目（两个，先后做）

1. **[CIFAR-10 完整训练](PROJECT-CIFAR10.md)**：从基线（70%）一路调到 90%+，记录每次改动的理由与效果——调参日志本身就是作品。
2. **[YOLO 口罩检测](PROJECT-YOLO.md)**：自己标数据、训练、评估 mAP、导出部署。

**验收标准（项目 1）**：准确率 ≥ 90%；有一份"改动 → 结果"的实验记录；能解释每个超参的最终取值依据。
**验收标准（项目 2）**：mAP@0.5 ≥ 0.85；含至少 5 张困难样本（遮挡/模糊）的测试；导出的模型能在新图片上跑通推理。
