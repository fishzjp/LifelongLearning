**如何使用 SHAP？**

```python
import shap

# 训练模型
model.fit(X_train, y_train)

explainer = shap.TreeExplainer(model)
```

### 5.2 模型融合技巧
**为什么模型融合有效？**

- 不同模型捕捉不同模式
- 降低单一模型的风险
- 提升整体预测精度

**常见融合方法**：

**简单平均**：
```python
pred_avg = (xgb_pred + lgb_pred) / 2
```

**加权平均**：
```python
pred_weighted = 0.6 * xgb_pred + 0.4 * lgb_pred
```

**Stacking**：
```python
from sklearn.ensemble import StackingClassifier

estimators = [
    ('xgb', XGBClassifier()),
    ('lgb', lgb.LGBMClassifier())
]

model = StackingClassifier(
    estimators=estimators,
    final_estimator=LogisticRegression()
)
```

### 核心要点回顾
1. **梯度提升 = 从错误中学习**
   - 每个新模型专注于纠正前一个模型的错误
   - 类比："接力复习小组"

2. **XGBoost = 工程化极致优化**
   - 正则化：控制复杂度
   - 稀疏性处理：自动处理缺失值
   - 加权分位数 Sketch：快速找分裂点
   - 二阶导数优化：更精确收敛

3. **LightGBM = 效率优先**
   - Leaf-wise 生长：集中火力
   - 直方图算法：用空间换时间
   - GOSS：保留重要样本
   - EFB：降低特征维度

4. **如何选择？**
   - 中小规模、可解释性 → XGBoost
   - 大规模、高维稀疏 → LightGBM

## 公式速查

1. **[梯度提升加法模型](#12-梯度提升的流程)**：$\hat{y}_i = \sum_{k=1}^{K} f_k(x_i)$
2. **[目标函数](#12-梯度提升的流程)**：$\mathcal{L}(\phi) = \sum_{i} l(\hat{y}_i, y_i)$
3. **[XGBoost 正则化项](#221-正则化regularization)**：$\Omega(f) = \gamma T + \frac{1}{2}\lambda \sum w_j^2$
4. **[泰勒展开](#224-二阶导数优化)**：$\mathcal{L}(y, \hat{y}^{(t)}) \approx \mathcal{L}(y, \hat{y}^{(t-1)}) + g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i)$
