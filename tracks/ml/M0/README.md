# M0 · 表格数据建模

> **过关后你能**：在 Kaggle 表格赛上独立完成一次完整提交（成绩 ≥ 中位数）；说清 XGBoost 与 LightGBM 的取舍；用调参流程而不是玄学提升分数。

**前置**：Python 基础（pandas 能读表即可）；懂导数概念。
**投入**：每周 8h 约 1-2 个月。

## 项目：Kaggle 表格赛完整提交

推荐从 [Titanic](https://www.kaggle.com/c/titanic) 或 [房价预测](https://www.kaggle.com/c/house-prices-advanced-regression-techniques) 开始（做完可挑战任一进行中的入门表格赛）。

**验收标准**：
- 走完完整流程：EDA → 基线（不调参）→ 特征工程 → 调参 → 交叉验证
- 有一份调参报告：每个重要参数"改动 → CV 变化 → 理由"，禁止只贴最终分数
- 用 SHAP 解释 top-5 特征，结论能与业务直觉对上
- 最终成绩 ≥ 该赛公开 Notebook 中位数

## 过关清单

- [ ] 用"接力复习"比喻向别人讲清梯度提升的核心思想
- [ ] 说清 XGBoost 与 LightGBM 各自的适用场景（数据量/维度/时效）
- [ ] 写出你的调参顺序（复杂度 → 学习率+树数 → 正则化），并解释为什么
- [ ] 解释 SHAP 图上"一个点的颜色"代表什么
- [ ] 项目四条验收全过

调参越调越差 → L4 陷阱清单；过拟合 → 对照 CV 与 LB 差距；数学推导卡壳 → [prep/math/](../../../prep/math/README.md)。
