## 上篇回顾：参数速查与陷阱清单

#### XGBoost 关键参数
| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `max_depth` | 树深度 | 3-10，默认 6 |
| `learning_rate` | 学习率 | 0.01-0.3，默认 0.1 |
| `n_estimators` | 树的数量 | 100-1000 |
| `reg_alpha` | L1 正则化 | 0-1 |
| `reg_lambda` | L2 正则化 | 0-1 |

#### LightGBM 关键参数
| 参数 | 说明 | 推荐值 |
|------|------|--------|
| `max_depth` | 树深度 | 3-8（防止过拟合） |
| `num_leaves` | 叶子数量 | < 2^max_depth |
| `learning_rate` | 学习率 | 0.01-0.1 |
| `feature_fraction` | 特征采样 | 0.6-1.0 |
| `bagging_fraction` | 数据采样 | 0.6-1.0 |

#### 调参策略
1. **先调 `max_depth` 和 `num_leaves`**：控制复杂度
2. **再调 `learning_rate` 和 `n_estimators`**：平衡速度和精度
3. **最后调正则化和采样参数**：防止过拟合

### 4.4 常见陷阱与解决
#### 陷阱1：过拟合
**表现**：训练集准确率很高，测试集很低

**解决**：
- 减小 `max_depth` 和 `num_leaves`
- 增加正则化（`reg_alpha`, `reg_lambda`）
- 使用特征采样和数据采样

#### 陷阱2：数据泄漏
**表现**：模型效果好，但实际应用很差

**原因**：特征中包含了未来信息

**解决**：仔细检查特征，确保不包含目标变量的信息

#### 陷阱3：类别不平衡
**表现**：模型倾向于预测多数类

**解决**：
- 使用 `scale_pos_weight` 参数
- 调整 `class_weight`
- 使用采样方法（SMOTE）

### 4.5 小结
**决策要点**：
- 大规模数据 → LightGBM
- 中小规模数据 → XGBoost
- 高维稀疏 → LightGBM
- 需要可解释性 → XGBoost

**快速上手步骤**：
1. 安装库：`pip install xgboost lightgbm`
2. 准备数据：划分特征和标签
3. 训练模型：调用 fit() 或 train()
4. 预测：调用 predict()
5. 评估：计算准确率、AUC 等指标

**调参策略**：
1. 控制复杂度：`max_depth`, `num_leaves`
2. 平衡速度和精度：`learning_rate`, `n_estimators`
3. 防止过拟合：正则化、采样

### 5.1 模型可解释性（SHAP）
**什么是 SHAP？**

**SHAP**（SHapley Additive exPlanations）是一种基于博弈论的方法，用于解释机器学习模型的预测。

**为什么需要可解释性？**

- 金融、医疗等领域要求解释模型决策
- 理解模型如何做决策
- 建立用户信任
