# 建模轨道 · 表格数据实战

**学会的标志**：拿一份没见过的表格数据（用户行为、交易记录、房价），你能完成"探索 → 基线 → 调参 → 评估 → 解释"的完整建模流程，成绩达到该数据集 Kaggle 中位数水平以上。

**适合谁**：想入门机器学习的人（最快路径）、要打数据比赛的在校学生、需要做预测模型的业务工程师。
**投入**：每周 8h 约 1-2 个月。

## 为什么从梯度提升开始

深度学习适合图像文本；现实业务大量输入是"一张二维表"，XGBoost/LightGBM 至今是表格任务基准：快、准、可解释、好部署。先拿下它 = 拿到表格任务的默认起点，也是理解树模型的最佳路径。

## 数学怎么办

本轨道对数学要求温和：懂"导数 = 变化率"即可开课；二阶泰勒展开（XGBoost 课）卡壳时去 [02-微积分](../../prep/math/02-微积分.md) 补对应小节。
