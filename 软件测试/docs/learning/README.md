## 💡 学习建议

### ✅ 应该做的

1. **每天动手**：只看不练=没学
2. **先理解后记忆**：理解原理比背诵重要
3. **记录问题**：遇到问题先记录，再搜索
4. **分享输出**：教是最好的学

### ❌ 避免的坑

1. **跳过基础**：基础不牢，地动山摇
2. **贪多求快**：一天学10章不如1章学3遍
3. **不写注释**：代码是写给人看的
4. **害怕失败**：测试失败是常态
