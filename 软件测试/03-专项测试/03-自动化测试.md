## 1. 自动化测试概述

### 1.1 什么是自动化测试

自动化测试（Automation Testing）是指使用自动化测试工具和脚本代替人工执行测试用例的过程。通过自动化脚本可以自动运行测试、比较实际结果与预期结果，并生成测试报告。

### 1.2 自动化测试的优势与局限性

#### ✅ 优势

- **高效率**：可24小时不间断运行，快速执行大量测试用例
- **可重复性**：脚本可重复执行，避免人为操作失误
- **覆盖率高**：能够执行更多更复杂的测试场景
- **回归测试**：快速进行回归测试，确保新功能不影响原有功能
- **资源复用**：脚本可复用，长期投入产出比高

#### ❌ 局限性

- **初期投入大**：需要投入时间和成本搭建框架、编写脚本
- **维护成本高**：UI变化时需要维护脚本
- **无法完全替代人工**：用户体验、界面美观度等需要人工判断
- **技术门槛高**：需要编程能力和测试技术结合

### 1.3 自动化测试适用场景

```
适合自动化的场景：
├── 重复性高的测试用例（如登录、数据初始化）
├── 回归测试（频繁迭代的项目）
├── 性能测试（并发、压力测试）
├── 兼容性测试（多浏览器、多设备）
└── 数据驱动测试（大量测试数据）

不适合自动化的场景：
├── 一次性测试
├── 界面频繁变更的项目
├── 需要人工判断的探索性测试
└── 用户体验测试
```

## 3. 主流自动化测试框架

### 3.1 Selenium WebDriver

#### 简介

Selenium 是最流行的 Web 自动化测试框架，支持多种编程语言（Java、Python、C#、JavaScript等）。

#### 核心组件

- **Selenium IDE**：录制回放工具（浏览器插件）
- **Selenium WebDriver**：核心API，控制浏览器
- **Selenium Grid**：分布式测试执行

#### 环境搭建（Python示例）

```bash
# 安装 Selenium

pip install selenium

# 下载浏览器驱动（以Chrome为例）
# 访问 https://chromedriver.chromium.org/ 下载对应版本

```

#### 基础使用示例

```python
from selenium import webdriver
from selenium.webdriver.common.by import By
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC
import time

# 1. 启动浏览器

driver = webdriver.Chrome()

# 2. 访问网页

driver.get("https://www.example.com")

# 3. 元素定位
# ID定位

username = driver.find_element(By.ID, "username")
# CSS选择器

password = driver.find_element(By.CSS_SELECTOR, "input[type='password']")
# XPath定位

login_btn = driver.find_element(By.XPATH, "//button[@type='submit']")

# 4. 元素操作

username.send_keys("testuser")
password.send_keys("password123")
login_btn.click()

# 5. 等待机制（显式等待）

wait = WebDriverWait(driver, 10)
element = wait.until(
    EC.presence_of_element_located((By.ID, "welcome_message"))
)

# 6. 获取信息

title = driver.title
url = driver.current_url
text = element.text

# 7. 关闭浏览器

driver.quit()
```

#### 常用定位方式

```python
from selenium.webdriver.common.by import By

# 8种定位方式

driver.find_element(By.ID, "id_value")              # ID
driver.find_element(By.NAME, "name_value")          # Name
driver.find_element(By.CLASS_NAME, "class_name")    # Class Name
driver.find_element(By.TAG_NAME, "tag_name")        # Tag Name
driver.find_element(By.LINK_TEXT, "链接文本")       # Link Text
driver.find_element(By.PARTIAL_LINK_TEXT, "部分文本") # Partial Link Text
driver.find_element(By.CSS_SELECTOR, "div.class")   # CSS Selector
driver.find_element(By.XPATH, "//div[@class='test']") # XPath
```

#### 等待机制

```bash
# 隐式等待（全局）

driver.implicitly_wait(10)

# 显式等待（推荐）

from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wait = WebDriverWait(driver, 20)
# 等待元素可见

element = wait.until(EC.visibility_of_element_located((By.ID, "element_id")))
# 等待元素可点击

element = wait.until(EC.element_to_be_clickable((By.ID, "button_id")))
# 等待元素不存在

wait.until(EC.invisibility_of_element_located((By.ID, "loading")))

# 常用预期条件

EC.presence_of_element_located()    # 元素存在于DOM中
EC.visibility_of_element_located()  # 元素可见
EC.element_to_be_clickable()        # 元素可点击
EC.text_to_be_present_in_element()  # 元素包含特定文本
EC.alert_is_present()               # Alert弹窗出现
```

### 4.2 Page Object 设计模式

```bash
# base_page.py

from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

class BasePage:
    def __init__(self, driver):
        self.driver = driver
        self.wait = WebDriverWait(driver, 10)

    def find_element(self, locator):
        """查找元素（带等待）"""
        return self.wait.until(EC.presence_of_element_located(locator))

    def click(self, locator):
        """点击元素"""
        self.find_element(locator).click()

    def input_text(self, locator, text):
        """输入文本"""
        self.find_element(locator).clear()
        self.find_element(locator).send_keys(text)

    def get_text(self, locator):
        """获取文本"""
        return self.find_element(locator).text

# login_page.py

from selenium.webdriver.common.by import By
from .base_page import BasePage

class LoginPage(BasePage):
    # 元素定位器
    USERNAME_INPUT = (By.ID, "username")
    PASSWORD_INPUT = (By.ID, "password")
    LOGIN_BUTTON = (By.ID, "login_btn")
    ERROR_MESSAGE = (By.CLASS_NAME, "error")

    def login(self, username, password):
        """登录操作"""
        self.input_text(self.USERNAME_INPUT, username)
        self.input_text(self.PASSWORD_INPUT, password)
        self.click(self.LOGIN_BUTTON)

    def get_error_message(self):
        """获取错误信息"""
        return self.get_text(self.ERROR_MESSAGE)

# test_login.py

def test_login_success(page_factory):
    login_page = page_factory.login_page
    login_page.login("admin", "123456")
    assert "欢迎" in page_factory.home_page.get_welcome_text()
```

### 4.3 数据驱动测试

```bash
# 使用 pytest 的 parametrize

import pytest

test_data = [
    ("admin", "123456", True, "正常账号"),
    ("", "123456", False, "空用户名"),
    ("admin", "", False, "空密码"),
    ("wrong", "wrong", False, "错误账号")
]

@pytest.mark.parametrize("username,password,expected,result_desc", test_data)
def test_login(browser, username, password, expected, result_desc):
    login_page = LoginPage(browser)
    login_page.login(username, password)

    if expected:
        assert browser.current_url == "https://example.com/home"
    else:
        assert login_page.is_error_displayed()
```

### 4.4 异常处理和日志

```python
import logging
from selenium.common.exceptions import TimeoutException, NoSuchElementException

class SafeExecutor:
    @staticmethod
    def safe_click(element, max_retries=3):
        """安全点击，带重试机制"""
        for attempt in range(max_retries):
            try:
                element.click()
                return True
            except Exception as e:
                logging.warning(f"点击失败，第{attempt+1}次重试: {e}")
                time.sleep(1)
        return False

# 日志配置

logging.basicConfig(
    level=logging.INFO,
    format='%(asctime)s - %(levelname)s - %(message)s',
    handlers=[
        logging.FileHandler('test.log'),
        logging.StreamHandler()
    ]
)
```
