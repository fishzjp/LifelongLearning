## 1. 接口测试概述

### 1.1 什么是接口测试

接口测试（API Testing）是测试系统组件间接口的一种测试方法，主要检验接口的功能、性能、安全性和可靠性。

```
系统架构示例：
┌─────────┐      HTTP/HTTPS      ┌──────────┐
│ 客户端  │ ──────────────────> │ 服务端   │
│ (App/Web)│ <───────────────── │ (API)    │
└─────────┘      JSON/XML       └──────────┘
```

### 1.2 接口测试的优势

- **早期介入**：可在UI完成前进行测试
- **高效率**：执行速度快，可批量运行
- **定位准确**：直接验证业务逻辑，问题定位更精准
- **覆盖率高**：可测试边界条件和异常场景
- **成本低**：维护成本低于UI自动化

### 1.3 接口测试适用场景

```
适用场景：
├── 前后端分离架构
├── 微服务架构
├── 移动端应用
├── 第三方服务集成
└── 高频迭代项目
```

## 2. HTTP 协议基础

### 2.1 HTTP 方法

| 方法 | 描述 | 幂等性 | 安全性 | 典型用途 |
|------|------|--------|--------|---------|
| **GET** | 获取资源 | ✓ | ✓ | 查询数据 |
| **POST** | 创建资源 | ✗ | ✗ | 新增数据 |
| **PUT** | 更新资源（全量） | ✓ | ✗ | 修改数据 |
| **PATCH** | 更新资源（部分） | ✗ | ✗ | 部分修改 |
| **DELETE** | 删除资源 | ✓ | ✗ | 删除数据 |

### 2.2 HTTP 状态码

```bash
# 2xx 成功

200 OK          # 请求成功
201 Created     # 资源创建成功
204 No Content  # 成功但无返回内容

# 3xx 重定向

301 Moved Permanently  # 永久重定向
302 Found              # 临时重定向
304 Not Modified       # 缓存有效

# 4xx 客户端错误

400 Bad Request      # 请求参数错误
401 Unauthorized     # 未认证
403 Forbidden        # 无权限
404 Not Found        # 资源不存在
422 Unprocessable Entity  # 请求格式正确但语义错误

# 5xx 服务端错误

500 Internal Server Error  # 服务器内部错误
502 Bad Gateway            # 网关错误
503 Service Unavailable    # 服务不可用
504 Gateway Timeout        # 网关超时
```

### 2.3 RESTful API 设计规范

```
资源设计示例：
GET    /api/users           # 获取用户列表
GET    /api/users/{id}      # 获取单个用户
POST   /api/users           # 创建用户
PUT    /api/users/{id}      # 更新用户（全量）
PATCH  /api/users/{id}      # 更新用户（部分）
DELETE /api/users/{id}      # 删除用户

查询参数：
```

## 3. Postman 接口测试

### 3.1 Postman 介绍

Postman 是最流行的接口测试工具，提供图形化界面和脚本编写能力。

### 3.2 基础使用

#### 创建请求

```
请求配置：
├── Method: GET/POST/PUT/DELETE
├── URL: https://api.example.com/users
├── Headers:
│   ├── Content-Type: application/json
│   └── Authorization: Bearer token
├── Body (POST/PUT):
│   └── raw JSON
├── Query Params:
│   └── page=1&size=10
└── Tests (断言脚本)
```

#### 基础断言示例

```javascript
// Tests 脚本

// 1. 状态码断言
pm.test("Status code is 200", function () {
    pm.response.to.have.status(200);
});

// 2. 响应时间断言
pm.test("Response time is less than 500ms", function () {
    pm.expect(pm.response.responseTime).to.be.below(500);
});

// 3. JSON 响应断言
pm.test("User ID is correct", function () {
    const jsonData = pm.response.json();
    pm.expect(jsonData.id).to.eql(1);
});

// 4. 响应体包含特定文本
pm.test("Response contains user name", function () {
    pm.response.to.have.body("John Doe");
});

// 5. Header 断言
pm.test("Content-Type header is present", function () {
    pm.response.to.have.header("Content-Type");
});

// 6. 复杂断言
pm.test("All users have active status", function () {
    const jsonData = pm.response.json();
    jsonData.forEach(function(user) {
        pm.expect(user.status).to.eql("active");
    });
});
```

#### Pre-request Script（前置脚本）

```python
// 请求前执行的脚本

// 1. 生成时间戳
const timestamp = new Date().getTime();
pm.environment.set("timestamp", timestamp);

// 2. 生成随机数
const randomId = Math.floor(Math.random() * 10000);
pm.environment.set("randomId", randomId);

// 3. 生成签名
const crypto = require('crypto-js');
const secret = pm.environment.get("secret_key");
const data = pm.request.url.substring(22); // 获取请求路径
const signature = crypto.HmacSHA256(data, secret).toString();
pm.environment.set("signature", signature);

// 4. 设置动态变量
pm.environment.set("request_id", `REQ_${timestamp}_${randomId}`);
```

```python
import requests
import json

# 基础请求示例

class APITester:
    def __init__(self, base_url):
        self.base_url = base_url
        self.session = requests.Session()

    # GET 请求
    def get_users(self, page=1, size=10):
        url = f"{self.base_url}/users"
        params = {"page": page, "size": size}
        response = self.session.get(url, params=params)
        return response

    # POST 请求
    def create_user(self, user_data):
        url = f"{self.base_url}/users"
        headers = {"Content-Type": "application/json"}
        response = self.session.post(
            url,
            data=json.dumps(user_data),
            headers=headers
        )
        return response

    # PUT 请求
    def update_user(self, user_id, user_data):
        url = f"{self.base_url}/users/{user_id}"
        headers = {"Content-Type": "application/json"}
        response = self.session.put(
            url,
            data=json.dumps(user_data),
            headers=headers
        )
        return response

    # DELETE 请求
    def delete_user(self, user_id):
        url = f"{self.base_url}/users/{user_id}"
        response = self.session.delete(url)
        return response

# 使用示例

api = APITester("https://api.example.com")

# GET 请求

response = api.get_users(page=1, size=5)
print(f"Status: {response.status_code}")
print(f"Data: {response.json()}")

# POST 请求

new_user = {
    "name": "张三",
    "email": "zhangsan@example.com",
    "age": 25
}
response = api.create_user(new_user)
print(f"Created: {response.json()}")
```

```python
import requests
from requests.auth import HTTPBasicAuth

class AuthAPITester:
    def __init__(self, base_url):
        self.base_url = base_url
        self.headers = {
            "User-Agent": "API-Test-Client/1.0",
            "Accept": "application/json"
        }

    # Basic Auth
    def test_basic_auth(self, username, password):
        url = f"{self.base_url}/protected"
        response = requests.get(
            url,
            auth=HTTPBasicAuth(username, password),
            headers=self.headers
        )
        return response

    # Bearer Token
    def test_bearer_token(self, token):
        url = f"{self.base_url}/api/data"
        headers = self.headers.copy()
        headers["Authorization"] = f"Bearer {token}"
        response = requests.get(url, headers=headers)
        return response

    # API Key
    def test_api_key(self, api_key):
        url = f"{self.base_url}/api/data"
        headers = self.headers.copy()
        headers["X-API-Key"] = api_key
        response = requests.get(url, headers=headers)
        return response

    # OAuth2 (简化示例)
    def get_oauth_token(self, client_id, client_secret):
        url = f"{self.base_url}/oauth/token"
        data = {
            "grant_type": "client_credentials",
            "client_id": client_id,
            "client_secret": client_secret
        }
        response = requests.post(url, data=data)
        return response.json().get("access_token")
```

### 4.3 数据处理和断言

```python
import unittest
import requests

class TestUserAPI(unittest.TestCase):
    BASE_URL = "https://api.example.com"

    def setUp(self):
        """测试前置准备"""
        self.api = requests.Session()

    def tearDown(self):
        """测试后置清理"""
        self.api.close()

    def test_get_users_success(self):
        """测试获取用户列表"""
        response = self.api.get(f"{self.BASE_URL}/users")

        # 状态码断言
        self.assertEqual(response.status_code, 200)

        # 响应时间断言
        self.assertLess(response.elapsed.total_seconds(), 1.0)

        # 响应体结构断言
        data = response.json()
        self.assertIn("users", data)
        self.assertIsInstance(data["users"], list)

    def test_create_user(self):
        """测试创建用户"""
        user_data = {
            "name": "测试用户",
            "email": "test@example.com",
            "age": 30
        }

        response = self.api.post(
            f"{self.BASE_URL}/users",
            json=user_data
        )

        # 验证创建成功
        self.assertEqual(response.status_code, 201)
        data = response.json()
        self.assertIn("id", data)
        self.assertEqual(data["name"], user_data["name"])

        # 清理数据
        user_id = data["id"]
        self.api.delete(f"{self.BASE_URL}/users/{user_id}")

    def test_update_user(self):
        """测试更新用户"""
        # 先创建用户
        create_resp = self.api.post(
            f"{self.BASE_URL}/users",
            json={"name": "Original", "email": "orig@example.com"}
        )
        user_id = create_resp.json()["id"]

        # 更新用户
        update_data = {"name": "Updated"}
        response = self.api.put(
            f"{self.BASE_URL}/users/{user_id}",
            json=update_data
        )

        self.assertEqual(response.status_code, 200)
        self.assertEqual(response.json()["name"], "Updated")

        # 清理
        self.api.delete(f"{self.BASE_URL}/users/{user_id}")

    def test_delete_user(self):
        """测试删除用户"""
        # 创建用户
        create_resp = self.api.post(
            f"{self.BASE_URL}/users",
            json={"name": "To Delete", "email": "delete@example.com"}
        )
        user_id = create_resp.json()["id"]

        # 删除用户
        response = self.api.delete(f"{self.BASE_URL}/users/{user_id}")
        self.assertEqual(response.status_code, 204)

        # 验证已删除
        get_resp = self.api.get(f"{self.BASE_URL}/users/{user_id}")
        self.assertEqual(get_resp.status_code, 404)

    def test_error_handling(self):
        """测试错误处理"""
        # 无效的用户ID
        response = self.api.get(f"{self.BASE_URL}/users/999999")
        self.assertEqual(response.status_code, 404)

        # 无效的数据格式
        response = self.api.post(
            f"{self.BASE_URL}/users",
            json={"invalid": "data"}
        )
        self.assertEqual(response.status_code, 422)

if __name__ == "__main__":
    unittest.main()
```

### 4.5 异步接口测试

```python
import asyncio
import aiohttp
import time

class AsyncAPITester:
    async def fetch(self, session, url):
        """异步请求单个接口"""
        async with session.get(url) as response:
            return await response.json()

    async def test_multiple_requests(self, urls):
        """并发测试多个接口"""
        async with aiohttp.ClientSession() as session:
            tasks = [self.fetch(session, url) for url in urls]
            results = await asyncio.gather(*tasks)
            return results

    def run_concurrent_test(self):
        """运行并发测试"""
        urls = [
            "https://api.example.com/users/1",
            "https://api.example.com/users/2",
            "https://api.example.com/users/3"
        ]

        start_time = time.time()
        results = asyncio.run(self.test_multiple_requests(urls))
        end_time = time.time()

        print(f"并发请求数: {len(urls)}")
        print(f"总耗时: {end_time - start_time:.2f}s")
        print(f"平均响应时间: {(end_time - start_time)/len(urls):.2f}s")
        return results
```

#### 测试基类

```bash
# api/base_api.py

import requests
from config.settings import Config

class BaseAPI:
    def __init__(self, env="dev"):
        self.config = Config(env)
        self.session = requests.Session()
        self.base_url = self.config.base_url
        self.timeout = self.config.timeout

    def request(self, method, endpoint, **kwargs):
        """统一请求方法"""
        url = f"{self.base_url}{endpoint}"

        # 添加通用headers
        headers = kwargs.pop("headers", {})
        headers["X-API-Key"] = self.config.api_key
        headers["Content-Type"] = "application/json"

        try:
            response = self.session.request(
                method=method,
                url=url,
                headers=headers,
                timeout=self.timeout,
                **kwargs
            )
            return response
        except requests.exceptions.Timeout:
            raise Exception(f"请求超时: {url}")
        except requests.exceptions.RequestException as e:
            raise Exception(f"请求失败: {e}")

    def get(self, endpoint, params=None):
        return self.request("GET", endpoint, params=params)

    def post(self, endpoint, json_data):
        return self.request("POST", endpoint, json=json_data)

    def put(self, endpoint, json_data):
        return self.request("PUT", endpoint, json=json_data)

    def delete(self, endpoint):
        return self.request("DELETE", endpoint)
```

```bash
def cleanup_user(user_api):
```

### 6.4 性能测试

```python
import time
import statistics

class PerformanceTester:
    def __init__(self, api_client):
        self.api = api_client
        self.results = []

    def test_response_time(self, endpoint, iterations=100):
        """测试接口响应时间"""
        for i in range(iterations):
            start = time.time()
            response = self.api.get(endpoint)
            elapsed = time.time() - start

            self.results.append({
                "iteration": i + 1,
                "time": elapsed,
                "status": response.status_code
            })

        # 统计分析
        times = [r["time"] for r in self.results]
        print(f"平均响应时间: {statistics.mean(times):.3f}s")
        print(f"中位数: {statistics.median(times):.3f}s")
        print(f"最大值: {max(times):.3f}s")
        print(f"最小值: {min(times):.3f}s")
        print(f"标准差: {statistics.stdev(times):.3f}s")

        return self.results
```

```bash
# tests/test_user_management.py

import pytest
import requests
from datetime import datetime, timedelta

class TestUserManagement:
    """用户管理系统接口测试"""

    BASE_URL = "https://api.example.com"

    @pytest.fixture
    def auth_headers(self):
        """认证头部"""
        # 登录获取token
        login_data = {"username": "admin", "password": "admin123"}
        response = requests.post(
            f"{self.BASE_URL}/auth/login",
            json=login_data
        )
        token = response.json()["token"]
        return {
            "Authorization": f"Bearer {token}",
            "Content-Type": "application/json"
        }

    def test_user_registration(self):
        """测试用户注册"""
        timestamp = int(datetime.now().timestamp())
        user_data = {
            "username": f"testuser_{timestamp}",
            "email": f"test{timestamp}@example.com",
            "password": "TestPass123!",
            "full_name": "Test User"
        }

        response = requests.post(
            f"{self.BASE_URL}/users/register",
            json=user_data
        )

        assert response.status_code == 201
        data = response.json()
        assert "id" in data
        assert data["username"] == user_data["username"]

        # 返回用户ID用于后续测试
        return data["id"]

    def test_user_login(self):
        """测试用户登录"""
        # 先注册
        user_id = self.test_user_registration()

        # 登录
        login_data = {
            "username": f"testuser_{int(datetime.now().timestamp())}",
            "password": "TestPass123!"
        }

        response = requests.post(
            f"{self.BASE_URL}/auth/login",
            json=login_data
        )

        assert response.status_code == 200
        data = response.json()
        assert "token" in data
        assert "refresh_token" in data

        # 清理
        requests.delete(f"{self.BASE_URL}/users/{user_id}")

    def test_get_user_list(self, auth_headers):
        """测试获取用户列表"""
        response = requests.get(
            f"{self.BASE_URL}/users",
            headers=auth_headers,
            params={"page": 1, "size": 10}
        )

        assert response.status_code == 200
        data = response.json()

        assert "users" in data
        assert "total" in data
        assert "page" in data
        assert isinstance(data["users"], list)

        if data["users"]:
            user = data["users"][0]
            assert "id" in user
            assert "username" in user

    def test_update_user_profile(self, auth_headers):
        """测试更新用户资料"""
        # 创建测试用户
        user_id = self.test_user_registration()

        # 更新资料
        update_data = {
            "full_name": "Updated Name",
            "phone": "13800138000"
        }

        response = requests.put(
            f"{self.BASE_URL}/users/{user_id}",
            headers=auth_headers,
            json=update_data
        )

        assert response.status_code == 200
        data = response.json()
        assert data["full_name"] == "Updated Name"
        assert data["phone"] == "13800138000"

        # 验证更新
        get_response = requests.get(
            f"{self.BASE_URL}/users/{user_id}",
            headers=auth_headers
        )
        assert get_response.json()["full_name"] == "Updated Name"

        # 清理
        requests.delete(f"{self.BASE_URL}/users/{user_id}", headers=auth_headers)

    def test_delete_user(self, auth_headers):
        """测试删除用户"""
        # 创建用户
        user_id = self.test_user_registration()

        # 删除
        response = requests.delete(
            f"{self.BASE_URL}/users/{user_id}",
            headers=auth_headers
        )

        assert response.status_code == 204

        # 验证已删除
        get_response = requests.get(
            f"{self.BASE_URL}/users/{user_id}",
            headers=auth_headers
        )
        assert get_response.status_code == 404

    def test_unauthorized_access(self):
        """测试未授权访问"""
        # 不带token访问受限接口
        response = requests.get(f"{self.BASE_URL}/users")
        assert response.status_code == 401

        # 带无效token
        invalid_headers = {
            "Authorization": "Bearer invalid_token",
            "Content-Type": "application/json"
        }
        response = requests.get(
            f"{self.BASE_URL}/users",
            headers=invalid_headers
        )
        assert response.status_code == 401

    def test_data_validation(self):
        """测试数据验证"""
        # 无效邮箱
        invalid_data = {
            "username": "testuser",
            "email": "invalid-email",
            "password": "password123"
        }
        response = requests.post(
            f"{self.BASE_URL}/users/register",
            json=invalid_data
        )
        assert response.status_code == 422

        # 密码太短
        weak_password = {
            "username": "testuser",
            "email": "test@example.com",
            "password": "123"
        }

            f"{self.BASE_URL}/users/register",
            json=weak_password

        assert response.status_code == 422
```
