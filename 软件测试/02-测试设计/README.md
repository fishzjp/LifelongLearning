# 02-测试设计

> **一句话总结**：掌握科学的测试设计方法，学会如何设计高质量的测试用例

---

## 📖 本部分概览

测试设计是测试工作的核心技能，决定了测试的覆盖率和有效性。本部分将系统讲解测试用例设计方法、黑盒/白盒/灰盒测试技术，以及如何制定测试策略。

### 你将学到什么

- ✅ **测试用例设计**：掌握等价类划分、边界值分析等方法
- ✅ **黑盒测试技术**：学习6种核心黑盒测试方法
- ✅ **白盒测试技术**：掌握逻辑覆盖和路径测试
- ✅ **灰盒测试技术**：了解结合黑盒和白盒的测试策略
- ✅ **测试策略设计**：学会制定完整的测试方案

## 🎯 学习目标

完成本部分学习后，你将能够：

1. **设计高质量测试用例**
   - [ ] 运用等价类划分法设计测试用例
   - [ ] 运用边界值分析法识别边界条件
   - [ ] 使用场景法设计用户场景测试
   - [ ] 编写规范的测试用例文档

2. **掌握黑盒测试技术**
   - [ ] 应用至少5种黑盒测试方法
   - [ ] 根据需求选择合适的测试方法
   - [ ] 设计全面的黑盒测试方案

3. **掌握白盒测试技术**
   - [ ] 理解不同级别的逻辑覆盖
   - [ ] 绘制控制流图
   - [ ] 计算圈复杂度
   - [ ] 设计白盒测试用例

4. **制定测试策略**
   - [ ] 分析项目风险
   - [ ] 确定测试范围和重点
   - [ ] 规划测试资源和进度
   - [ ] 编写完整的测试计划

## 💡 学习建议

### 重点章节
1. **01-测试用例设计基础** - 必须精通，这是最常用的技能
2. **02-黑盒测试方法** - 核心章节，内容丰富，需要大量练习
3. **05-测试策略与计划** - 实用性极强，工作中直接应用

### 学习顺序建议
- **测试新人**：按顺序学习，01→02→03→04→05
- **有经验者**：重点看02和05，其他快速浏览
- **开发转测试**：重点关注03白盒测试

### 常见难点
- **白盒测试的逻辑覆盖**：需要多做练习，绘制控制流图
- **决策表法**：复杂场景容易出错，建议先从简单场景开始
- **测试策略制定**：需要结合实际项目经验，多看案例
