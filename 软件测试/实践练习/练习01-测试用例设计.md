## 📝 练习题目

### 题目1：登录功能测试

**需求描述**：
用户登录系统，需要验证用户名和密码：
- 用户名：6-20位字符，只能包含字母、数字和下划线
- 密码：8-16位字符，必须包含字母和数字
- 登录失败3次后锁定账号30分钟

**任务**：
1. 使用等价类划分法设计测试用例
2. 使用边界值分析法补充测试用例
3. 设计异常场景测试用例
4. 编写完整的测试用例（包含前置条件、步骤、预期结果）

### 题目2：购物车结算

**需求描述**：
购物车结算功能：
- 商品总价 = 商品单价 × 数量 - 优惠券金额
- 优惠券满100减10，满200减25，满500减80
- 运费：满99包邮，否则10元
- 最终支付金额 = 总价 + 运费

**任务**：
1. 设计测试场景（正常+异常）
2. 使用场景法编写测试用例
3. 设计边界值测试用例（0件、1件、最大库存）
4. 考虑并发场景（多人同时购买同一商品）

### 题目3：文件上传功能

**需求描述**：
文件上传功能要求：
- 文件大小：不超过10MB
- 文件类型：jpg, png, pdf
- 文件名：不能包含特殊字符
- 上传后需要进行病毒扫描

**任务**：
1. 设计功能测试用例
2. 设计安全测试用例
3. 设计性能测试用例（大文件、慢网络）
4. 设计异常处理测试用例

### 📈 自动评估脚本

```python
#!/usr/bin/env python3
# test_case_evaluator.py - 测试用例自评估工具

import re

class TestCaseEvaluator:
    def __init__(self):
        self.score = 0
        self.max_score = 100
        self.feedback = []

    def evaluate(self, test_cases):
        """评估测试用例质量"""
        self.score = 0
        self.feedback = []

        # 1. 完整性检查 (40分)
        self._check_completeness(test_cases)

        # 2. 规范性检查 (30分)
        self._check_standardization(test_cases)

        # 3. 覆盖度检查 (30分)
        self._check_coverage(test_cases)

        return self._generate_report()

    def _check_completeness(self, test_cases):
        """检查完整性"""
        required_fields = ['用例编号', '测试步骤', '预期结果']

        for i, tc in enumerate(test_cases):
            for field in required_fields:
                if field in tc:
                    self.score += 2
                else:
                    self.feedback.append(f"用例{i+1}缺少字段: {field}")

        # 检查是否包含等价类分析
        if '等价类' in str(test_cases):
            self.score += 10
        else:
            self.feedback.append("缺少等价类分析")

        # 检查是否包含边界值
        if '边界' in str(test_cases):
            self.score += 10
        else:
            self.feedback.append("缺少边界值分析")

    def _check_standardization(self, test_cases):
        """检查规范性"""
        for i, tc in enumerate(test_cases):
            # 检查步骤是否编号
            if re.search(r'\d+\.', str(tc)):
                self.score += 2

            # 检查是否有明确预期结果
            if '预期结果' in tc and len(tc['预期结果']) > 5:
                self.score += 2

    def _check_coverage(self, test_cases):
        """检查覆盖度"""
        # 统计不同场景类型
        content = str(test_cases).lower()

        if '正常' in content or 'success' in content:
            self.score += 5

        if '异常' in content or 'error' in content or '失败' in content:
            self.score += 5

        if '边界' in content or 'boundary' in content:
            self.score += 5

        if '安全' in content or 'security' in content:
            self.score += 5

        if '性能' in content or 'performance' in content:
            self.score += 5

        # 检查用例数量
        if len(test_cases) >= 10:
            self.score += 5
        elif len(test_cases) >= 5:
            self.score += 3

    def _generate_report(self):
        """生成评估报告"""
        level = ""
        if self.score >= 90:
            level = "优秀 ✅"
        elif self.score >= 70:
            level = "良好 ✅"
        elif self.score >= 60:
            level = "及格 ⚠️"
        else:
            level = "不合格 ❌"

        report = f"""
# 测试用例评估报告

## 评分结果
- **总分**：{self.score}/{self.max_score}
- **等级**：{level}

## 详细反馈
"""

        if self.feedback:
            for item in self.feedback:
                report += f"- {item}\n"
        else:
            report += "- ✅ 所有检查通过！\n"

        report += f"\n## 改进建议\n"

        if self.score < 90:
            if self.score < 60:
                report += "- 需要补充更多测试场景\n"
                report += "- 完善测试用例格式\n"
            elif self.score < 70:
                report += "- 增加边界值测试\n"
                report += "- 补充异常场景\n"
            else:
                report += "- 考虑安全性和性能测试\n"
                report += "- 优化测试用例描述\n"

        return report

# 使用示例
if __name__ == "__main__":
    # 示例测试用例数据
    test_cases = [
        {
            "用例编号": "TC-LOGIN-001",
            "测试步骤": "1. 输入正确用户名\n2. 输入正确密码\n3. 点击登录",
            "预期结果": "登录成功"
        }
    ]

    evaluator = TestCaseEvaluator()
    report = evaluator.evaluate(test_cases)
    print(report)
```
